# 📚 电网安全论文库

> 本页使用 **Dataview** 插件动态生成，打开即自动刷新。

## 📊 总览

```dataviewjs
const papers = dv.pages('"20_Research/Papers"');
```

## 🗂 按领域统计

```dataview
TABLE WITHOUT ID
  domain AS "研究领域",
  length(rows) AS "论文数"
FROM "20_Research/Papers"
WHERE domain
GROUP BY domain
SORT length(rows) DESC
```

---

## 📄 全部论文（按发布日期倒序）

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS "论文",
  domain AS "领域",
  published AS "发布日期",
  venue AS "来源"
FROM "20_Research/Papers"
WHERE source_type = "arxiv"
SORT published DESC
```

## 🏷 按标签浏览

```dataview
TABLE WITHOUT ID
  link(file.link, title) AS "论文",
  tags AS "标签"
FROM "20_Research/Papers"
WHERE tags
SORT file.mtime DESC
```

## 🔍 快速检索提示

- **按关键词**：`Ctrl/Cmd + O` 打开快速切换器
- **全局搜索**：`Ctrl/Cmd + Shift + F`，可用 `tag:#FDI` 或 `path:"20_Research"` 精确定位
- **图谱视图**：左侧栏「关系图谱」，可看论文间的引用链接
- **反向链接**：打开任一论文，底部「反向链接」显示哪些简报引用了它
