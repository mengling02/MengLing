### AIDC Microgrid Vulnerability Assessment Under Computing-Power Coordinated Attacks

> **arXiv**: [2608.10645](https://arxiv.org/abs/2608.10645) ｜ **提交**: 2026-08-11（v2 08-22）｜ **分类**: eess.SY ｜ **10 页 / 7 图 / 5 表**
> **作者**: Ze Yu, Hongwei Zhen, Chao Shen, Mingyang Sun（IEEE Senior Member）
> **深度解读**: [[AIDC_Microgrid_Vulnerability_Assessment_Under_Computing-Power_Coordinated_Attacks]]

### 一句话概括

**用恶意 Prompt 抬高算力功耗（改变负荷阻抗）+ 篡改光伏逆变器控制参数（改变电源阻抗）——单独做都无害，合起来能把 AI 数据中心微电网推出发散振荡。** 论文给出的是一套**不确定性感知的脆弱性评估框架**，回答"什么时候打、打哪个向量"。

### 深度解读摘要

**问题**：AIDC 微电网同时依赖（1）互连的计算/通信基础设施，与（2）通过量测控制信号调节电压频率的逆变器。这形成了**两个跨域攻击面**：

| 攻击面 | 入口 | 物理后果 |
|---|---|---|
| 算力侧 | AI 服务公开 API（恶意 Prompt） | 改变功率需求 → 改变**负荷阻抗** |
| 电力侧 | PV 逆变器参数更新接口 | 改变控制参数 → 改变**电源阻抗** |

**威胁模型极低门槛**：攻击者只需 **①用户级 API 访问 + ②只读 PMU + ③一个被攻陷的逆变器参数接口**——**不需要物理接触、不需要改拓扑、不需要覆盖保护约束**。这是本文最值得记住的一点。

**方法链**（五步）：

```
① 算力侧：对抗 AI 请求 → 工作负载放大 → AIDC 功率抬升 → AIDC 阻抗实现
② 电力侧：历史 PMU 量测 → PV 运行点预测 → PV 导纳构建 → 被攻击 PV 导纳
③ 源-荷联合交互 → 临界特征值分析 → 攻击可达域 ARD（联合不确定性下）
④ 置信加权可攻击性得分 → 不确定性感知攻击时间窗
⑤ 不确定性感知攻击向量集
```

**关键技术要素**：

- **算力 → 功率的量化**：区分"用户请求的算力"$C_{\mathrm{off}}$ 与"实际执行的算力"$C(t) = \min\{C_{\mathrm{off}} + B_t/\Delta t,\; C n_t\}$。**这个 min 结构是最漂亮的一处建模**——它刻画了两种截然不同的电气后果：*有余量 → 立即功率爬坡；容量饱和 → 排队与延迟扩容的持续扰动*。
- **攻击强度参数化**：$\delta(u_{\mathrm{dc}}) \approx \eta_C \frac{T_a}{T_r}[r(A_w-1) + \rho_N A_b]$，其中 $A_w$ 是单请求工作量放大倍数、$\rho_N$ 是注入请求比。**$T_a$ 攻击者可控，$r, A_w, \rho_N, A_b$ 不可控** → 这正是"需求响应不确定性"的来源。
- **阻抗判据**：回路增益 $L(s) = Z_{\mathrm{eq}}(s)\tilde{Y}_{\mathrm{pv}}(s)$，闭环特征值由 $\det[I + L(\lambda_i)] = 0$ 给出（Middlebrook 型判据）。
- **★ 两个核心定义**（全文的 signature contribution）：
  - **ARD（攻击可达域）**：$\mathcal{D} = \{\lambda_{\mathrm{crit}}(a) \mid a \in \Omega_a\}$，投影到实轴后判是否与 $(0,\infty)$ 相交。
  - **不确定性感知攻击时间窗 / 攻击向量**：把"脆弱性"从**单点最坏情况**升级为**跨时间、跨不确定性的持续可达性**——用作者的话说，**"区分持续性脆弱与孤立的最坏情况"**。

**关键结果**：

| 结果 | 数值 |
|---|---|
| 仅逆变器侧攻击（5 参数在 5%/5%/5%/10%/10% 界内） | 最右特征值实部 **−0.341**（稳定） |
| 仅负荷侧攻击（AIDC 负荷 ±15%） | **−1.317**（稳定） |
| **协同攻击** | **+0.734**（**越界**） |
| 5 天 7,200 个 1 分钟点中"至少 1 个实现不稳定" | **4,726 个（65.64%）** |
| 但 $A_{t+\tau} \geq 0.9$（高置信可攻击） | **仅 41 个（0.569%）**，形成 **8 个连续窗口** |
| 时域验证：非关键窗口内攻击 | 逆变器频率 **49.79–50.65 Hz**（有界） |
| 时域验证：关键窗口内攻击 | **37.80–61.35 Hz**（峰偏 > 标称 20%），VSG 转子角 0.5 → 2.6 rad 持续振荡 |

> **"65.64% vs 0.569%"这个对比是全文最有价值的数字**：
> 只看"是否存在某个实现能致稳"，结论是"**大部分时间都危险**"；
> 一旦要求"**在置信加权意义下普遍可攻击**"，只剩 **0.569%**。
> **脆弱性高度集中在少数短窗口**——攻击者必须精确择时，防御者只需守住少数时段。**这对攻防双方都有强操作含义。**

**用实测数据推翻建模惯例（Fig. 3）**：

### 需要注意的三个疑点（不粉饰）

**疑点 1：协同效应没有被分解，交互项未量化。**
协同攻击集合 $\Omega_a$ 是两侧可行集的**乘积集**，因此协同 ARD **在构造上必然包含**两个单侧 ARD 的并集。论文报告的 +0.734 确实**超出**了并集（−0.341 与 −1.317 的并集全为负），所以协同效应**是真实的**；但论文**没有回答"超出多少来自物理耦合、多少来自取极值"**。**正确的做法是做双因素分解**（固定逆变器篡改，扫描负荷变化，看是否仅因负荷变化就使特征值变号）——**这是一处可以立刻补上、成本极低的分析**。

**疑点 2：小信号预测 vs 大信号结果，存在线性/非线性一致性缺口。**
预测框架是**线性小信号**的（回路增益 + 闭环特征值），但时域验证给出 **±12 Hz 的持续频率偏差**（标称的 ±24%）——**这远超小信号适用域，意味着微电网已彻底失步**。而且 Fig. 7 显示的是**等幅极限环**（非线性现象），而非线性预测的指数增长。二者的桥在理论上成立，但**论文没做任何衔接论证**。
**更实际的问题：保护装置被完全忽略。** 任何实际微电网的频率保护（典型定值 ±1~2 Hz）会在几十毫秒内切除，所以"±12 Hz 持续振荡"**隐含假设保护不动作或已失效**——论文没有说明这一点。

**疑点 3：算力 → 功率的映射链条过于简化，$\eta_C = 0.40$ 是薄弱环节。**
从"工作量"到"电功率"只经过**一个线性系数**。这忽略了三件真实数据中心里都很重要的事：**① 制冷功率非线性跟随 IT 功率（PUE 随负载率变化）；② UPS/PSU 效率曲线（低负载率时效率显著下降，会放大波动）；③ GPU 峰值功率受硬件上限约束**（论文自己在 Table II 承认了，但线性模型体现不出来）。**$\eta_C = 0.40$ 意味着"只有 40% 的基线功率对工作负载敏感"，没有任何来源或验证。**
> **这恰恰是线②中 `2609.22093`（DC-CLM）正在解决的问题**——把这段换成经过验证的数据中心功率模型，是一个**"低垂果实"式的改进**。

**自评 7.3 / 10**（问题重要性 9.0、方法创新 7.5、理论深度 6.5、实验严谨性 6.0、充分性 6.5、写作可复现 7.0、影响潜力 8.5）。
**判词**：**选题一流、框架一流、数据诚实（用实测阻抗推翻固定阻抗惯例）——但把最关键的两处（交互项分解、算力-功率映射）留成了黑箱。** 它最大的价值不在结论本身，而在于**示范了一条"把算力域攻击翻译成电力域稳定性语言"的完整路径**，并**留下了一个几乎空白的蓝队方向**。
