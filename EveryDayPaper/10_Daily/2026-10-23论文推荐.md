### 2.2 一句话讲清它做了什么

数据中心并网有两个诉求：**① 别把算力振荡漏到电网（隔离）；② 电网出事时按规范动作（支撑）**。现有论文要么只做①，要么只做②，要么两个都演示一遍但不说清边界。

这篇先问：**"这两个诉求同时能做到什么程度？"** 然后给出三个答案：

$$
\underbrace{A+E\ge1}_{\text{只测功率：互斥}}
\quad\xrightarrow{\text{加测 } v,f}\quad
\underbrace{\operatorname{rank}H=2}_{\text{源可分辨}}
\quad\xrightarrow{\text{但}}\quad
\underbrace{\int_0^\infty\!\ln|S_u|\,\mathrm d\omega=0}_{\text{跨频带必然有代价}}
$$

最后在这个边界内，用**凸优化 + 稳定性证书**设计了一个只用本地 $[p,v,f]$ 的储能控制器，在单机与 IEEE 九母线两个算例、13 个运行点上验证（其中 4 个运行点**不参与拟合**，是真正的留出集）。

### 2.3 为什么值得读（三条理由，按重要性排序）

**理由一：它把问题从"控制"重新摆到了"观测"的桌面上**

这是本篇唯一真正稀缺的东西。引言的倒数第二段是全篇的题眼：

> "Grid and server disturbances jointly affect the powers measured at the grid connection and within the data center, so those measurements **cannot automatically be treated as separate disturbance inputs**."

**并网点功率 $p$ 抖了，你无法从 $p$ 本身判断是里面服务器在闹、还是外面电网在抖。** 而这两种情况要求储能做**相反**的动作。

于是"隔离 vs 支撑"的冲突，本质不是"控制器带宽不够"，而是"**信息不够**"。这个转向的价值在于：它把一条死路（更聪明的控制器）换成了一条活路（**换量测 / 换观测方式**）。

**对做安全的同学，这句话应该格外刺耳**：这不就是"**在合法流量里区分正常业务与恶意行为**"的电力版本吗？只不过这里的"流量"是功率，"业务"是算力负载。

**理由二：它给出了两个可以直接借用的硬判据**

| 判据 | 形式 | 能干什么 |
|---|---|---|
| **源可辨识性** | $\operatorname{rank}H(j\omega)=2$，对 $y=[p,v,f]^{\mathsf T}$ 要求 $P_w\ne0$ 且 $G_g\ne0$ | 判断"我现在的量测够不够分开两个源"。**附赠一个否定结论**：测 $p$ 又测 $d$ 毫无用处（式 11：$d=p+u$，信息量相同） |
| **隔离–支撑互斥** | $A(\omega)+E(\omega)\ge|T_g^\star/P_g|$，响应保持时 $=1$ | 判断"我这个控制器的指标是不是自相矛盾"。**看到只报隔离指标不报支撑指标的论文，直接判它不合格** |

第二个判据的杀伤力在本期 Table III 里体现得淋漓尽致：**Power only 在九母线上的隔离指标 $A=0.0370$ 比 proposed 的 $0.0252$ 只差一点，但 $E_g=1.0019$（支撑彻底失效），13 个运行点 0 个通过。** 单看隔离指标会得出完全错误的结论。

**理由三：它无意中暴露了一个"缓解措施损害取证"的硬冲突**

这是本期我认为**最有价值**的东西，作者完全没意识到。

全文把 $w=\Delta P_{\text{dem}}$ 当良性随机扰动。但 Vault 已有的 `2607.05993`（Bit2Watt, CHES 2026）证明：**一个合法云租户用官方 API 就能把 GPU 功率调制成任意确定性波形。**

两篇一乘：

$$
\text{攻击者在电网侧的足迹}=A\cdot|P_w|\cdot|w|,\qquad A=0.0090
$$

**隔离控制器把攻击者的电气足迹压到了 0.9%。**

| 角色 | 想要什么 | 隔离控制器做了什么 |
|---|---|---|
| 数据中心运营方 | 不被投诉、不违反并网规范 | ✅ 完美达成 |
| **电网调度/取证方** | **看到异常、归因、追责** | ❌ **证据被系统性抹除** |
| 攻击者 | 制造扰动而不被发现 | ✅ **免费获得一个降噪器** |

更进一步：设计规范允许"带外泄漏 ≤2.8"（**280% 放大**），Fig. 4 的算例里 3 Hz 压到 11.2%、**47.71 Hz 放大到 2.195 倍**。控制器参数是固定的、可逆向的，**攻击者只需把调制频率搬到灵敏度峰上，就白拿 2.2–2.8 倍增益，而防御方还在看 $A$ 指标自我感觉良好。**

> **"你越认真地做缓解，取证就越不可能。"** 这个结论不需要任何新实验——只要把两篇论文的传递函数乘起来。

### 2.6 我的批判（六条，详见笔记 §7.1）

1. **"Fundamental limits" 名不副实**：定理 1 一行三角不等式，定理 3 教科书 Bode 积分。**真正的贡献是模型与问题提法，不是数学。** 用这个标题会拉高审稿人期待，反被质疑。
2. **源可辨识性只给了代数条件，没给数值条件**：强网（$G_g$ 小）或深隔离（$P_w$ 被压小）时 $H$ 满秩但**病态**，$\kappa(H)$ 可达 $10^2$–$10^3$，此时"代数可分辨"毫无实践意义。作者只提了一句"保持良态"，**没有条件数阈值、没有噪声敏感性分析**。→ **这是最容易补的一篇 Letters。**
3. **无时延、无 SoC/爬坡、无噪声蒙特卡洛**：作者承认了前两者的 future work，但**通信时延连提都没提**，而 `[19]` 专门研究过时延。1–20 Hz 隔离带的相位裕度对 5–10 ms 时延极其敏感，**这是实机上最可能翻车的地方**。
4. **基线公平性判据偏弱**：只按"状态数相同"比较，比较器全是 SISO 工程结构 + 一个 power-only。**缺 H∞/μ 或 MIMO LQG 这类"同信息集下的最优"基线**。若 proposed 与 H∞ 差距很小，贡献就退化为"用了凸优化而非 Riccati"。
5. **$T_g^\star$ 是自己定的**：由 grid-only 搜索在点 1–5 上把阻尼比从 5.91%/15.06% 调到 10.71%/18.71%，然后冻结。所以"meets prescribed response"是相对**自定目标**成立，不是相对 IEEE 2800 / GB/T 19964 这类真实并网规范。
6. **纯离线仿真，无 HIL**：只有 MATLAB `ode15s` + CVXPY。对比 `2608.06521`（OPAL-RT）、`2610.12730`（OPAL-RT HIL）、Bit2Watt（三级硬件验证），**实证强度明显不足**。加上单作者、未标注单位，外部无法核实。

### 3.1 ★★★ 第一关联：`2610.26480` —— 同日的"另一半"

| 项 | 内容 |
|---|---|
| **标题** | Does Synchrophasor Attenuation Preclude Detection of High-Frequency Oscillations? |
| **arXiv** | [`2610.26480`](https://arxiv.org/abs/2610.26480) |
| **作者** | Chetan Mishra, Jaime Delaree Jr., **Kevin D. Jones**（**Dominion Energy**）；**Luigi Vanfretti**（RPI） |
| **提交** | **2026-10-19**（与主推同日）；eess.SP；3 页 / 15,280 字符；**投稿 IEEE Power Engineering Letters** |

**它说了什么**：近年有工作认为"标准同步相量抓不住数据中心高频振荡，因为 DFT 相量估计的滤波与加窗会衰减幅度"。这篇证明：**这个担心对检测器基本不成立。**

核心推导只有两步：

1. DFT 窗把真实幅度周期图按 $|\hat g(f)|^2$ 缩放：$I_N^{A_p}(f_i)\approx|\hat g(f_i)|^2I_N^{A}(f_i)$；
2. 对**周期图检测器**，比较"有振荡/无振荡"时这个因子**上下约掉** ⇒ AUC 完全不变（除非恰好落在窗的谱零点）；对 **RMS 能量检测器**，性能只取决于**相对**衰减比 $\beta_i^2=|\hat g(f_i)|^2/|\hat g(f_o)|^2$，窄带即可恢复。

**数值验证**（200 次蒙特卡洛，60 s 窗，六周期 boxcar，10 Hz 谱零点）：

- 周期图检测器：**4 Hz 以上衰减明显，但检测概率不降**；唯一例外是 10 Hz（窗零点），检测概率掉到 $\alpha=0.1$；
- RMS 检测器（$B=(1,15)$ Hz）：$A_o=0.01$ 时性能大致跟随 $|\hat g(f)|$——**8 Hz 检测概率 <20%，6 Hz 近 70%**；但换成窄带（即周期图）后，同样 8 Hz 检测概率 ≈100%、AUC ≈1。
