# LLaTSA: Large Language Model-Aligned General-Purpose Transient Stability Analysis

> **arXiv**: [2609.14374](https://arxiv.org/abs/2609.14374) ｜ **提交日期**: 2026-09-13 ｜ **分类**: eess.SY; cs.AI ｜ **作者**: Chao Shen, Hongwei Zhen, Junyan Shao, Zhenghao Yang, Yifan Zhang, Mingyang Sun

---

## 一、研究背景与问题

**暂态稳定分析（Transient Stability Analysis, TSA）** 是电力系统安全评估的核心任务：判断系统在遭受扰动（短路、切机、断线）后能否恢复同步运行。

近年来，**基于动态轨迹预测的 TSA** 成为数据驱动的主流范式 —— 用神经网络预测故障后的发电机转子角/转速轨迹，再据此判别稳定性。但这一范式存在**根本性缺陷**：

> **现有预测器几乎都是"系统专用"的**。一旦网络拓扑改变、发电组合变化、或状态变量集合不同，模型就必须**重新训练**。这在实际电网中不可接受 —— 拓扑每天都在变（检修、开关操作、新能源投退）。

**已有尝试**：Uni-TSA 引入了"通用 TSA 框架"，结合**通道独立建模**与**预训练大语言模型（LLM）预测器**。但作者指出 Uni-TSA 仍有四个瓶颈：

| 瓶颈 | 具体表现 |
|---|---|
| **短观测歧义** | 观测窗口短时，轨迹含义不明确，缺少上下文 |
| **数值—语义错配** | 数值型轨迹与 LLM 的词嵌入空间不匹配 |
| **状态变量解耦** | 忽略了状态变量之间的物理耦合（如转子角与转速强耦合） |
| **推理成本高** | 稠密骨干网络（dense backbone）推理代价大 |

## 二、系统模型与问题表述

**任务定义**：给定故障后的**短时观测轨迹** $\mathbf{X}_{1:T_{obs}}$（各发电机状态变量的时序），预测**长时程轨迹** $\hat{\mathbf{X}}_{T_{obs}+1:T_{pred}}$，进而判别系统稳定性。

**关键挑战的形式化**：
- **跨系统泛化**：训练系统与测试系统的发电机数量、拓扑、参数均可不同
- **异构状态变量**：不同系统的状态变量集合不同（如是否含励磁、调速器状态）
- **长时程误差累积**：自回归预测的漂移问题

## 三、方法 / 技术路线

LLaTSA 是 **LLM 对齐（LLM-aligned）** 的通用轨迹式 TSA 框架，四个核心组件：

### 3.1 结构化文本前缀（解决"短观测歧义"）

在数值轨迹之前注入**结构化文本描述**，包含三类上下文：

1. **运行工况（operating conditions）** —— 负荷水平、发电出力
2. **扰动属性（disturbance attributes）** —— 故障类型、位置、持续时间
3. **状态变量身份（state-variable identity）** —— 每个通道对应的物理量

> 这相当于给 LLM 一个"prompt"，让它知道自己在看什么物理量，而不仅仅是一串数字。

### 3.2 数值 patch 与 TSA 词表对齐（解决"数值—语义错配"）

- 将归一化后的时序轨迹切成 **patches**
- 把每个 patch 对齐到 **TSA 相关词表（TSA-related vocabulary）** 的嵌入空间
- 使数值序列可以在 LLM 的离散 token 空间中表示

### 3.3 稀疏 MoE 骨干（解决"推理成本高"）

- 采用**预训练的稀疏 decoder-only 混合专家（MoE）** 骨干网络
- 相比稠密骨干，MoE 在推理时只激活部分专家，**大幅降低计算量**
- 保留 LLM 预训练获得的时序建模能力

### 3.4 状态变量耦合模块（解决"状态变量解耦"）

- 显式建模**故障后状态变量的协同演化**（coordinated post-fault evolution）
- 弥补通道独立建模忽略的物理耦合

### 3.5 训练策略：Teacher Forcing + Rollout

- **Teacher forcing**：训练时用真实历史作为输入，稳定早期训练
- **Rollout-based training**：模拟推理时的自回归过程，缓解**长时程误差累积**

> 两种策略结合，既有 teacher forcing 的稳定性，又有 rollout 对推理分布的适配。

## 四、关键创新点

1. **结构化文本前缀注入物理上下文**：把运行工况、扰动属性、变量身份显式编码，让 LLM 真正"理解"电网物理语义，而非盲目拟合数值。

2. **TSA 专用词表对齐**：解决了数值轨迹与 LLM 离散嵌入空间之间的鸿沟 —— 这是把 LLM 用于连续物理系统的关键障碍。

3. **稀疏 MoE 骨干替代稠密网络**：在保持表达能力的同时显著降低推理成本，使在线 TSA 更可行。

4. **状态变量耦合建模**：显式捕捉故障后变量间的协同演化，符合电力系统物理规律。

5. **通用性验证**：在**多个测试系统**上验证了跨系统适配能力 —— 这是相对于系统专用预测器的最大价值。

## 六、对电网安全领域的意义

### 直接价值

1. **解决 TSA 落地的最大障碍 —— 泛化性**。电网拓扑与运行方式时刻变化，"换系统就重训"的模型在工程上不可用。LLaTSA 的通用性直接对应这一痛点。

2. **LLM 进入电力核心分析任务的标志性工作**。此前 LLM 在电力系统的应用多集中在问答、文档处理等外围任务；LLaTSA 把它推进到了**暂态稳定判别**这一安全核心。

3. **效率与精度的平衡**。MoE 稀疏化让推理成本可控，对在线安全评估（需秒级甚至更快响应）有实际意义。

### 方法迁移潜力

- **动态安全评估（DSA）**：同样的轨迹预测范式可扩展到电压稳定、频率稳定
- **新能源高比例场景**：逆变器主导的系统轨迹特征不同，通用框架的适配能力尤为关键
- **故障后控制决策**：轨迹预测可衔接紧急控制策略生成

### 需要谨慎之处

- **物理可解释性弱**：LLM 黑箱 + MoE 路由，稳定判别的可解释性差于传统能量函数法
- **安全关键任务的可靠性**：暂态稳定误判代价极高，需严格的置信度与拒识机制
- **对训练数据的依赖**：通用性建立在大量多系统仿真数据之上，实际电网数据获取困难
- **实时性待验证**：MoE 虽比稠密骨干快，但是否满足在线 TSA 时限需实测
