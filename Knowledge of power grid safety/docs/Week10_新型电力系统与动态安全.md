# 📓 第 10 周 · 新型电力系统与动态安全

> **本周目标**：理解**电网正在发生的结构性变化**，以及这些变化如何**重新定义攻击面**。
>
> **为什么安全研究者必须跟上这个变化**：
> 传统电网安全研究假设"有同步机、有惯量、通信只用于监视"。
> 而新型电力系统里，**电源是软件定义的、惯量靠控制合成、通信是控制回路的一部分**。
> 这意味着一大批**传统研究没覆盖过的新攻击面**。

## Day 68 · 09:00 —— 新能源接入：当电网由逆变器主导

> **一句话**：**风电光伏通过电力电子逆变器并网，它们"不转、不惯、不主动供无功"**——这三点改变了电网的物理本质。

### 一、两种截然不同的并网方式

| 类型 | 代表 | 并网接口 | 关键特性 |
|---|---|---|---|
| **同步机型电源** | 火电、水电、核电 | **直接并网**（转子与电网同步） | 自带惯量、自带阻尼、天然供无功 |
| **逆变器型电源** | 风电、光伏、储能 | **电力电子变流器** | 无惯量、需控制、通常不供无功 |

> 💡 **本质区别**：同步机的转子**物理上**和电网"绑在一起"；逆变器则是**用软件模拟**出与电网的连接。

### 二、逆变器型电源的三个"不"

| # | 特征 | 物理原因 | 后果 |
|---|---|---|---|
| ① | **不转** | 没有旋转质量 | 无动能储备 |
| ② | **不惯** | 频率变化时不能自动释放动能 | **惯量下降** |
| ③ | **不主动供无功** | 默认单位功率因数运行 | 电压支撑弱 |

### 三、为什么惯量这么重要

$$\frac{df}{dt} = \frac{\Delta P}{2H}$$

| $H$（惯量常数） | $\Delta P$ 相同时的 $df/dt$ | 留给调频的时间 |
|---|---|---|
| 大（传统电网，$H \approx 5$ s） | 小 | 多（数十秒） |
| 小（新能源电网，$H \approx 1.5$ s） | **大 3 倍以上** | **少（几秒）** |

**惯量下降 = 频率变化更快 = 留给调频动作的时间更短。**

### 四、中国的新能源格局（背景）

| 维度 | 现状 |
|---|---|
| 装机占比 | 风光装机已超总装机的 **50%** |
| 发电量占比 | 约 15~20%（受出力波动限制） |
| 布局 | 西北/华北**集中式**基地 + 中东部分布式 |
| 输电 | 特高压直流外送（"西电东送"） |

### 五、安全含义：四个层面的变化

| 变化 | 直接后果 | 安全影响 |
|---|---|---|
| **惯量下降** | 频率稳定裕度下降 | 小扰动即可造成大频率偏差 |
| **无功支撑弱** | 电压稳定裕度下降 | 电压崩溃风险上升 |
| **控制依赖通信** | 控制回路跨网络 | **通信攻击直接转化为物理后果** |
| **设备软件化** | 逆变器有固件 | **新攻击面**：固件篡改、参数篡改 |

### 🔗 与网安研究关联

**这是"攻击面迁移"的典型案例**：

```
传统电网的攻击面：      物理设备 + 监控通信（只读为主）
                ↓
新型电力系统的攻击面：  物理设备 + 控制通信（读写）+ 固件 + 控制算法
```

| 新攻击面 | 说明 | 对接实验室方向 |
|---|---|---|
| **逆变器固件** | 可被植入后门/篡改参数 | 程序逆向 / 固件安全 |
| **控制指令通道** | 通信攻击 → 直接物理后果 | 入侵检测 |
| **控制算法** | 参数篡改 → 诱发振荡 | AI安全 / 时序检测 |
| **海量分布式设备** | 攻击面数量级增加 | 大规模IDS |

> 💡 **一个重要的研究直觉**：
> 传统电网里，攻击者要"打进物理层"很难（隔离装置、专网）。
> 新型电力系统里，**成千上万台逆变器分布在用户侧** ——
> 攻击者可以从**最边缘、防护最弱**的地方入手。

2. 如果攻击者同时控制大量分布式光伏逆变器，能造成什么后果？（提示：想想惯量）

## Day 68 · 14:00 —— 电力电子化电网的稳定性新问题：宽频振荡

> **一句话**：**逆变器控制器的快速动态引入了传统电网从未有过的"宽频振荡"**——从几 Hz 一直延伸到几千 Hz。

### 一、振荡类型的谱系（一张表看懂）

| 类型 | 频率范围 | 主导机理 | 时代 |
|---|---|---|---|
| **低频振荡** | 0.1 ~ 2.5 Hz | 机电（转子角） | 传统 |
| **次同步振荡** | 5 ~ 50 Hz | 机电-电气耦合（串补） | 传统 |
| **次/超同步振荡** | 数十 Hz | **逆变器控制 × 电网阻抗** | 新型 |
| **宽频振荡** | 几 Hz ~ 数千 Hz | **多控制器交互** | 新型 |

> 💡 **关键认知**：传统振荡源于**机械惯性**（秒级）；新型振荡源于**控制带宽**（毫秒级）。
> 两者的**时间尺度差了两个数量级** —— 所以传统分析方法完全不够用。

### 二、两个标志性事件

| 事件 | 时间 | 现象 | 教训 |
|---|---|---|---|
| **新疆哈密次同步振荡** | 2015 | 风电场与串补线路耦合振荡，大量风机脱网 | 逆变器会与电网"共振" |
| **英国 8·9 大停电** | 2019 | 雷击后分布式电源连锁脱网，频率跌至 48.8 Hz | 逆变器**不会**像同步机那样"撑住" |

### 三、机理：为什么逆变器会诱发振荡

```
逆变器控制带宽很高（毫秒级响应）
        ↓
控制器试图快速跟踪指令
        ↓
与电网阻抗（尤其弱电网、高阻抗）形成**负阻尼**
        ↓
小扰动被放大 → 持续振荡
        ↓
保护动作 → 大量电源脱网 → 连锁
```

**"弱电网"是关键词**：新能源基地常在电网末端，短路容量小 → 阻抗大 → 极易振荡。

### 四、为什么传统方法失效

| 维度 | 机电暂态仿真 | 电磁暂态仿真 |
|---|---|---|
| 步长 | 10 ms | **1 ~ 50 μs** |
| 仿真 1 秒需要 | 100 步 | **20,000 ~ 1,000,000 步** |
| 适用 | 传统稳定 | 新型振荡 |

**计算量爆炸 1000 倍以上** —— 这就是新型电力系统仿真难的根本原因。

### 五、检测难点

| 需求 | 传统 SCADA | PMU | 宽频测量 |
|---|---|---|---|
| 采样率 | 2 s | 30~60 帧/s | 数千 Hz |
| 能看到 0.5 Hz？ | ❌ | ✅ | ✅ |
| 能看到 500 Hz？ | ❌ | ❌ | ✅ |

> ⚠️ **结论**：**要检测宽频振荡，传统量测体系完全不够** —— 这既是挑战，也是研究机会。

### 🔗 与网安研究关联

| 攻击思路 | 原理 | 隐蔽性 |
|---|---|---|
| **篡改逆变器控制参数** | 把阻尼参数改小 → 诱发振荡 | **极高** |
| **伪造阻抗估计** | 让控制器误判电网强度 | 高 |
| **同步扰动多台逆变器** | 放大振荡能量 | 高 |

**与 Day 64 的"阻尼比攻击"是同一思路的延伸**：

```
Day 64：攻击状态估计 → 让调度员看不到阻尼比下降（稳态层面）
Day 68：攻击逆变器参数 → 直接让阻尼变负（控制层面）
```

> 💡 **选题灵感**：
> 「**面向逆变器控制参数的隐蔽篡改检测：基于宽频量测与图注意力**」
> - 攻击模型：直接改控制参数，绕过所有基于稳态残差的检测
> - 检测思路：宽频量测 + 逆变器之间的**空间相关性**（同一区域多台同时异常 = 强信号）
> - 这正是 GNN 的用武之地（设备是图的节点）

### 🔍 延伸思考

1. 攻击者需要什么能力才能篡改逆变器控制参数？（考虑物理接触 vs 远程）
2. 检测宽频振荡最少需要什么量测条件？为什么 PMU 也不够？

## Day 69 · 09:00 —— 储能系统与构网型（Grid-forming）控制

> **一句话**：**储能是新型电力系统的"缓冲器"**，而构网型控制让它能像同步机一样**主动撑住**电网。

### 一、储能技术谱系

| 类型 | 放电时长 | 响应速度 | 主要用途 |
|---|---|---|---|
| **抽水蓄能** | 小时 ~ 天 | 分钟级 | 大规模调峰、削峰填谷 |
| **锂电池** | 分钟 ~ 小时 | **毫秒级** | 调频、调峰、备用 |
| **飞轮** | 秒 ~ 分钟 | 毫秒级 | 快速调频 |
| **压缩空气** | 小时 | 分钟级 | 调峰 |
| **超级电容** | 秒 | 毫秒级 | 电能质量、瞬时支撑 |

> 💡 **选型逻辑**：**能量型**（抽蓄、锂电）看"能存多少"；**功率型**（飞轮、超容）看"能出多快"。

### 二、储能在电网中的三种角色

| 角色 | 说明 | 收益来源 |
|---|---|---|
| **① 能量搬移** | 低谷充电、高峰放电 | 峰谷价差套利 |
| **② 快速调频** | 参与 AGC，秒级响应 | 调频辅助服务市场 |
| **③ 惯量支撑** | 构网型控制提供合成惯量 | 容量补偿 / 政策要求 |

### 三、跟网型 vs 构网型（核心对比）

| 维度 | **跟网型**（Grid-following） | **构网型**（Grid-forming） |
|---|---|---|
| **电气本质** | 电流源 | **电压源** |
| 能否独立建立电压 | ❌ 不能 | ✅ 能 |
| 是否依赖锁相环（PLL） | ✅ **强依赖** | 弱依赖 |
| 惯量提供 | ❌ 无 | ✅ **可合成** |
| 弱电网适应性 | ❌ 差（易振荡） | ✅ 好 |
| 典型控制 | PQ 控制、电流控制 | 下垂控制、**虚拟同步机（VSG）** |
| 类比 | 跟着电网走的"乘客" | 能撑起电网的"支柱" |

### 四、为什么必须转向构网型

```
高比例新能源接入
        ↓
同步机减少 → 电网变"弱"（短路容量下降、阻抗上升）
        ↓
跟网型逆变器在弱电网下**负阻尼 → 振荡 → 脱网**
        ↓
必须用构网型主动建立电压/频率
```

### 五、储能系统的三层攻击面（安全重点）

```
┌─────────────────────────────────────────┐
│  EMS 能量管理系统                        │  ← 层 3：调度指令
│  （决定充放电计划、参与市场）             │     攻击：篡改指令
└────────────────┬────────────────────────┘
                 │ 通信（Modbus/IEC 61850/私有协议）
                 ↓
┌─────────────────────────────────────────┐
│  PCS 变流器控制系统                      │  ← 层 2：控制参数
│  （执行功率指令、控制电压/频率）           │     攻击：篡改 J/D 参数
└────────────────┬────────────────────────┘
                 │ 内部通信（CAN/RS485）
                 ↓
┌─────────────────────────────────────────┐
│  BMS 电池管理系统                        │  ← 层 1：电池状态
│  （监测 SOC/SOH/温度、保护）              │     攻击：虚报 SOC
└─────────────────────────────────────────┘
```

| 层 | 典型攻击 | 后果 | 检测难度 |
|---|---|---|---|
| **EMS** | 篡改充放电计划 | 经济/安全损失 | 中 |
| **PCS** | 篡改控制参数 | **直接影响稳定性** | **高** |
| **BMS** | 虚报 SOC/SOH | 实际无电却以为有电 | **高** |
| **通信** | 中间人、重放 | 任意篡改 | 中 |

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **三层皆可攻** | 且三层的检测方法完全不同（指令异常 / 参数异常 / 状态异常） |
| **BMS 虚报是典型 FDIA** | 虚报 SOC 相当于"伪造状态"，与传统 FDIA 同构 |
| **PCS 参数篡改是新型攻击** | 没有网络异常、没有残差变化，**传统 IDS 完全失效** |
| **对接实验室方向** | 固件安全（BMS/PCS 固件）+ 入侵检测（通信）+ AI安全（参数异常） |

> 💡 **一个非常值得做的选题**：
> 「**储能系统 BMS 虚假数据注入攻击的检测：从单体电压相关性入手**」
> - 电池组内**单体之间**有强物理相关性（同批次、同温度、同老化）
> - 攻击者篡改某个单体的电压/温度读数，会**破坏这种相关性**
> - 这正好是 GNN 的用武之地（单体是图的节点，相关性是边）

### 🔍 延伸思考

1. 如果攻击者让 BMS **虚报 SOC**（实际 20%，上报 80%），在调频场景下会有什么后果？
2. 储能电站通常无人值守，物理攻击和网络攻击哪个更现实？

## Day 69 · 14:00 —— 虚拟同步机（VSG）：用软件"造"一台发电机

> **一句话**：**VSG 在逆变器控制器里跑一个发电机模型**，让没有转子的逆变器表现出惯量和阻尼。

### 一、核心思想

```
逆变器物理上：没有转子 → 没有惯量
        ↓
在控制器里"虚拟"一个转子方程
        ↓
让它表现出与同步机相似的动态响应
```

**本质上：用软件把"同步机的物理特性"复现出来。**

### 二、VSG 的核心方程（虚拟摇摆方程）

$$J\frac{d\omega}{dt} = \frac{P_{\text{ref}} - P_e}{\omega} - D(\omega - \omega_{\text{grid}})$$

| 符号 | 含义 | 物理类比 |
|---|---|---|
| $J$ | **虚拟惯量** | 转子转动惯量 |
| $D$ | **虚拟阻尼** | 阻尼绕组 |
| $P_{\text{ref}}$ | 功率参考值 | 汽轮机出力指令 |
| $\omega$ | 虚拟角频率 | 转子角速度 |

> 注意：这个方程**和 Day 65 的真实摇摆方程长得一模一样** —— 这就是 VSG 名字的由来。

### 三、控制结构

```
P_ref ──┐
        ├──→ [虚拟转子方程] ──→ δ ──→ [电压合成] ──→ PWM ──→ 逆变器
P_meas ─┘         ↑
                  │
                 ω（虚拟转速）
                  ↑
              [频率下垂] ←── ω_grid
```

### 四、VSG 的两个关键参数（安全核心）

| 参数 | 作用 | 调太大 | 调太小 |
|---|---|---|---|
| **$J$（虚拟惯量）** | 提供频率支撑 | 响应迟钝、易振荡 | 支撑不足 |
| **$D$（虚拟阻尼）** | 抑制振荡 | 响应慢 | **振荡不止** |

**工程上这两个参数的整定本身就是一个难题** —— 而它们**都是软件里的数字**。

### 五、VSG 的工程挑战

| 挑战 | 说明 |
|---|---|
| 参数整定 | 与电网阻抗强耦合，难以通用 |
| 多机并联交互 | 多台 VSG 之间可能互相激励 |
| 计算负担 | 需要实时求解微分方程 |
| 与跟网型混联 | 混合系统的稳定性分析复杂 |

### 六、安全含义（本周最重要的洞察）

$$\boxed{\text{稳定性参数变成了软件变量} \Longrightarrow \text{攻击面从"物理"迁移到"参数"}}$$

| 攻击方式 | 手段 | 检测难度 |
|---|---|---|
| **篡改 $J$** | 改一个数字 | **极高** |
| **篡改 $D$** | 改一个数字 | **极高** |
| **篡改下垂系数** | 改变功率分配 | 高 |
| **篡改 P_ref** | 改变出力指令 | 中 |

**为什么检测难？**

```
❌ 没有网络异常（可能是合法配置修改）
❌ 没有残差变化（状态估计完全正常）
❌ 没有量测异常（量测都是真实的！）
✅ 只有"系统动态响应"变了 —— 而这需要高频量测才能看到
```

### 🔗 与网安研究关联

**这是"控制层攻击"的典范，也是传统 IDS 的盲区**：

| 传统 IDS 看什么 | VSG 参数攻击留下什么 |
|---|---|
| 网络流量异常 | 无 |
| 协议违规 | 无 |
| 量测残差 | 无 |
| 物理约束违反 | 无（稳态完全合法） |

> 💡 **研究机会**：
> 「**基于系统辨识的 VSG 参数篡改检测**」
> - 思路：持续辨识系统的实际动态特性（$J$, $D$），与"配置应该是什么"比对
> - 难点：需要**激励信号**（系统不能一直稳态）
> - 结合点：可以用 **PMU 时序 + 图神经网络**（多台 VSG 的空间相关性）
>
> 这条路线把「工业AI」「入侵检测」「时序异常检测」三个方向缝在一起。

2. 如果**多台 VSG 同时**被改，能否从"系统整体响应"上发现异常？（这是图方法的用武之地）

## Day 70 · 09:00 —— 微电网与孤岛运行：电网的"细胞"

> **一句话**：**微电网是"能自己活下来的小电网"**——孤岛运行是它的核心能力，也是最危险的运行状态。

### 一、微电网的构成

```
┌─────────────────── 微电网 ───────────────────┐
│                                              │
│  ┌────────┐  ┌────────┐  ┌────────┐          │
│  │ 光伏   │  │ 风机   │  │ 储能   │  分布式电源 │
│  └───┬────┘  └───┬────┘  └───┬────┘          │
│      └───────────┴───────────┘               │
│                  │                            │
│          ┌───────┴────────┐                   │
│          │  微电网控制器   │ ← 大脑            │
│          │  (MGCC)        │                   │
│          └───────┬────────┘                   │
│                  │                            │
│      ┌───────────┴───────────┐                │
│      │      负荷            │                │
│      └──────────────────────┘                │
│                  │                            │
└──────────────────┼───────────────────────────┘
                   │
            ┌──────┴──────┐
            │  PCC 并网点 │  ← 与大电网的接口
            └──────┬──────┘
                   │
            大电网（主网）
```

### 二、两种运行模式

| 模式 | 频率/电压由谁支撑 | 控制难点 | 能否用跟网型 |
|---|---|---|---|
| **并网模式** | 大电网 | 功率分配、潮流方向 | ✅ 可以 |
| **孤岛模式** | **微电网自己** | 必须建立电压/频率基准 | ❌ 必须构网型 |

### 三、模式切换：最危险的时刻

| 切换方向 | 触发 | 技术难点 |
|---|---|---|
| **并网 → 孤岛** | 大电网故障 | 快速检测 + 无缝切换（不断电） |
| **孤岛 → 并网** | 大电网恢复 | **同步**：频率、相位、幅值必须匹配 |

> ⚠️ **非同步并网 = 短路事故**。相位差太大时合闸，会产生巨大的冲击电流。

### 四、孤岛检测：一个经典的矛盾

| 方法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **被动法** | 监测 $f$、$V$ 是否越限 | 简单、无扰动 | 功率匹配时**检测不到** |
| **主动法** | 注入微小扰动，看响应 | 灵敏度高 | 影响电能质量、可能误动 |

**核心矛盾**：**检测速度 vs 误动作**。慢了危险，快了误切。

### 五、微电网的安全含义

| 特点 | 安全后果 |
|---|---|
| **保护配置复杂** | 双向潮流 → 传统单向保护失效 |
| **通信依赖强** | 协调控制全靠通信 |
| **无人值守** | 物理安全弱 |
| **边缘设备多** | 攻击面大、防护弱 |
| **并网点是咽喉** | 单点失效影响整体 |

### 六、典型攻击场景

| 攻击目标 | 手段 | 后果 |
|---|---|---|
| **孤岛检测** | 伪造电网状态 → **拒绝孤岛** | 大电网故障时被拖垮 |
| **模式切换** | 篡改切换指令 | 非同步并网 → 设备损坏 |
| **通信** | DoS | 失去协调 → 各自为战 |
| **DER 设备** | 批量篡改 | 影响大电网 |

> 💡 **反直觉但重要**：**"拒绝孤岛"（该切不切）通常比"误切孤岛"更危险**。
> 因为前者会让微电网在**主网故障时继续挂在故障电网上**，可能被一起拖垮，
> 甚至向故障点倒送电流，危及检修人员。

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **微电网是"边缘战场"** | 防护弱、数量多、但后果真实 |
| **孤岛检测攻击是独特研究点** | 传统电网没有这个问题 |
| **攻击放大器** | 一个微电网控制器被控 → 影响一片负荷 |
| **对接实验室方向** | 入侵检测（边缘 IDS）+ 固件安全（控制器）+ 智能体（自主决策） |

> 💡 **选题灵感**：
> 「**微电网孤岛检测的欺骗攻击与防御**」
> - 攻击：伪造 PCC 处的电压/频率，让孤岛检测器误判"大电网正常"
> - 防御：多源信息交叉验证（本地量测 + 邻近微电网 + 主网广播）
> - 新意：这是**跨微电网协同**的安全问题，可以用图建模

### 🔍 延伸思考

1. 为什么"拒绝孤岛"比"误切孤岛"更危险？从人身安全和设备安全两个角度想。
2. 微电网的通信被 DoS 后，**本地控制**能否兜底？能撑多久？

## Day 70 · 14:00 —— 需求响应与负荷侧灵活性：把调度权延伸到千家万户

> **一句话**：**需求响应让"用电"也能被调度**——但这把调度权延伸到了千家万户，攻击面随之爆炸。

### 一、需求响应的类型

| 类型 | 触发信号 | 响应时间 | 用户参与方式 |
|---|---|---|---|
| **价格型（PBR）** | 电价信号 | 小时 ~ 天 | 用户自主决策 |
| **激励型（IBR）** | 补偿/奖励 | 分钟 ~ 小时 | 签约响应 |
| **直接负荷控制（DLC）** | 调度**直接控制** | 秒 ~ 分钟 | 授权被控 |
| **自动需求响应（ADR）** | 自动执行 | **秒级** | 系统自动 |

> 💡 **注意 DLC 和 ADR**：它们是**调度直接控制用户设备**，攻击价值最高。

### 二、可调负荷资源

| 资源 | 可调量 | 响应特性 |
|---|---|---|
| **空调** | 温度设定微调 | 量大、响应快、用户无感 |
| **电热水器** | 加热时段 | 储能特性好 |
| **电动汽车** | 充电时段/功率 | **潜力最大**（未来） |
| **工业负荷** | 生产排程 | 量大但影响生产 |
| **数据中心** | 非关键任务延后 | 响应快、技术成熟 |

### 三、虚拟电厂（VPP）：把碎片聚合起来

```
  [空调]  [热水器]  [EV]  [储能]  [工业负荷]
     │       │       │      │        │
     └───────┴───────┴──────┴────────┘
                    │
          ┌─────────┴──────────┐
          │  VPP 聚合控制平台   │  ← ★ 单点！
          └─────────┬──────────┘
                    │
             参与电力市场 / 提供辅助服务
```

**VPP 的价值**：把分散的小资源聚合成一个"大电源"，可以参与调频、备用市场。

**VPP 的脆弱性**：**聚合平台是单点** —— 攻破它，等于控制了几十万台设备。

### 四、技术基础

| 环节 | 技术 | 安全弱点 |
|---|---|---|
| 感知 | AMI 智能电表 | 可被篡改、可被批量控制 |
| 通信 | 公网/无线/PLC | 易被干扰、DoS |
| 聚合 | VPP 平台 | **单点失效** |
| 执行 | 用户侧网关 | 固件可被植入后门 |

### 五、安全含义：攻击面的数量级跃升

| 传统电网 | 需求响应场景 |
|---|---|
| 攻击面：几百个变电站 | 攻击面：**几百万台终端** |
| 防护：专网 + 隔离装置 | 防护：**公网 + 家用设备** |
| 后果：局部停电 | 后果：**全网频率波动** |

### 六、最危险的场景：负荷侧的协同 DoS

```
攻击者控制 VPP 平台（或批量控制智能电表）
        ↓
在某一时刻同时：
    · 切除 10 万台空调
    · 或投入 5 万辆 EV 充电
        ↓
瞬时功率缺额/过剩达 GW 级
        ↓
频率剧烈波动
        ↓
低频/高频减载动作 → 连锁停电
```

> ⚠️ **这本质上是"用负荷做 DoS 攻击"** —— 而且**不需要篡改任何量测**，
> 传统 BDD、状态估计、FDIA 检测方法**全部失效**，因为它们检测的是"数据"不是"行为"。

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **攻击面爆炸** | 从"几百"到"几百万"，防护水平断崖式下降 |
| **单点放大** | VPP 平台 = 攻击放大器 |
| **检测范式变化** | 不是"数据异常"而是"**行为异常**" → 需要行为建模 |
| **对接实验室方向** | 入侵检测（海量终端）+ 智能体（自主协调）+ 假消息（价格信号伪造） |

> 💡 **一个前沿选题**：
> 「**面向 VPP 聚合调度的异常行为检测：从"数据一致"到"行为合理"**」
> - 传统方法查"数据对不对"，新方法查"行为合不合理"
> - 例如：10 万台空调在同一秒响应同一指令 → 这在物理上"合法"但**统计上极不合理**
> - 用**时空聚类 + 异常检测**可以发现这种"过于同步"的行为
> - 这个思路和"假消息检测"（识别异常传播模式）是相通的

2. 如何区分"正常的集中响应"（如调频指令）和"攻击性的同步动作"？

## Day 71 · 09:00 —— 频率动态与惯量下降：电网的"心跳"变快了

> **一句话**：**惯量是电网频率的"缓冲垫"**——新能源替代同步机后缓冲垫变薄，频率变化越来越快。

### 一、为什么频率是"全网唯一"的公共量

所有同步机**转速相同** → 电气频率相同 → 频率是全网的**公共信号**。

| 含义 | 说明 |
|---|---|
| 好处 | 一个量就能反映全网功率平衡 |
| 坏处 | **一处失衡，全网可见** |
| 安全含义 | 频率是攻击最容易"做大"的突破口 |

### 二、频率动态的三个阶段

```
频率 f
│
50.0 ─●─────────────────────────────  ← 稳态
      │╲
      │ ╲  ① 惯量响应（0~5 s）
      │  ╲   转子释放动能，靠"物理"
      │   ╲
      │    ╲___
      │        ╲___  ② 一次调频（5~30 s）
      │            ╲___  调速器动作，靠"控制"
      │                ╲___
      │                    ╲___ ③ 二次调频（AGC，30 s~分钟）
      │                        ╲____
49.5 ─┼───────────────────────────────────
      └───────────────────────────────→ t
```

| 阶段 | 时间 | 主导机制 | 是否依赖通信 |
|---|---|---|---|
| **① 惯量响应** | 0 ~ 5 s | 转子动能（**物理**） | ❌ 不依赖 |
| **② 一次调频** | 5 ~ 30 s | 调速器（**本地控制**） | ❌ 不依赖 |
| **③ 二次调频** | 30 s ~ 分钟 | AGC（**远程控制**） | ✅ **强依赖** |

> 💡 **安全洞察**：**①②阶段不依赖通信**（所以通信攻击影响有限）；
> **③阶段强依赖通信**（所以是通信攻击的重点目标）。

### 三、惯量响应的数学

$$\frac{df}{dt} = \frac{\Delta P}{2H}, \qquad H = \frac{\sum_i H_i S_i}{S_{\text{total}}}$$

| 符号 | 含义 | 典型值 |
|---|---|---|
| $\Delta P$ | 功率缺额 | 例：1000 MW |
| $H$ | 系统惯量常数 | 传统 4~6 s；新型 1~2 s |
| $df/dt$ | **RoCoF**（频率变化率） | 传统 0.1~0.2 Hz/s；新型 **> 1 Hz/s** |

### 四、惯量下降的后果（量化对比）

| 指标 | 传统电网 | 低惯量电网 | 变化 |
|---|---|---|---|
| 惯量常数 $H$ | 5 s | 1.5 s | **↓ 70%** |
| RoCoF | 0.2 Hz/s | **1.0 Hz/s** | ↑ 5 倍 |
| 最大频率偏差 | 小 | 大 | ↑ |
| 留给调频的时间 | 数十秒 | **几秒** | ↓ 10 倍 |

### 五、RoCoF 与保护的"死亡螺旋"

```
惯量下降
    ↓
RoCoF 变大
    ↓
RoCoF 继电器（df/dt 超限跳闸）**误动作**
    ↓
更多电源脱网
    ↓
惯量进一步下降
    ↓
（正反馈，回到第一步）
```

> ⚠️ **这就是 2019 年英国 8·9 大停电的核心机制** —— 保护本身成了连锁的推手。

### 六、解决方案

| 方案 | 原理 | 代价 |
|---|---|---|
| **构网型储能** | 提供**合成惯量** | 成本高、需要储能 |
| **快速频率响应（FFR）** | 秒级功率支撑 | 需要快速资源 |
| **降低 RoCoF 保护定值** | 不轻易跳闸 | **更危险**（可能错过真实故障） |
| **虚拟惯量控制** | 风机/光伏预留备用 | 弃风弃光 |

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **惯量 = 系统韧性的量化指标** | 攻击者降低 $H$ 等价于降低系统韧性 |
| **"惯量攻击"是新型攻击面** | 让储能**不提供**惯量支撑（而不是篡改数据） |
| **检测窗口极短** | 5 秒内要完成检测 + 响应 → 传统 IDS 来不及 |
| **对接实验室方向** | 时序异常检测（毫秒级）+ 智能体（自主响应） |

> 💡 **研究直觉**：

## Day 71 · 14:00 —— 低惯量电网的安全挑战：攻击的"高杠杆时代"

> **一句话**：**低惯量让电网"更脆"，攻击收益更高、检测窗口更短**——安全攻防的成本收益比彻底改变了。

### 一、低惯量带来的正反馈连锁

```
惯量低
  ↓
频率变化快（RoCoF 大）
  ↓
保护误动作 / 电源脱网
  ↓
电源更少 → 惯量更低
  ↓
（正反馈，加速崩溃）
```

**这是一个"越崩越快"的过程** —— 而传统电网的惯量足以抑制这个反馈。

### 二、2019 年英国 8·9 大停电的启示

| 要素 | 内容 |
|---|---|
| **触发** | 雷击导致一条线路故障 + 一座燃气电站跳机 |
| **功率缺额** | 约 1.1 GW |
| **关键现象** | **分布式电源（逆变器）大量脱网**（不是同步机） |
| **频率最低点** | 48.8 Hz（标准 49.5 Hz） |
| **后果** | 低频减载动作，约 **100 万人**受影响 |
| **核心教训** | **逆变器不会"撑住"电网** |

> 💡 **对比**：如果是同样规模的同步机脱网，惯量足以把频率最低点抬到 49.2 Hz 以上 —— **不会触发减载**。

### 三、低惯量电网的安全挑战清单

| 挑战 | 传统电网 | 低惯量电网 |
|---|---|---|
| **响应时间窗口** | 分钟级 | **秒级** |
| **检测所需采样率** | 2 s（SCADA） | **毫秒级** |
| **攻击后果放大倍数** | 1× | **3~10×** |
| **攻击成本** | 高（要打多个点） | **低**（一个点可能够） |
| **现有 IDS 适用性** | 可用 | **基本失效** |

### 四、攻击者的"杠杆"（核心洞察）

$$\text{攻击杠杆} = \frac{\text{物理后果}}{\text{攻击成本}}$$

| 电网类型 | 需要多少攻击量才能引发连锁 |
|---|---|
| 传统（$H = 5$ s） | 必须造成**大扰动**（切大机组） |
| 低惯量（$H = 1.5$ s） | **小扰动即可**（切少量分布式电源） |

> ⚠️ **结论**：**新型电力系统对攻击者更"友好"** ——
> 同样的攻击能力，在低惯量电网上能造成大得多的后果。

### 五、防御思路

| 层次 | 措施 | 局限 |
|---|---|---|
| **物理层** | 构网型储能、同步调相机 | 成本高、部署慢 |
| **控制层** | 快速频率响应（FFR）、虚拟惯量 | 需要预留容量 |
| **保护层** | 保护协调优化、防误动 | 难以兼顾灵敏与可靠 |
| **监测层** | 宽频测量、毫秒级异常检测 | **需要新方法** ⭐ |

### 六、研究机会清单

| 方向 | 核心问题 | 难度 | 新意 |
|---|---|---|---|
| **惯量攻击建模** | 如何量化"降低惯量"的攻击后果？ | 中 | **高** |
| **毫秒级异常检测** | 传统 IDS 太慢，怎么办？ | 高 | 高 |
| **保护协调安全** | 防止保护成为连锁推手 | 中 | 中 |
| **韧性评估** | 从"检测攻击"到"评估剩余韧性" | 中 | **高** |
| **构网型设备安全** | 合成惯量能否被攻击？ | 中 | **高** |

### 🔗 与网安研究关联

**低惯量 = 高杠杆 = 攻击者友好** —— 这是新型电力系统安全的核心命题。

## Day 72 · 09:00 —— 电力市场基础：现货、辅助服务与出清机制

> **一句话**：**电力市场用"价格"代替"指令"来配置资源**——但价格信号本身，成了新的攻击目标。

### 一、电力市场的三个特殊性

| 特殊性 | 说明 | 后果 |
|---|---|---|
| **难以大规模储存** | 传统上电必须"即发即用" | 供需必须**实时**平衡 |
| **输电有约束** | 线路会阻塞 | **不能**全网一个价 |
| **需求刚性** | 用户对价格不敏感 | 容易出现价格尖峰 |

> 💡 第二点是关键：因为有**阻塞**，所以不同节点的电价不同 → 这就是 **LMP** 的由来。

### 二、电力市场的完整体系

| 市场类型 | 时间尺度 | 交易对象 | 作用 |
|---|---|---|---|
| **中长期市场** | 年 / 月 | 电能量（MWh） | 锁定基础电量、规避风险 |
| **日前市场** | 提前 1 天 | 次日 96 点（15 分钟粒度） | 主体交易 |
| **实时市场** | 分钟级 | 平衡偏差 | 修正预测误差 |
| **辅助服务市场** | 分钟 ~ 小时 | **调频 / 备用 / 无功** | 保障安全 |
| **容量市场** | 年 | 装机可用性 | 保障长期充裕 |

### 三、出清机制

| 模式 | 代表 | 特点 |
|---|---|---|
| **集中式** | PJM（美国）、中国现货试点 | 调度统一出清，透明度高 |
| **分散式** | 北欧、德国 | 双边交易为主 |
| **中国现状** | 中长期为主 + 现货试点 | 8 个现货试点省份 |

### 四、出清算法：SCED

**安全约束经济调度（Security-Constrained Economic Dispatch, SCED）**：

$$\min \sum_i C_i(P_i) \quad \text{s.t.} \quad \begin{cases} \sum P_i = \sum P_d \\ |P_{ij}| \le P_{ij}^{\max} \\ P_i^{\min} \le P_i \le P_i^{\max} \end{cases}$$

**输出两样东西**：
1. **中标电量**：每台机组发多少
2. **节点电价（LMP）**：每个节点的价格

### 五、LMP 的三个分量

$$\text{LMP}_i = \underbrace{\lambda}_{\text{能量分量}} + \underbrace{\sum_k \mu_k \frac{\partial P_k}{\partial P_i}}_{\text{阻塞分量}} + \underbrace{\text{损耗分量}}_{\text{通常忽略}}$$

| 分量 | 来源 | 攻击价值 |
|---|---|---|
| **能量分量** $\lambda$ | 系统供需平衡 | 中 |
| **阻塞分量** $\mu_k$ | 线路约束 | **高**（可伪造阻塞） |
| 损耗分量 | 网损 | 低 |

> 💡 **攻击者的思路**：伪造"某条线路阻塞"的数据 → 该区域 LMP 飙升 → 攻击者在该区域的机组获利。

### 六、价格尖峰与操纵

| 情况 | 成因 | 是否合法 |
|---|---|---|
| **正常尖峰** | 供需紧张、机组故障 | ✅ 合法 |
| **物理操纵** | 机组**故意检修**制造稀缺 | ⚠️ 灰色地带（市场力） |
| **数据操纵** | **篡改数据影响 LMP** | ❌ **攻击** |

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **市场 = 经济动机的来源** | 这是"有明确回报"的攻击，比无差别攻击更危险 |
| **LRA 的攻击目标就是市场** | 篡改负荷数据 → 改变出清结果 |
| **新威胁模型** | **有经济动机的内部人攻击者** |
| **对接实验室方向** | 异常检测（价格异常）+ 博弈论（激励机制） |

> 💡 **威胁模型的升级**：
> ```
> 传统威胁模型：攻击者想让系统崩溃（破坏型）
> 市场环境模型：攻击者想让自己获利（经济型）
>                → 攻击更隐蔽（只要"看起来正常"就行）
>                → 攻击更持续（每次市场出清都是机会）
> ```

## Day 72 · 14:00 —— 市场机制下的攻击动机与安全激励

> **一句话**：**市场让攻击第一次有了明确的"经济回报"**——攻击者从"炫技"变成了"牟利"。

### 一、攻击动机的分类（威胁建模的第一步）

| 动机 | 典型攻击者 | 手法 | 隐蔽性需求 |
|---|---|---|---|
| **经济获利** | 市场参与者 | LRA、价格操纵 | **极高**（要长期不被发现） |
| **破坏** | 敌对势力 | 直接物理 / 大规模攻击 | 低（只求后果） |
| **勒索** | 犯罪组织 | 勒索软件、数据加密 | 中 |
| **研究 / 炫技** | 爱好者、研究者 | 漏洞挖掘、PoC | 低 |

> 💡 **注意"经济获利"这一栏的隐蔽性需求是"极高"** ——
> 因为攻击者要**长期反复**作案，一旦被发现就前功尽弃。这使攻击更"精巧"，也更难检测。

### 二、经济驱动的攻击：LRA 的完整逻辑

**攻击者 = 市场参与者（内部人）**，目标：让自己的机组多发电 / 抬高电价。

```
① 篡改负荷量测数据
   保持总负荷不变，只重新分配（"负荷重分配"名字的由来）
        ↓
② 状态估计给出错误的负荷分布 x̂
   （残差可能完全不变 → BDD 通过）
        ↓
③ SCED 用错误的负荷分布做优化
        ↓
④ 出清结果改变：
   · 攻击者机组从"不中标"变成"中标"
   · 或区域 LMP 升高
        ↓
⑤ 攻击者获利
```

### 三、LRA 的收益模型（简化）

| 场景 | 便宜机组 | 昂贵机组 | 攻击者（拥有昂贵机组） |
|---|---|---|---|
| **正常** | 中标多发 | 不中标 | 收益 = 0 |
| **攻击后** | 少发 | **中标** | **收益 > 0** |

**攻击成本**：需要知道网络拓扑和负荷分布（内部人有优势）。
**攻击收益**：差价 × 电量，可以很大且**持续**。

### 四、为什么经济动机的攻击更危险

| 维度 | 破坏型攻击 | 经济型攻击 |
|---|---|---|
| **攻击频率** | 一次 | **每次出清都是机会** |
| **隐蔽要求** | 低 | **极高** |
| **攻击者知识** | 可能很少 | **通常很了解系统**（内部人） |
| **检测难度** | 中 | **高**（与正常策略难区分） |
| **持续性** | 短 | **长** |

> ⚠️ **最棘手的点**：攻击者的行为**在统计上看起来像一个"激进的交易策略"** ——
> 而不是明显的"攻击"。这让检测变得极其困难。

### 五、市场安全机制与局限

| 机制 | 作用 | 局限 |
|---|---|---|
| **市场监管** | 发现异常报价 | 滞后（事后） |
| **结算校验** | 核对实际与计划 | 需要数据本身可信 |
| **数据审计** | 事后追溯 | 事后 |
| **市场力监测** | 防止垄断 | 不针对数据攻击 |

**共同局限**：**都假设"数据是真的"** —— 而 LRA 恰恰攻击的是数据本身。

### 六、研究机会清单

| 方向 | 核心问题 | 新意 |
|---|---|---|
| **LRA 检测** | 从优化结果反推数据是否被篡改 | 中 |
| **市场异常检测** | 统计方法识别异常价格/中标模式 | 中 |
| **经济激励设计** | 设计机制使攻击无利可图 | **高** |
| **攻防博弈** | Stackelberg 博弈求最优防御 | 中 |
| **内部人威胁建模** | 攻击者同时是合法参与者 | **高** |

### 🔗 与网安研究关联

**这是"有动机的攻击者"模型** —— 比无差别攻击危险得多。

| 传统 IDS 假设 | 市场场景的现实 |
|---|---|
| 攻击者留下异常流量 | 攻击者用**合法接口** |
| 攻击者行为异常 | 攻击者行为**像正常交易** |
| 攻击是离散事件 | 攻击是**持续过程** |

> 💡 **选题灵感**：
> 「**面向电力市场的数据攻击检测：从"数据一致性"到"决策合理性"**」
> - 思路：不检查数据本身（可能完全合法），而检查**优化决策的合理性**
> - 例如：为什么这次出清选了成本更高的机组组合？是否存在更优解？
> - 结合点：**博弈论（防御者最优策略）+ 异常检测（决策异常）**
> - 这条路线对接实验室的「工业AI与智能体」（可以做防御智能体）

### 🔍 延伸思考

1. **内部人攻击**与**外部攻击**的检测策略有何本质不同？
2. 如何设计市场机制，使"数据攻击"**无利可图**？（这是机制设计问题）

## Day 73 · 09:00 —— 配电网与分布式资源（DER）管理

> **一句话**：**配电网从"被动末端"变成了"主动战场"**——因为光伏、储能、EV 全都接在这里。

### 一、配电网 vs 输电网（一张表看懂差异）

| 维度 | **输电网** | **配电网** |
|---|---|---|
| 电压等级 | 220 kV 及以上 | 10 kV / 380 V |
| 结构 | **环网**（有冗余） | **辐射状**（单路径） |
| 潮流方向 | 单向（电源→负荷） | **双向**（有 DER 后） |
| 量测完备度 | **高**（$m \gg n$） | **极低**（$m \ll n$） |
| 自动化水平 | 高 | 低 |
| 设备数量 | 少（几百） | **海量（百万级）** |
| 防护水平 | **专网 + 隔离装置** | **公网 / 无线** |

### 二、配电网的范式转变

```
传统配电网（被动）：
  变电站 → 馈线 → 用户
  单向潮流，只需"供电"

主动配电网（ADN，主动）：
  变电站 ⇄ 馈线 ⇄ 用户（含光伏、储能、EV）
  双向潮流，需要"协调控制"
```

**新问题**：

| 问题 | 原因 |
|---|---|
| **电压越限** | 分布式光伏反向送电 → 末端电压升高 |
| **反向潮流** | 潮流方向不确定 → 保护配合失效 |
| **保护误动** | 双向潮流 + 变流器限流特性 |
| **谐波** | 大量电力电子设备 |

### 三、DER 的类型

| 类型 | 特点 | 可控性 |
|---|---|---|
| **分布式光伏** | 出力不可控（看天） | 只能限功率 |
| **储能** | 充放电可控 | **完全可控** |
| **EV 充电桩** | 时间/功率可调 | 半可控 |
| **微燃机** | 出力可控 | 可控 |
| **可控负荷** | 需求响应 | 半可控 |

### 四、DER 管理的四重挑战

| 挑战 | 说明 | 安全含义 |
|---|---|---|
| **数量大** | 百万级设备 | 攻击面爆炸 |
| **通信异构** | 光纤/无线/PLC/公网混用 | 漏洞面大 |
| **归属分散** | 不同业主、不同运维方 | **责任不清、难统一防护** |
| **标准不一** | 各厂商私有协议 | 难以统一审计 |

### 五、DER 聚合与协调

```
分布式资源（海量、分散、异构）
        ↓ 聚合
┌───────────────────────────────┐
│  VPP / 微电网 / DER 管理系统   │
└───────────────┬───────────────┘
                ↓ 作为整体
        参与电网调度与市场
```

### 六、安全含义（配电网是"攻击面最大"的地方）

| 层面 | 攻击方式 | 后果 |
|---|---|---|
| **海量终端** | 批量控制 | 影响主网频率/电压 |
| **通信异构** | 利用某一种协议的漏洞 | 局部失效 |
| **归属分散** | 从防护最弱的一环入手 | 突破整体 |
| **无人值守** | 物理接触篡改固件 | 长期潜伏 |
| **数据采集** | 伪造量测 | 影响状态估计 |

> ⚠️ **核心洞察**：**攻击者可以从"最边缘、防护最弱"的地方入手，逐级影响主网**。
> 传统电网的"隔离装置 + 专网"防线，在配电网这一层**完全不存在**。

## Day 73 · 14:00 —— 配电网状态估计的难点：为什么它比输电网难得多

> **一句话**：**配电网量测稀疏、三相不平衡、辐射状结构**——这三点让传统状态估计方法直接失效。

### 一、四大差异（对比表）

| 维度 | 输电网 | **配电网** | 后果 |
|---|---|---|---|
| **量测密度** | $m \gg n$（冗余高） | **$m \ll n$（严重不足）** | 不可观测 |
| **三相平衡** | 平衡（单相建模） | **不平衡** | 状态维度 ×3 |
| **网络结构** | 环网 | **辐射状** | 需专门算法 |
| **$R/X$ 比** | $X \gg R$ | **$R \approx X$** | **直流近似失效** |

### 二、难点 1：量测严重不足

```
输电网：每个节点都有量测 → 冗余 → WLS 可用
配电网：只在变电站出口和少数开关处有量测
        ↓
        m < n → **数学上不可观测**
        ↓
必须引入"伪量测"（Pseudo-measurement）
```

| 伪量测来源 | 精度 | 风险 |
|---|---|---|
| 负荷预测值 | 中 | **预测被攻击 = 状态估计被攻击** |
| 历史负荷曲线 | 中 | 依赖历史数据可信 |
| 用户电表数据 | 低（时延大） | 数据质量差 |

> ⚠️ **这是配电网独有的攻击面**：**攻击负荷预测，就等于攻击状态估计** ——
> 因为伪量测直接被当成"真量测"参与估计。

### 三、难点 2：三相不平衡

输电网假设三相平衡，只需建模**一相**。
配电网三相负荷不对称 → 必须**三相分别建模**：

$$n_{\text{state}}^{\text{dist}} = 3 \times n_{\text{node}} \quad (\text{输电网只需 } n_{\text{node}})$$

**后果**：状态维度 ×3，计算量上升，攻击面也 ×3。

### 四、难点 3：$R/X$ 比接近 1

| 电网类型 | $R/X$ | 能否用直流近似 |
|---|---|---|
| 输电网 | 0.1 ~ 0.3 | ✅ 可以（$X \gg R$） |
| **配电网** | **0.5 ~ 3** | ❌ **不行** |

**后果**：Day 61 学的直流潮流近似**在配电网完全失效** ——
必须用完整的交流模型，甚至要考虑**电压与有功的耦合**。

### 五、难点 4：辐射状结构 → 前推回代法

**辐射状网络**（树形，无环）有一个天然优势：**可以用"前推回代"高效求解**。

```
前推（Backward Sweep）：从末端向根节点，累加功率
    ↓
回代（Forward Sweep）：从根节点向末端，更新电压
    ↓
重复直到收敛
```

| 方法 | 适用 | 收敛性 |
|---|---|---|
| 牛顿-拉夫逊 | 输电网（环网） | 二次收敛但需要好初值 |
| **前推回代** | **配电网（辐射状）** | 线性收敛但**极其稳健** |

### 六、安全含义汇总

| 配电网特点 | 攻击含义 | 检测难度 |
|---|---|---|
| **量测稀疏** | 更容易制造不可观测 → **攻击空间大** | **高** |
| **伪量测依赖预测** | 攻击负荷预测即可影响估计 | 高 |
| **三相建模** | 攻击面 ×3 | 中 |
| **观测能力弱** | BDD 本身就不灵敏 | **高** |
| **$R/X$ 大** | 传统线性方法失效 → 检测器设计更难 | 高 |

### 🔗 与网安研究关联

| 要点 | 说明 |
|---|---|
| **研究空白大** | 配电网 FDIA 研究**远少于**输电网 → 好发论文 |
| **伪量测是独特攻击点** | 输电网没有这个问题 |
| **"低观测度下的检测"** | 这是一个**通用**的科学问题（不只在电力） |
| **对接实验室方向** | AI与数据安全（低质量数据下的学习）+ 入侵检测 |

> 💡 **一个很好的选题（配电网 + FDIA + GNN）**：
> 「**量测稀疏条件下配电网 FDIA 检测：基于伪量测可信度建模与图学习**」
> - **问题新**：配电网量测不足是真实痛点，输电网的方法不能直接用
> - **方法新**：需要**同时**处理"真实量测"和"伪量测"的**不同可信度**
> - **数据可得**：IEEE 33/69 节点配电网算例公开，pandapower 直接支持
> - **可对比**：与输电网方法（直接套用）对比，证明"不能简单迁移"

2. 伪量测（负荷预测）被攻击会怎样？这算 FDIA 吗？

### 五、从清单到选题：四步筛选法

```
第 1 步：有真实攻击面吗？
    → 攻击在物理上可实现吗？（不是纯理论假设）

第 2 步：有检测难度吗？
    → 如果很容易检测，就没有研究价值
    → 理想：攻击不留数据痕迹，但留下"行为"或"物理"痕迹

第 3 步：有数据/仿真支持吗？
    → 能用 pandapower / MATLAB / 公开数据集复现吗？

第 4 步：与实验室方向契合吗？
    → 能否挂到「工业AI」「入侵检测」「AI与数据安全」上？
```

### 六、推荐组合（给你的具体建议）

**首选组合**：「**配电网 FDIA 检测 + 图学习 + 伪量测可信度建模**」

| 理由 | 说明 |
|---|---|
| **问题真实** | 配电网量测稀疏是工程痛点 |
| **研究少** | 现有 FDIA 研究 90% 集中在输电网 |
| **数据可得** | IEEE 33/69 节点算例公开，pandapower 直接支持 |
| **方法契合** | GNN 天然适合"辐射状网络 + 稀疏量测" |
| **实验室契合** | 工业AI + 入侵检测双覆盖 |
| **可延伸** | 后续可扩展到"伪量测攻击"这个更独特的问题 |

**次选组合**：「**VSG 参数篡改检测 + 系统辨识 + 时序异常检测**」
- 新意更高，但需要电磁暂态仿真能力，入门门槛高一些。
