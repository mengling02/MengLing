## Day 8 · 09:00 —— 发电机：电能从哪里来

> **一句话**：发电机是电网的"心脏"，靠**电磁感应**把机械能转成电能。它有三个参数你必须记住：**容量、功角、励磁**——因为它们分别对应过载攻击、稳定攻击和电压攻击。

### 一、基本原理

**法拉第电磁感应定律**：导体切割磁力线产生电动势。发电机把"转子（磁场）"和"定子（线圈）"做相对运动，就产生了三相交流电。

```
[汽轮机/水轮机] ──带动──→ [转子旋转] ──电磁感应──→ [定子输出三相交流]
   机械能                                   电能
```

频率与转速的关系：**f = p·n/60**（p 是极对数，n 是转速 rpm）。中国 50 Hz，两极机转速就是 3000 rpm。

### 二、三个关键参数

| 参数 | 含义 | 安全问题 |
|---|---|---|
| **容量 (MW)** | 最大出力 | 篡改容量数据 → 调度误判备用 |
| **功角 δ** | 转子磁场超前定子磁场的角度 | **功角失稳 = 系统崩溃** |
| **励磁** | 转子电流，决定机端电压 | 攻击励磁系统 → 电压失控 |

**功角稳定性是电力系统稳定性的核心**：功角随输电功率增大而增大，超过 90° 就失去同步（"失步"），发电机和系统"脱节"。

### 三、发电机的控制与保护

| 系统 | 作用 | 攻击价值 |
|---|---|---|
| **励磁系统 (AVR)** | 维持机端电压、控制无功 | 极高（可致电压崩溃） |
| **调速系统** | 控制频率、有功 | 极高（AGC 攻击的落点） |
| **继电保护** | 故障时切机 | 高（可被欺骗而误切） |

现代发电机的这些系统都是**数字化的、网络化的**——DCS（分散控制系统）将它们连成一体。**这就是攻击入口**。

### 四、和电网安全研究的关系

**发电机侧攻击的三个层次**：

1. **数据层**：篡改发电机出力/容量量测 → 调度误判（FDIA 的发电侧变体）
2. **控制层**：攻击 AVR/调速器 → 直接操控发电机物理输出（比数据攻击更直接）
3. **保护层**：伪造故障信号触发误切机 → 制造人为功率缺额

**研究提示**：**"最小攻击代价导致最大机组跳闸"** 是一个可量化的优化问题，很适合用 AI 方法求解（例如强化学习求攻击策略）。这是"工业AI + 安全"的典型交叉选题。

## Day 8 · 14:00 —— 变压器：电网的"齿轮箱"与变比原理

> **一句话**：变压器是电网里唯一能"改变电压"的设备，靠的是**电磁耦合**。它既是电网灵活性的来源，也是**攻击者的高价值目标**——因为它的故障往往是不可逆的硬件损坏。

### 一、变比原理

变压器通过**两个绕组匝数比**改变电压：

$$\frac{U_1}{U_2} = \frac{N_1}{N_2}$$

```
[一次侧 U₁] ──→ [铁芯磁通] ──→ [二次侧 U₂]
   N₁ 匝                          N₂ 匝
   U₁N₁ 高                        U₂N₂ 低
```

**关键特性**：
- 电压比 = 匝数比（理想情况）
- 电流比 ∝ 匝数反比（功率守恒）
- **只对交流有效**（直流不能变压——这就是 Day6 直流输电要用换流器的原因）

### 二、变压器家族

| 类型 | 特点 | 用途 |
|---|---|---|
| **电力变压器** | 容量大、效率高（>99%） | 输电、变电 |
| **配电变压器** | 数量巨大、分布广 | 10 kV → 380 V |
| **自耦变压器** | 体积小、成本低 | 高压联络 |
| **换流变压器** | 特殊设计，耐受谐波 | HVDC 换流站 |

### 三、保护与监测

变压器是**昂贵设备**（大型电力变压器上千万），有完整的保护体系：

| 保护 | 检测什么 |
|---|---|
| **差动保护** | 两侧电流不平衡（内部故障） |
| **瓦斯保护** | 内部产气（早期故障） |
| **过流保护** | 过载 |
| **油温/绕组温度** | 过热 |

这些保护**全部是数字化的**，通过 IEC 61850 接入变电站网络。

### 四、和电网安全研究的关系

**变压器攻击的独特之处：物理损害难以恢复**

| 攻击方式 | 后果 |
|---|---|
| 篡改差动保护数据 | 误动（正常时跳闸）或拒动（故障时不跳） |
| 攻击冷却系统监测 | 过热损坏，**更换周期以月计** |
| 制造过载而保护失效 | 绕组烧毁，**这是物理破坏，无法"重启恢复"** |
| 篡改油温数据 | 掩盖早期故障，直至损毁 |

**这是电网安全与纯网安最大的区别**：**网络攻击可以造成不可逆的物理破坏。** 传统网络安全里"最坏就是数据泄露"，而这里"最坏是整个变电站烧掉"。

**选题提示**：**"隐蔽的物理破坏攻击"**（攻击者故意让保护失效，慢慢把设备"烧死"）是一个很有意思的方向——它需要的攻击周期长、隐蔽性高，检测也更难。**这种"慢攻击"适合用时序异常检测方法**。

2. 为什么"物理破坏"比"数据泄露"对电网的威胁等级更高？这对检测的实时性要求意味着什么？

## Day 9 · 09:00 —— 断路器与隔离开关：电网的"保险丝"与"门锁"

> **一句话**：断路器负责**切断故障电流**，隔离开关负责**隔离检修**。它们看起来只是"开关"，但在攻击者手里，**一个误动的断路器就能引发连锁事故**。

### 一、两者的区别

| 设备 | 能切什么 | 操作时机 | 比喻 |
|---|---|---|---|
| **断路器 (CB)** | 能切**故障电流** | 正常/故障时均可带载操作 | 家里的闸刀 |
| **隔离开关 (DS)** | **只能切空载电流** | 必须在断路器断开后操作 | 检修用的"门锁" |

**关键区别**：断路器有**灭弧能力**（用真空、SF₆ 气体、油来熄灭火花），隔离开关没有。所以**隔离开关必须在断路器断开后操作**，否则会拉出致命电弧。

### 二、操作顺序规则

```
送电：先合隔离开关，后合断路器
停电：先断断路器，后断隔离开关
```

这个顺序**绝对不能颠倒**。现代变电站用**五防系统**（防止误分合、防止带负荷拉隔离开关等）强制约束。**五防系统是软件逻辑——所以它也是攻击目标。**

### 三、断路器的发展

| 类型 | 灭弧介质 | 特点 |
|---|---|---|
| 油断路器 | 变压器油 | 老式，淘汰 |
| 真空断路器 | 真空 | 中压主力 |
| **SF₆ 断路器** | 六氟化硫气体 | 高压/超高压主力 |

SF₆ 是强效温室气体（GWP = 23500），所以在推行替代。它也是**监测对象**——气体压力、微水含量都能反映设备状态。

### 四、和电网安全研究的关系

**断路器是"执行机构"——攻击它等于直接控制电网的物理动作**：

| 攻击手法 | 后果 |
|---|---|
| **伪造跳闸指令** | 让断路器错误跳闸（2015 乌克兰事件的核心手法！） |
| **阻塞跳闸指令** | 故障时该跳不跳 → 设备损毁、故障扩大 |
| **篡改状态量测** | 调度员看到"已经跳闸"，实际没有 |
| **攻击五防系统逻辑** | 造成违规操作，设备损坏 |

**重大提示**：乌克兰 2015 事件中，攻击者**直接操作了变电站的断路器**——他们拿到 HMI 权限后，像调度员一样"点鼠标"断开断路器，造成 23 万人停电。**这是"网络攻击直接导致物理停电"的教科书案例**，也是本题材最值得反复研读的事件。

**选题方向**：**"断路器操作的异常检测"** —— 因为断路器操作是**稀疏事件**（一天可能就几次），而且有严格的顺序和授权规则。**用规则+AI混合方法检测异常操作指令**，是一个实用且有价值的选题。

## Day 9 · 14:00 —— 母线、开关站与变电站一次设备全景

> **一句话**：变电站是电网的"交通枢纽"，**母线就是枢纽里的"主干道"**。理解了母线的接线方式，你就看懂了变电站为什么这么"抗打击"。

### 一、母线是什么

**母线（Busbar）**：汇集和分配电能的导体。多条进线、出线都接在母线上，它就是电能的"集散中心"。

```
        进线1   进线2
          │       │
    ┌─────┴───────┴─────┐
    │      母线 I        │  ← 主干道
    └──┬────┬────┬───────┘
       │    │    │
     出线1 出线2 出线3
```

### 二、母线接线方式（可靠性与成本的权衡）

| 接线方式 | 可靠性 | 成本 | 用于 |
|---|---|---|---|
| **单母线** | 低（母线故障全停） | 最低 | 小型站 |
| **单母线分段** | 中 | 低 | 中型站 |
| **双母线** | 较高（可倒母线） | 中 | 重要站 |
| **双母线双分段** | 高 | 高 | 重要枢纽 |
| **一台半断路器（3/2 接线）** | **最高** | 最高 | 500 kV 及以上 |

**一台半断路器接线**是超高压变电站的标准配置：每条线路由 1.5 个断路器控制，**任意一台断路器检修都不停电**，可靠性极高。

### 三、变电站主要一次设备清单

| 设备 | 作用 |
|---|---|
| 变压器 | 变压 |
| 断路器 | 切除故障 |
| 隔离开关 | 隔离检修 |
| 母线 | 汇集分配 |
| 电流互感器 (CT) | 测量电流，供保护用 |
| 电压互感器 (PT) | 测量电压，供保护用 |
| 避雷器 | 防过电压 |
| 电容器/电抗器 | 无功补偿 |

**注意 CT 和 PT**：它们是**量测的源头**。所有保护、状态估计、SCADA 数据都来自它们。**攻击 CT/PT 的二次回路，等于从源头污染所有数据。**

### 四、和电网安全研究的关系

**变电站的"拓扑可靠性"与"网络攻击"存在有趣的张力**：

| 设计特点 | 对故障的意义 | 对攻击的意义 |
|---|---|---|
| 冗余设计（双母线、3/2 接线） | 抗单点故障 | **攻击者需要同时攻破多个点** |
| 保护冗余（主保护+后备保护） | 提高可靠性 | **主备保护若共用通信网络，则同时失效** |
| 集中监控 | 便于运行 | **单点被攻破影响面大** |

**核心洞察**：变电站的冗余是**为随机故障设计的**，而攻击是**针对性的**。攻击者可以研究冗余逻辑，找到"同时打掉主备保护"的方法。**"冗余设计在对抗性环境下的有效性"** 是一个非常值得研究的问题。

**选题提示**：**"基于拓扑的攻击路径分析"** —— 用图论方法找出从网络入口到关键一次设备的最短攻击路径，这是"入侵检测"和"图神经网络"的结合点，你实验室方向完全对口。

2. 如果主保护和后备保护走同一根光纤，冗余就失效了。这在现实中常见吗？怎么检测？

## Day 10 · 09:00 —— 输电线路：杆塔、导线、绝缘子与输电容量

> **一句话**：输电线路是电网的"血管"。它的**输送容量不是由导线粗细决定的，而是由热极限、电压降和稳定极限三者中最低的那个决定**——这叫"木桶原理"。

### 一、线路的组成

| 部件 | 作用 | 关键参数 |
|---|---|---|
| **导线** | 载流 | 截面积、材质（钢芯铝绞线 LGJ） |
| **杆塔** | 支撑 | 高度、型式（直线塔/耐张塔） |
| **绝缘子** | 电气隔离 | 爬电比距、片数 |
| **金具** | 连接固定 | — |
| **地线** | 防雷 | 通常在最上方 |

### 二、输电容量由三个极限决定

**取三者最小值**：

| 极限 | 限制因素 | 典型场景 |
|---|---|---|
| **热极限** | 导线温度（≤70-80°C） | 短线路 |
| **电压降极限** | 末端电压不低于限值 | 中长线路 |
| **稳定极限** | 功角不超过限值（<90°） | **长线路（主导）** |

$$\text{线路容量} = \min(\text{热极限}, \text{电压降极限}, \text{稳定极限})$$

**对远距离输电，稳定极限通常是瓶颈**——这解释了为什么特高压要用分裂导线、串联电容补偿（降低电抗、提高稳定极限）。

### 三、分裂导线：为什么不只用一根粗线

高压线路用 **2-8 根细导线**组成"一相"，好处：

1. **降低电抗**（提高输送容量）
2. **减少电晕放电**（减少损耗和噪声）
3. **增加散热**（提高热极限）

### 四、和电网安全研究的关系

**输电线路的攻击特点是"物理暴露"**：

| 攻击类型 | 说明 |
|---|---|
| **物理攻击** | 倒塔、剪线（2013 美国 Metcalf 变电站枪击案是经典案例） |
| **无人机破坏** | 新兴威胁，防不胜防 |
| **数据攻击** | 篡改线路潮流/温度监测，掩盖过载 |
| **动态增容攻击** | 篡改温度数据，让系统误判"还能多送" → 导线过热下垂 |

**"动态增容"（DLR）** 值得关注：现代电网用实时温度监测来挖掘线路潜力（导线温度越低，能送的电越多）。**如果攻击者篡改温度传感器数据，让系统认为导线很凉，实际却过载——导线会因过热而弧垂增大，最终对树木或地面放电，引发山火。** 这是一个"从数据篡改到物理灾害"的完整链条，故事性极强，很适合写论文。

## Day 10 · 14:00 —— 电网拓扑建模：节点-支路模型与邻接矩阵

> **一句话**：电力工程师看电网看到的是"设备"，**网络研究者看电网应该看到的是"图"**。把电网建模成图（Graph），你熟悉的图论和 GNN 就全部能用上——**这是你背景的最大优势区**。

### 一、电网就是一张图

```
电力概念          →    图论概念
─────────────────────────────────
母线（节点）       →    Node / Vertex
输电线路（支路）   →    Edge
阻抗               →    Weight
开关状态           →    Edge 存在/不存在
```

**节点-支路模型（Node-Branch Model）**：用**导纳矩阵 Y** 描述电网，是潮流计算的基础。

### 二、图的两层结构

电网有**两张图**，理解这一点是研究的关键：

| 层级 | 节点 | 边 | 用途 |
|---|---|---|---|
| **物理层（电网拓扑）** | 母线 | 输电线 | 潮流、稳定性 |
| **信息层（通信网络）** | 服务器/交换机/RTU | 光纤/网络链路 | 数据流、攻击路径 |
| **耦合（CPS）** | 信息节点控制物理节点 | 控制/量测依赖 | **攻击传导** |

**这就是"信息物理系统（CPS）"的本质**：两张图耦合在一起。**很多电网安全研究的创新点，就在于分析这两张图之间的"跨域依赖关系"。**

### 三、图论指标与电网脆弱性

| 指标 | 电网含义 |
|---|---|
| **度 (Degree)** | 节点的连接数 → 枢纽变电站 |
| **介数中心性** | 经过该节点的最短路径数 → **关键节点** |
| **电网介数** | 只计发电-负荷路径 → 更贴合电力 |
| **聚类系数** | 局部连通性 |
| **连通性** | 攻击后是否解列 |

**"介数中心性最高的节点被攻击，后果最严重"**——这是可以量化的结论，也是"故意攻击 vs 随机故障"研究的核心方法。

## Day 11 · 09:00 —— 潮流计算入门：电网分析的"Hello World"

> **一句话**：潮流计算是电力系统分析的**第一课**，它回答一个基本问题：**给定发电和用电，电网各节点的电压和功率是多少？** 所有电网分析（包括安全分析）都建立在它之上。

### 一、潮流计算在算什么

**已知**：发电出力、负荷、网络参数
**求解**：各**节点电压幅值和相角**、各**支路功率**

数学上它是一个**非线性方程组**：

$$\begin{cases}
P_i = U_i \sum_j U_j (G_{ij}\cos\theta_{ij} + B_{ij}\sin\theta_{ij}) \\
Q_i = U_i \sum_j U_j (G_{ij}\sin\theta_{ij} - B_{ij}\cos\theta_{ij})
\end{cases}$$

（这看起来吓人，但本质就是"基尔霍夫定律 + 欧姆定律"）。

### 二、四种节点类型

| 节点类型 | 已知 | 未知 | 数量 |
|---|---|---|---|
| **PQ 节点** | P、Q | U、θ | 最多（负荷节点） |
| **PV 节点** | P、U | Q、θ | 发电机节点 |
| **平衡节点（Slack）** | U、θ | P、Q | 1 个（承担全网损耗） |

**为什么必须有平衡节点？** 因为网络损耗事先不知道，必须有一个节点"兜底"。

### 三、求解方法

| 方法 | 特点 |
|---|---|
| **高斯-赛德尔** | 简单，收敛慢，教学用 |
| **牛顿-拉夫逊 (NR)** | **主流**，收敛快（二次收敛），但初值敏感 |
| **PQ 分解法** | NR 的简化，速度快，适合大规模 |
| **直流潮流** | 线性化近似，**只算有功**，速度极快 |

**直流潮流（DC Power Flow）** 特别重要——它把非线性问题变成**线性问题**，所以：

$$P = B \cdot \theta$$

**这是几乎所有 FDIA 攻击研究的基础模型**！攻击者要构造虚假数据，用的就是直流潮流的线性关系。**你以后读 FDIA 论文，会发现满篇都是这个公式。**

### 四、和电网安全研究的关系

**潮流计算是"攻击者的工具"，也是"防御者的工具"**：

| 用途 | 说明 |
|---|---|
| **构造攻击** | 用直流潮流线性关系构造"一致性"的虚假数据（可绕过坏数据检测） |
| **检测攻击** | 用潮流方程残差检测不一致数据 |
| **评估后果** | 计算攻击后的潮流，看是否过载 |

**关键提示**：**直流潮流的线性性（P = Bθ）是双刃剑**：
- 对攻击者：线性意味着**容易构造满足约束的假数据**
- 对防御者：线性意味着**可以用矩阵方法高效检测**

**你实验室可用的选题**：用**机器学习拟合潮流关系**，然后检测偏离该关系的异常数据。这在本质上就是"物理约束 + 数据驱动"的混合检测——是当前最受认可的思路。

## Day 11 · 14:00 —— 状态估计：电网调度的"眼睛"

> **一句话**：状态估计（State Estimation, SE）是**电网安全的核心环节**——它从不完美的量测中"猜"出全网真实状态。**也正因为它是"猜"的，所以它是被攻击的首选目标。**

### 一、为什么需要状态估计

**问题**：量测数据有三个毛病：
1. **不冗余**：量测点少于状态量
2. **有误差**：传感器精度有限
3. **可能有坏数据**：故障、干扰

**解决**：用**冗余量测 + 网络模型**，通过**最小二乘法**估计真实状态。

### 二、数学形式

**量测方程**：$z = h(x) + e$
- $z$：量测向量（电压、功率、电流）
- $x$：状态向量（通常是节点电压幅值和相角）
- $e$：量测误差

**加权最小二乘（WLS）估计**：

$$\hat{x} = \arg\min_x \sum_i w_i (z_i - h_i(x))^2$$

（直觉：让"估计出的量测"和"实际量测"的加权差距最小）

### 三、坏数据检测（Bad Data Detection, BDD）

**这是关键环节**！估计完成后，计算**残差**：

$$r = z - h(\hat{x})$$

**如果残差过大 → 判定存在坏数据**。

最常用的检测方法：**卡方检验（χ² 检验）** 和 **最大归一化残差检验**。

```
量测数据 z → 状态估计 → 估计值 x̂ → 计算残差 r
                                        ↓
                                  |r| > 阈值？
                                  是 → 有坏数据，告警
                                  否 → 数据正常
```

### 四、和电网安全研究的关系：这是核心战场

**几乎所有 FDIA 攻击研究的起点，都是"如何绕过 BDD"**：

| 攻击思路 | 原理 |
|---|---|
| **完美 FDIA** | 构造 $a = Hc$，使残差不变（H 是量测雅可比矩阵） |
| **隐蔽攻击** | 假设攻击者知道 H 和拓扑 |
| **盲攻击** | 攻击者不知道 H，用估计方法逼近 |
| **LRA** | 不伪造量测，只改拓扑假设 |

**完美 FDIA 的核心条件**（必须记住）：

$$a = H \cdot c$$

其中 $a$ 是攻击向量，$H$ 是雅可比矩阵，$c$ 是任意非零向量。**满足这个条件的攻击，残差 r 完全不变，BDD 完全无法检测。**

**这就是为什么 FDIA 研究这么热**——它从数学上证明了"存在一种攻击，传统检测方法理论上就检不出来"。**防御必须引入新的信息源**（如物理约束、时序相关性、多源交叉验证）。

**研一入手的建议**：
1. 先在 MATPOWER / pandapower 里复现经典 FDIA（IEEE 14/118 节点系统）
2. 再实现 BDD，验证它检测不出来
3. 然后尝试用**机器学习**（如自编码器）来检测——**这就是一篇论文的雏形**

2. 如果防御方引入"电压相角必须满足物理约束"这一信息，能检测出完美 FDIA 吗？为什么？

## Day 12 · 09:00 —— 继电保护基础：电网的"免疫系统"

> **一句话**：继电保护是电网的"免疫系统"——它要在**几十毫秒内**判断故障、切除故障。**它的核心挑战是"选择性"**：既要动作，又不能误动。而"欺骗免疫系统"正是电网攻击的高级玩法。

### 一、保护要解决的核心问题

**故障时，如何只切除故障部分，保证其余部分正常？**

这需要满足**四性**：

| 要求 | 含义 |
|---|---|
| **选择性** | 只切故障部分 |
| **速动性** | 越快越好（毫秒级） |
| **灵敏性** | 能检测到轻微故障 |
| **可靠性** | 该动就动，不该动不动 |

### 二、保护的分层配合

```
[电源] ──── CB1 ────┬──── CB2 ──── [负荷A]
                    │
                    └──── CB3 ──── [负荷B]

若负荷A侧故障：
  CB2 主保护动作（0.02-0.1s）
  若 CB2 拒动 → CB1 后备保护动作（0.5-1s）
```

**重合闸**：架空线故障 80% 是瞬时的（树枝碰线、鸟害），所以跳闸后**自动重合一次**，成功就恢复供电。

### 三、主要保护类型

| 保护类型 | 原理 | 应用 |
|---|---|---|
| **过流保护** | 电流超限 | 配电网 |
| **距离保护** | 测量阻抗（U/I）判断故障距离 | 输电网主力 |
| **差动保护** | 两端电流差 | 变压器、母线、线路 |
| **纵联保护** | 两端信息比较（通信！） | 高压线路主保护 |

**纵联保护需要通信**——这就是攻击面所在。

### 四、和电网安全研究的关系

**继电保护是"攻击的最高境界"**，因为：攻击保护 = 直接控制电网的"免疫反应"

| 攻击手法 | 后果 |
|---|---|
| **距离保护攻击**（篡改 U/I 量测） | 让保护"看到"虚假故障距离 → 误动 |
| **纵联保护通信攻击** | 阻塞或伪造对侧信号 → 误动/拒动 |
| **差动保护攻击** | 同时篡改两侧电流，保持"差动平衡" → 拒动 |
| **重合闸攻击** | 阻止重合，让瞬时故障变成永久停电 |
| **保护定值篡改** | 改变保护灵敏度，让它"瞎"或"过敏" |

**最值得研究的**：**"距离保护攻击"**——因为距离保护的判据是阻抗 $Z = U/I$，攻击者只需同时篡改 U 和 I，让比值对应一个"故障点"，保护就会动作。**数学上很清晰，实验上可实现，是很好的入门课题。**

另有 **"保护配合攻击"**：通过精确操纵多台保护的动作时序，让后备保护先动、主保护后动（破坏配合关系），扩大停电范围。**这是"跨设备协同攻击"，非常有研究深度。**

## Day 12 · 14:00 —— 故障分析与短路计算：电网异常长什么样

> **一句话**：短路是电网最常见的故障，**短路电流可达额定电流的几十倍**。理解短路，才能理解保护为什么这么设计——也才能理解"仿真一个故障"是攻击研究的基本功。

### 一、短路的四种类型

| 类型 | 符号 | 发生率 | 严重度 |
|---|---|---|---|
| **单相接地** | LG | **最高（~80%）** | 较低 |
| **两相短路** | LL | 中 | 中 |
| **两相接地短路** | LLG | 中 | 较高 |
| **三相短路** | LLL | 最低（~5%） | **最严重** |

**为什么单相接地最常见？** 因为架空线暴露在环境中——雷击、树枝、鸟、风偏都可能造成单相碰地。

### 二、短路电流的特点

三相短路电流（对称）：

$$I_k = \frac{U}{\sqrt{3} \cdot Z_k}$$

其中 $Z_k$ 是故障点到电源的总阻抗。

**关键特征**：
- **数值大**：可达额定电流的 **10-50 倍**
- **含直流分量**：衰减振荡（5-100 ms），是断路器最难断的部分
- **有冲击电流**：第一个半周期峰值最大，决定设备动稳定

### 三、对称分量法（理解不对称故障的钥匙）

单相/两相故障是**不对称**的，直接分析很复杂。**对称分量法**把它们分解为三个"对称"分量：

```
不对称故障 = 正序 + 负序 + 零序
              ↓      ↓      ↓
           正常分量  反向   接地分量
```

**零序分量**是接地故障的特征——所以有**零序保护**。这是电力系统的"独门工具"，网络研究者很少接触。

### 四、和电网安全研究的关系

**故障仿真 = 攻击研究的实验基础**：

| 用途 | 说明 |
|---|---|
| **攻击效果评估** | 伪造故障 → 仿真 → 看保护是否误动 |
| **检测算法训练** | 生成"故障"和"攻击"两类样本，训练分类器 |
| **攻击场景构造** | 用短路计算设计"恰到好处"的假故障 |

**关键区别（研究时务必分清）**：

| 维度 | 真实故障 | 网络攻击 |
|---|---|---|
| 来源 | 自然、随机 | 人为、策略性 |
| 数据特征 | 符合物理规律 | 可能"过于完美"或"不一致" |
| 时间分布 | 随机 | 可选择时机（如负荷高峰） |

**一个重要的检测思路**：**真实故障的电气量之间满足严格的物理关系（如零序与正序的比例），而攻击伪造的数据往往"物理上不自洽"**。用这个特性做检测，称为**"物理一致性校验"**，是目前很有效的方法。

**选题提示**：**"基于物理一致性校验的虚假故障注入检测"** —— 这是一个层次清晰的题目：先建物理模型 → 找攻击的"破绽" → 设计检测器 → 用仿真验证。研一完全能做。

## Day 13 · 09:00 —— N-1 准则与电网可靠性

> **一句话**：**N-1 准则是电网安全运行的硬标准**——任一元件故障都不能引发连锁反应。但对攻击者来说，**N-1 假设"一次只坏一个"恰恰是最大的漏洞**。

### 一、N-1 准则的定义

**N** = 系统中元件总数
**N-1** = 任一元件退出后，系统仍能满足：
- 不出现过载
- 电压在允许范围
- 保持稳定

**检验方法**：对所有元件，逐个假设它故障，重新计算潮流，检查约束。

### 二、N-1 到 N-k：安全等级

| 准则 | 含义 | 应用场景 |
|---|---|---|
| **N-1** | 单一故障安全 | 常态要求 |
| **N-1-1** | 故障后检修状态再故障 | 重要时段 |
| **N-k** | k 个元件同时故障 | 极端场景、防御研究 |

**关键问题**：N-1 检验的计算量是 **O(N)**，而 N-2 是 **O(N²)**，N-k 是组合爆炸。**所以实际电网只做 N-1 校验，以及少数关键断面的 N-1-1。**

### 三、N-1 的实际执行

```
当前运行方式
    ↓
逐个假设元件故障（断路/退出）
    ↓
重新分配潮流（潮流计算）
    ↓
检查：过载？电压合格？稳定？
    ↓
全部通过 → N-1 安全     有失败 → 调整运行方式
```

**预防性控制**：如果 N-1 检验不过，调度员会提前调整（如减出力、切负荷），这叫**"预防控制"**。

### 四、和电网安全研究的关系：攻击 N-1 的三个思路

**这是电网安全研究最有"故事性"的方向之一**：

| 攻击思路 | 原理 | 研究价值 |
|---|---|---|
| **① 人为制造 N-2** | 同时攻击两个元件 | 简单直接，但如何"同时"是难点 |
| **② 隐蔽的 N-1 攻击** | 攻击后系统"看起来"仍满足 N-1，实际已越限 | **诈骗防御，难度高** |
| **③ 攻击 N-1 校验系统** | 篡改输入数据，让校验通过 | 可行性高，危害大 |
| **④ 利用校验时间窗** | 大规模电网 N-1 计算耗时，利用这个间隙攻击 | 时序攻击 |

**特别值得研究的**：**"隐蔽的 N-1 违规"**

攻击者通过**同时篡改量测数据和拓扑信息**，构造一个"在攻击者的数据世界里 N-1 完全合格、但物理上已经不安全"的状态。**这需要攻击者同时欺骗状态估计和 N-1 校验两个环节**——难度高，但一旦成功，后果严重。

**你的方法优势**：这类攻击的检测，本质是**"数据一致性检验"** 问题——正好是 AI 方法（异常检测、图学习）的强项。

**任务**：用 pandapower 载入 IEEE 14 节点系统，画出它的拓扑图，计算各节点的介数中心性，输出"最关键的 3 个节点"。

```python
import pandapower.networks as pn
import networkx as nx

net = pn.case14()
# 构建图
G = nx.Graph()
for _, line in net.line.iterrows():
    G.add_edge(int(line.from_bus), int(line.to_bus))
# 计算介数中心性
bc = nx.betweenness_centrality(G)
top3 = sorted(bc.items(), key=lambda x: -x[1])[:3]
print("最关键节点：", top3)
```

## Day 14 · 14:00 —— 延伸：从复杂网络视角看电网的脆弱性

> **一句话**：电网既是**工程系统**，也是**复杂网络**。用复杂网络理论分析电网，能发现工程视角看不到的脆弱性——**这可能是你背景最能发挥的地方**。

### 一、电网的复杂网络特性

| 特性 | 电网表现 |
|---|---|
| **小世界性** | 平均路径短（几个节点就能跨全网） |
| **无标度性** | 少数枢纽节点连接度极高 |
| **聚类性** | 局部紧密互联 |
| **层次性** | 500kV 主干 + 220kV 次干 + 10kV 配电 |

**"无标度"的关键含义**：**网络的鲁棒性对随机故障很强，对针对性攻击很弱。**

- 随机坏 10% 节点 → 网络基本完好（因为大部分节点度很低）
- **针对性坏 10% 高度节点 → 网络严重解列**

### 二、经典的脆弱性指标

| 指标 | 定义 | 电网含义 |
|---|---|---|
| **度分布** | P(k) ∝ k^(-γ) | 判断是否无标度 |
| **介数中心性** | 最短路径经过率 | 关键传输节点 |
| **电网介数** | 只计发电-负荷路径 | 更贴合电力 |
| **最大连通子图** | 攻击后最大连通部分 | 解列程度 |
| **网络效率** | 平均路径长度的倒数 | 输电能力 |
| **代数连通度** | 拉普拉斯矩阵第二小特征值 | 同步能力 |

### 三、级联失效模型

**电网的连锁失效是复杂网络研究的经典问题**：

```
初始故障（1条线路） 
    → 潮流转移到其他线路 
    → 部分线路过载 
    → 过载线路保护跳闸 
    → 潮流再次转移 
    → 更多线路过载…… 
    → 大面积停电
```

**关键参数**：**容限（tolerance）α**。线路能承受的最大负荷 = (1+α) × 初始负荷。α 越小，越容易级联。

**2003 美加大停电的研究表明**：电网级联失效存在"临界点"，超过临界负载，一次小扰动就会引发全网崩溃。

### 四、和电网安全研究的关系：这是你的"高产区"

**复杂网络 + 安全 + AI = 你实验室三个方向的交汇点**：

| 选题 | 方法 | 对接方向 |
|---|---|---|
| **识别关键攻击节点** | 中心性 + 潮流约束 | 攻防建模 |
| **攻击下的级联失效预测** | 图学习 + 仿真 | **工业AI** |
| **GNN 检测拓扑攻击** | 图神经网络 | **入侵检测** |
| **最优防御资源分配** | 图优化 / 强化学习 | 工业AI |
| **信息-物理双层网络脆弱性** | 多层网络理论 | 前沿选题 |
