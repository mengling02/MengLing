## 研究方向

**核心选题：FDIA（虚假数据注入攻击）+ GNN（图神经网络）**

围绕电力系统状态估计的攻防展开，重点在于——

**物理约束是护城河。** 所有选题设计尽量用上潮流方程、灵敏度矩阵、KCL/KVL 等物理先验，
这是纯机器学习研究者不具备的视角。
