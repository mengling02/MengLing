# ⚡ 深度学习学习总目录（120 天 · 两阶段 · 从零到论文初稿）

> **学习主线**：数学地基 → 模型原理 → 论文精读 → 复现实验 → **专精深化 → 课题产出 → 投稿**
> **你的背景**：网络与信息安全专业研一，Python 熟悉，数学需补，电网知识为零
> **实验室方向**：贵州大学 工业AI与安全实验室（工业AI与智能体 / AI与数据安全 / 入侵检测 / 程序逆向 / 图像识别与安全 / 多模态大模型 / 假消息检测 / 元宇宙）
> **时间约束**：每天 1 小时（研一课业压力大）
> **内容形态**：每天一篇（知识清单 + 正文讲解 + 图文 + 末尾 🎬 视频检索）；每周末尾附 📄 配套论文清单
> **使用方式**：Typora 打开本文件，用侧边栏大纲（`Ctrl+Shift+1` 或左下角大纲面板）跳转

## 🧭 两个阶段，两种目标

| | **第一阶段**（Day 1-60 · 第 1-9 周） | **第二阶段**（Day 61-120 · 第 10-18 周） |
|---|---|---|
| **关键词** | 广度 · 地基 · 跑通闭环 | 专精 · 结构 · 真正出成果 |
| **要解决的问题** | "我看不懂论文，也写不出代码" | "我会跑通了，但方法没有差异化，投不出去" |
| **交付物** | 一份可投初稿 + 完整流程认知 | 一个**有创新点**的完整工作 + 投稿实战 |
| **难点** | 数学断层、概念太密 | 找到真正属于你的那一点增量 |

**为什么第二阶段要换挡？** 第一阶段的终点是"能读懂 + 能复现 + 有初稿"。但**通用深度学习套在电网上，几乎一定打不过一个调好参的 LSTM**——因为电力数据的价值不在"更深"，而在"结构"：**拓扑是图、攻击有物理约束、数据不能出域、决策是序贯的**。第二阶段补的就是这四块，它们才是你能写出差异化论文的地方。

## 🎬📄 配套资源说明（视频 + 论文）

**每天末尾**都有一段 `### 🎬 视频讲解`，形如：

| 平台 | 推荐搜索关键词 | 说明 |
|---|---|---|
| **B站** | [关键词链接](https://search.bilibili.com/all?keyword=关键词) | 该视频讲什么 |

> **为什么用"搜索链接"而不是固定视频链接？**
> 单个视频的 BV 号会失效、会被下架。**搜索链接永远有效**，且你能在结果里挑播放量高、讲得清楚的看。点开即跳到该平台的搜索结果页。抖音同理自动生成搜索链接。

**每周最后一天**末尾都有 `## 📄 第 N 周 · 配套论文清单`：

- 表格列出 **论文题名 / 出处年份 / 为什么读它 / 链接**
- 带 ⭐ 的是**强烈建议精读**的奠基性文献
- 链接优先给 **arXiv / DOI / IEEE Xplore / ACM** 等可稳定访问的地址；少数只能靠检索的会标注「检索题名」+ Google Scholar 搜索链接
- 每周清单末尾附 **阅读顺序建议**

> 💡 **重点推荐**：
> - **第 6 周论文清单**（论文阅读方法 + 电网场景）是第一阶段的入口，含 FDIA 检测与对抗攻击两条主线
> - **第 4 周**（RNN/LSTM 时序）是第一阶段含金量最高的一周 —— 电力数据 90% 是时序
> - **第 12 周论文清单**（对抗攻防与安全评估）是安全方向的**立身之本**
> - **第 17 周**（课题实战）是全程的**汇合点**，把前面所有能力合成一个完整工作
> - **第 18 周**（投稿与 rebuttal）决定你**能不能真的投出去**

### 第二阶段 · 做差异化（Day 61-120）

| 周次 | 主题 | 核心目标 | 为什么这一周不可省 |
|---|---|---|---|
| **W10** | 图神经网络与电网拓扑建模 | 把电网当图，掌握 GCN/GraphSAGE/GAT | 电网的**物理连接**就是先验，通用模型拿不到 |
| **W11** | 生成模型与数据增强 | VAE / GAN / 扩散，解决样本稀缺 | 攻击样本 <0.1%，**没数据就没有实验** |
| **W12** | 对抗攻防进阶 | FGSM/PGD/对抗训练/认证鲁棒性 | 安全方向的**立身之本**，没有攻击视角的检测器论文站不住 |
| **W13** | 物理信息神经网络与约束建模 | PINN、把潮流方程写进损失 | **选题 A 的落地工具**：物理不可行的解必须被排除 |
| **W14** | 强化学习与电网防御决策 | MDP / PPO / 攻防博弈建模 | 检测之后要**动作**，这才是防御闭环 |

**第二阶段的逻辑链**（每一周解决上一周留下的问题）：

```
W10 拓扑 → 怎么把"谁连谁"喂给模型
W11 数据 → 攻击样本太少，能不能造
W12 攻防 → 造出来的攻击，我的检测器扛得住吗
W13 物理 → 纯数据驱动的解，物理上可行吗
W14 决策 → 检测到了，然后呢
W15 隐私 → 各家数据不能共享，怎么联合训练
W16 前沿 → 能不能用大模型，代价是什么
W17 实战 → 把上面全部合成一个工作
W18 投稿 → 投出去，接受审判
```
