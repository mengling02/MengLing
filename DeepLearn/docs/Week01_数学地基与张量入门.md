## Day 1 —— 深度学习到底在干什么：从规则引擎到数据驱动的范式转变

> **一句话**：传统程序是"人写规则、机器执行"，深度学习是"人给数据、机器自己找规则"。这个转变是理解后面一切的前提。

### 一、AI / 机器学习 / 深度学习：三层包含关系

这三个词经常被混用，但它们是包含关系，不是并列关系：

```
人工智能（AI）
  └── 机器学习（ML）
        └── 深度学习（DL）
```

| 层级 | 定义 | 典型方法 |
|---|---|---|
| **人工智能** | 让机器表现出智能行为的统称 | 专家系统、搜索算法、规划 |
| **机器学习** | 从数据中自动学习规律，而非人工编码规则 | 决策树、SVM、随机森林 |
| **深度学习** | 用多层神经网络做机器学习 | CNN、RNN、Transformer |

**关键区别**：机器学习需要人工设计特征（feature engineering），深度学习能**自己从原始数据里学特征**。这是 2012 年之后 DL 爆发的根本原因。

### 二、深度学习的本质：学一个函数

所有深度学习任务，本质上都是在找一个函数：

```
f(x) → y
```

| 任务类型 | 输入 x | 输出 y | 例子 |
|---|---|---|---|
| **分类** | 一张图 / 一段序列 | 类别标签 | 这张图是猫还是狗 |
| **回归** | 历史负荷 | 未来负荷数值 | 明天 14:00 的用电量 |
| **生成** | 随机噪声 | 新样本 | 生成一张不存在的人脸 |

**"训练"就是调整这个函数里的参数**，让它在训练数据上预测得尽可能准。

### 三、和你的老本行对比：规则引擎 vs 深度模型

你熟悉入侵检测规则引擎（比如 Snort 规则）。两者差别值得说透：

| 维度 | 规则引擎 | 深度模型 |
|---|---|---|
| 知识来源 | 专家手工编写 | 从数据里自动学习 |
| 面对新攻击 | 需要人工加规则 | 可能自己泛化到相似模式 |
| 可解释性 | 高（规则可读） | 低（黑箱） |
| 误报率 | 靠规则精度 | 靠数据质量和训练 |
| 维护成本 | 随规则增长线性上升 | 随数据增长，需重训 |

> **一句话总结**：规则是"人写死"，模型是"数据里长出来"。两者不是替代关系——**工业场景里通常是"规则兜底 + 模型增强"的混合架构**。

### 四、和电网安全的关系

电网安全研究的核心矛盾是：**攻击手法在不断演化，而防御规则是静态的**。2015 年乌克兰电网事件中，攻击者用的是合法凭证和已知工具，传统基于签名的检测完全失效。

这正是深度学习的机会点：**从"匹配已知攻击特征"转向"学习正常行为基线，偏离即异常"**。本课程第 4 周和第 6 周会重点展开这条线。

## Day 2 —— 张量：深度学习的数据容器与形状心法

> **一句话**：张量就是"多维数组"，但你必须把**形状**当成第一等公民来对待 —— 后面 90% 的报错都源于形状不对。

### 一、张量的阶

| 阶 | 名称 | 形状示例 | 典型用途 |
|---|---|---|---|
| 0 阶 | 标量 | `()` | 损失值 |
| 1 阶 | 向量 | `(3,)` | 一个样本的特征 |
| 2 阶 | 矩阵 | `(3, 4)` | 批量样本 × 特征 |
| 3 阶 | 3D 张量 | `(N, T, F)` | 批量时序数据 |
| 4 阶 | 4D 张量 | `(N, C, H, W)` | 批量图像 |

**两种最常用的形状约定，务必记住**：

```
图像批次：[N, C, H, W]    批次, 通道, 高, 宽
时序批次：[N, T, F]        批次, 时间步, 特征数
```

### 二、形状操作七件套

```python
import torch
x = torch.randn(3, 4)

x.reshape(4, 3)          # [4, 3]   重新排列（必要时复制）
x.view(4, 3)             # [4, 3]   要求内存连续，否则报错
x.permute(1, 0)          # [4, 3]   交换轴顺序
x.transpose(0, 1)        # [4, 3]   交换两个轴（permute 的特例）
x.unsqueeze(0)           # [1, 3, 4] 在最前面加一个长度为 1 的维
x.squeeze(0)             # 从 [1,3,4] 变回 [3,4]（删长度为 1 的维）
torch.cat([x, x], dim=0) # [6, 4]   沿已有维度拼接
torch.stack([x, x], 0)   # [2, 3, 4] 新建一个维度来堆叠
```

**`cat` 与 `stack` 的区别**：`cat` 是"拼接已有维度"，`stack` 是"新建维度"。这是新手最容易混的一对。

### 三、`dim` 参数：新手最大的坑

```python
x = torch.randn(3, 4)
x.sum(dim=0)   # 形状 [4]   —— 第 0 维消失
x.sum(dim=1)   # 形状 [3]   —— 第 1 维消失
x.sum(dim=1, keepdim=True)  # 形状 [3, 1] —— 保留长度为 1 的维度
```

> **记忆口诀**：`sum(dim=k)` 之后，**第 k 维消失**。
> 每次写 `dim` 之前先默念这句，能省下大量调试时间。

### 四、广播机制：形状不同也能运算

三条规则，从右往左对齐：

1. **从最右边开始对齐**两个形状
2. 每一维**相等**，或**其中一个为 1**（则扩展），否则报错
3. **缺失的维度视为 1**

```python
a = torch.randn(3, 1, 4)
b = torch.randn(   2, 4)
(a + b).shape   # [3, 2, 4]
```

### 五、和电网安全的关系

一条 IEC 61850 的 MMS 报文序列，喂进网络前要先想清楚形状：

```
[N, T, F] = 样本数 × 时间步 × 特征数
```

- 一个"样本"可以是一段报文窗口（比如 1 秒的采样）
- `T` 是窗口内的时间步
- `F` 是每条报文的字段数（长度、类型、时间戳、校验位……）

**形状想错了，后面全错。** 第 4 周的时序模型、第 6 周的报文异常检测，都建立在这一天的基本功上。

## Day 3 —— 线性代数最小必要集：矩阵乘法与广播

> **一句话**：深度学习里的线代只有一个核心问题 —— **形状怎么变**。不要被"线性空间""特征分解"吓住，你需要的只是形状规则和范数。

### 一、矩阵乘法：形状规则是全部

```
(m, n) @ (n, p) = (m, p)
      ↑     ↑
   必须相等
```

```python
A = torch.randn(3, 4)
B = torch.randn(4, 5)
(A @ B).shape   # [3, 5]
```

**唯一要记的**：中间那两个维度必须相等，结果取首尾两个维度。

### 二、矩阵乘法的几何意义

矩阵乘法不只是"数字相乘"，它是**对向量做线性变换**。3Blue1Brown 的《线性代数的本质》把这层讲得最透：

- 一个矩阵可以理解为"把空间拉伸、旋转、剪切"
- 矩阵乘向量 = 把这个变换作用到向量上
- 单位矩阵 = 不做任何变换

**为什么这层理解重要**：神经网络的每一层 `y = Wx + b` 就是在做一次线性变换，激活函数负责"把空间掰弯"。整个网络就是在高维空间里反复拉伸、折叠。

### 三、转置、单位矩阵、逆矩阵

```python
A.T                      # 转置：行列互换
torch.eye(4)             # 4×4 单位矩阵
torch.linalg.inv(A)      # 逆矩阵（仅方阵且可逆）
```

| 概念 | 定义 | 用途 |
|---|---|---|
| 转置 `Aᵀ` | 行列互换 | 注意力机制里 `Q @ K.T` |
| 单位矩阵 `I` | 对角线为 1 | 定义逆矩阵 |
| 逆矩阵 `A⁻¹` | `A @ A⁻¹ = I` | 解线性方程组（闭式解） |

### 四、范数：惩罚什么就得到什么

| 范数 | 公式 | 惩罚特点 | 效果 |
|---|---|---|---|
| **L1** | `Σ\|xᵢ\|` | 惩罚绝对值之和 | 产生**稀疏解**（很多权重恰好为 0） |
| **L2** | `√(Σxᵢ²)` | 惩罚平方和 | 抑制**大权重**，权重整体变小 |
| **L∞** | `max(\|xᵢ\|)` | 惩罚最大值 | 控制最坏情况 |

**这直接对应 Day 12 的正则化**：权重衰减（weight decay）就是给损失加 L2 惩罚项。

```python
torch.linalg.norm(x, p=1)   # L1
torch.linalg.norm(x, p=2)   # L2
```

### 五、和电网安全的关系

电力系统状态估计的核心方程是一个线性模型：

```
z = H·x + e
```

- `z`：量测量（节点电压、支路功率）
- `H`：量测矩阵（描述"状态"如何映射到"量测"）
- `x`：状态量（节点电压幅值与相角）
- `e`：量测误差

**FDI 攻击的数学基础就在这里**：攻击者构造 `Δz = H·Δx`，使得残差 `r = z - H·x̂` 保持不变。这在 Day 38 会详细展开。

## Day 4 —— 微积分：只要导数与链式法则

> **一句话**：你不需要学完整本微积分。深度学习只用一件事 —— **链式法则**，它也是反向传播的全部数学。

### 一、导数：变化率与切线斜率

导数衡量"输入变一点，输出变多少"：

```
f'(x) = lim(Δx→0) [f(x+Δx) - f(x)] / Δx
```

**必须背下来的几个**：

| 函数 | 导数 |
|---|---|
| `xⁿ` | `n·xⁿ⁻¹` |
| `eˣ` | `eˣ` |
| `ln x` | `1/x` |
| `σ(x) = 1/(1+e⁻ˣ)` | `σ(x)·(1-σ(x))` |

### 二、偏导数与梯度

**偏导数**：多元函数里"只对某一个变量求导"，其他变量当作常数。

**梯度**：所有偏导数堆成的向量。

```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

**梯度的几何意义**：指向函数值**增长最快**的方向。

### 三、梯度下降：为什么是"减去"梯度

```python
x = x - lr * grad
```

因为梯度指向**增长最快**方向，所以要往**反方向**走才能下降。这就是"减去"的原因，不是约定，是几何必然。

**学习率 lr 的作用**：
- 太大 → 在最低点两侧反复横跳，甚至发散
- 太小 → 收敛极慢，半天不动

### 四、链式法则：反向传播的全部数学

```
d/dx f(g(x)) = f'(g(x)) · g'(x)
```

**多层网络就是链式法则的反复应用**：

```
x → W₁ → σ → W₂ → ŷ → L

∂L/∂W₁ = ∂L/∂ŷ · ∂ŷ/∂W₂ · ∂(σ) · ∂(W₁x)/∂W₁
         └──────── 一串偏导相乘 ────────┘
```

> **核心直觉**：梯度像接力棒，从最后一层往前传，每过一层就乘上那一层的"本地梯度"。这就是 Day 8 要展开的"上游梯度 × 本地梯度"。

### 五、必须手推的三道题

1. `y = 3x² + 2x`，求 `dy/dx`
2. `y = (2x + 1)³`，用链式法则求导
3. `y = σ(x) = 1/(1+e⁻ˣ)`，证明 `σ'(x) = σ(x)(1-σ(x))`

**第 3 题为什么重要**：Sigmoid 的导数会在反向传播里反复出现。而且它的最大值只有 0.25（小于 1），这就是梯度消失的根源。

### 六、和电网安全的关系

梯度不仅是训练工具，也是**攻击工具**。对抗样本的核心方法 FGSM 就是：

```
x_adv = x + ε · sign(∇ₓ L(x, y))
```

即"沿着让损失增大的方向，给输入加一小步扰动"。第 6 周会用它攻击自己的检测器。

## Day 5 —— 自动求导 autograd：让框架替你算梯度

> **一句话**：autograd 是 PyTorch 的灵魂。它把 Day 4 的链式法则自动化了 —— 你只需要写前向，梯度自己会算出来。

### 一、三件套：requires_grad / backward / grad

```python
import torch

x = torch.tensor(2.0, requires_grad=True)   # ① 标记需要求导
y = x ** 2 + 3 * x                           # 前向：构建计算图
y.backward()                                 # ② 反向：自动求导
print(x.grad)                                # ③ 取梯度 → 7.0
```

手算验证：`dy/dx = 2x + 3 = 2×2 + 3 = 7` ✅

**这个例子对不上就重来** —— 第 8 天的反向传播必崩。

### 二、计算图：前向构建，反向求导

autograd 在**前向传播时**悄悄记录了一张图：

```
x ──┬── x² ──┐
    │         ├── + ── y
    └── 3x ──┘
```

`y.backward()` 时沿这张图**反向**走一遍，用链式法则算出每个叶子节点的梯度。

### 三、梯度累加：为什么必须 zero_grad

```python
x = torch.tensor(2.0, requires_grad=True)
for i in range(3):
    y = x ** 2
    y.backward()
    print(x.grad)   # 4, 8, 12 —— 梯度在累加！
```

**原因**：PyTorch 默认把新梯度**加到** `.grad` 上，而不是覆盖。

**后果**：如果训练循环里忘了 `optimizer.zero_grad()`，梯度会像滚雪球一样越滚越大，训练直接失控。

```python
optimizer.zero_grad()   # 清空梯度
loss.backward()         # 算新梯度
optimizer.step()        # 更新参数
```

> **记住这个顺序**：清空 → 反向 → 更新。顺序错了就出事。

### 四、切断梯度：no_grad 与 detach

```python
with torch.no_grad():       # 上下文管理器：整块代码不建计算图
    pred = model(x)

feat = h.detach()           # 从计算图里摘出来，后续操作不记录梯度
```

| 场景 | 用什么 | 为什么 |
|---|---|---|
| 推理 / 评估 | `torch.no_grad()` | 省显存、加速 |
| 固定某部分特征 | `.detach()` | 阻断梯度回传 |
| 只更新部分参数 | `requires_grad=False` | 冻结层 |

### 五、和电网安全的关系

autograd 不只是训练工具。**对抗攻击生成器就靠它**：

```python
x_adv = x.clone().detach().requires_grad_(True)
loss = criterion(model(x_adv), target)
loss.backward()                        # 求"输入"的梯度，不是参数的
x_adv = x_adv + eps * x_adv.grad.sign()  # 沿梯度方向扰动输入
```

注意这里的巧妙之处：**梯度是相对于输入求的，不是相对于权重**。同一个 autograd 机制，换个求导对象就从"训练"变成了"攻击"。

## Day 6 —— 概率：从最大似然推出交叉熵

> **一句话**：所有损失函数都来自同一个源头 —— **最大似然估计**。搞懂这条推导，你就再也不用背"分类用交叉熵、回归用 MSE"了。

### 一、条件概率与贝叶斯

```
P(A|B) = P(A∩B) / P(B)         条件概率
P(A|B) = P(B|A)·P(A) / P(B)    贝叶斯公式
```

**贝叶斯的直觉**：先验（P(A)）→ 看到证据（B）→ 后验（P(A|B)）。模型训练就是在做这件事：先有一个参数假设，看到数据后更新它。

### 二、最大似然估计 MLE

**核心思想**：找一组参数 θ，使得**观测到的数据出现概率最大**。

```
θ* = argmax P(数据 | θ)
```

### 三、最重要的一次推导：分类为什么用交叉熵

**第 1 步**：假设标签服从类别分布，模型输出经 Softmax 后是概率：

```
P(y = c | x) = softmax(z)ᵢ
```

**第 2 步**：写出整个数据集的似然（各样本独立，概率相乘）：

```
L = ∏ softmax(z)ᵢ
```

**第 3 步**：取对数，把"乘"变成"加"（不改变最大值位置）：

```
log L = Σ log softmax(z)ᵢ
```

**第 4 步**：最大化 `log L` = 最小化 `-log L`：

```
损失 = -Σ log softmax(z)ᵢ    ← 这就是交叉熵
```

> **结论**：交叉熵不是"设计"出来的，是**从最大似然推导出来的**。回归用 MSE 同理（假设噪声服从高斯分布，取对数后平方项留下来）。

### 四、三个相关概念

| 概念 | 公式 | 含义 |
|---|---|---|
| **交叉熵** | `H(p,q) = -Σ pᵢ log qᵢ` | 用分布 q 去编码分布 p 的代价 |
| **KL 散度** | `D(p‖q) = Σ pᵢ log(pᵢ/qᵢ)` | 两个分布的"距离"（不对称） |
| **信息熵** | `H(p) = -Σ pᵢ log pᵢ` | 分布本身的不确定度 |

**关系**：`H(p,q) = H(p) + D(p‖q)`。因为训练时 `H(p)` 固定（标签不变），所以最小化交叉熵 = 最小化 KL 散度。

### 五、和电网安全的关系

异常检测里的"正常概率低"怎么量化？三条路：

| 方法 | 怎么算异常分数 |
|---|---|
| **重建误差** | 自编码器重建得差 → 异常 |
| **密度估计** | 用高斯混合等模型估 P(x)，P(x) 低 → 异常 |
| **负对数似然** | `-log P(x)` 大 → 异常 |

这三条都是"概率视角"的不同实现。第 26 天的自编码器异常检测就走第一条路。

## Day 7 —— 复盘 + 线性回归从零实现

> **一句话**：不调 `nn.Linear`，用纯张量手写一次线性回归。这一步做通了，你就真正拥有了"训练一个模型"的能力。

### 一、完整训练循环的五个动作

```python
for epoch in range(num_epochs):
    # ① 前向：算预测
    y_pred = X @ w + b

    # ② 算损失
    loss = ((y_pred - y) ** 2).mean()

    # ③ 清空梯度（回顾 Day 5 的累加陷阱）
    if w.grad is not None:
        w.grad.zero_()
        b.grad.zero_()

    # ④ 反向：算梯度
    loss.backward()

    # ⑤ 更新参数
    with torch.no_grad():
        w -= lr * w.grad
        b -= lr * b.grad
```

**注意第 ⑤ 步的 `torch.no_grad()`**：更新参数本身不该被记录进计算图，否则图会无限增长。

### 二、为什么用 `no_grad` 包住更新

如果不包，`w -= lr * w.grad` 这个操作会被 autograd 记录，形成新的计算图节点。下一轮迭代时图会继续累积，显存爆掉。

**规则**：凡是"不需要梯度的参数更新操作"，都要放进 `torch.no_grad()`。

### 三、判断训练是否收敛

把损失曲线画出来，看三种形态：

| 曲线形态 | 诊断 | 对策 |
|---|---|---|
| 平稳下降后趋平 | ✅ 正常收敛 | 可以停了 |
| 上下剧烈震荡 | 学习率太大 | 调小 lr（÷10） |
| 缓慢直线下降不趋平 | 学习率太小 / 迭代不够 | 调大 lr 或增加轮数 |
| 损失变 NaN | 学习率过大 / 梯度爆炸 | 大幅调小 lr，加梯度裁剪 |

### 六、和电网安全的关系

**今天你写的这个线性回归，就是状态估计的骨架。** 这不是类比，是同一件事：

| 线性回归（你今天写的） | 加权最小二乘状态估计（Day 37 会学） |
|---|---|
| `y = Xw` | `z = Hx + e` |
| 设计矩阵 `X` | 量测矩阵 `H` |
| 闭式解 `w = (XᵀX)⁻¹Xᵀy` | `x̂ = (HᵀH)⁻¹Hᵀz` |
| 损失 `‖y - Xw‖²` | 残差 `r = z - Hx̂` |
| 特征 `x` | 状态 `x`（节点电压幅值与相角） |

**所以你在 Day 6 推的"从 MLE 到最小二乘"，在电力系统里是一条现成的公式。** 电力行业用了几十年的 WLS 状态估计，数学上就是"假设量测噪声是高斯的、做极大似然"——和你在 Day 6 做的事完全一样。

**而 FDI 攻击的全部巧妙之处，就藏在这个式子里**：

```
攻击者不直接改 x，而是改 z：z_bad = z + Δz
如果 Δz = H·Δx，那么 x̂_bad = (HᵀH)⁻¹Hᵀ(z + HΔx) = x̂ + Δx
                              ↑ 状态被偏移了 Δx

而残差：r_bad = z_bad - H·x̂_bad = (z + HΔx) - H(x̂ + Δx) = z - Hx̂ = r
                              ↑ 残差一字不变 → BDD 完全看不见
```

**你今天能写出 `w = (XᵀX)⁻¹Xᵀy`，就已经具备了看懂这条推导的全部工具。** 剩下的只是把 `X` 换成 `H`。

> 💡 **如果今天只记一件事**：线性回归不是"热身题"，它是电网安全的数学地基。**后面 100 天你会反复回到这个式子。**
