# 不良数据检测与状态估计防御（BDD）

## 一句话

电网的**第一道（也是唯一一道）数据完整性防线**：通过检查量测残差是否异常，判断数据有没有被污染。而 [[虚假数据注入攻击(FDIA)]] 的全部意义，就是绕过它。

## 核心机制（小白版）

1. 用[[状态估计]]求出 $\hat{x}$
2. 算残差 $r = z - H\hat{x}$
3. 构造检验统计量（常用**卡方检验**）：

$$J(\hat{x}) = \sum_{i=1}^{m} \left(\frac{r_i}{\sigma_i}\right)^2$$

4. 若 $J(\hat{x}) > \chi^2_{(m-n),\alpha}$（自由度 = 量测数 $m$ − 状态数 $n$）→ **报警：存在不良数据**

5. **最大标准化残差法**：找出残差最大的那个量测，把它剔除，重新估计（循环直到通过检验）

## 它为什么不够用

| 弱点 | 说明 |
|---|---|
| **可被精确绕过** | 攻击者构造 $a = Hc$ 时残差不变，BDD 完全失效 |
| **检测率低** | 对小幅、协调一致的多点攻击几乎无感 |
| **依赖拓扑** | 拓扑本身若被篡改（如开关状态攻击），检测前提就没了 |
| **只能事后** | 是"事后校验"，不是"主动防御" |
| **对 ML 不友好** | 传统 BDD 是静态阈值，面对动态/时变攻击不适应 |

## 主流防御路线（论文里会反复出现）

1. **保护关键量测（PMU 部署优化）** — 用最少的钱保护最关键的节点，让攻击成本上升
2. **[[移动目标防御(MTD)]]** — 主动扰动线路电抗/传感器增益，让攻击者算不准 $H$
3. **机器学习检测** — 用自编码器/LSTM/GNN 学习正常模式，检测异常（但会面对[[对抗样本攻击]]）
4. **物理一致性校验** — 结合物理约束（如 KCL/KVL）验证数据自洽
5. **分布式/联邦检测** — 多区域协同，避免单点被攻破（见[[联邦学习]]）

## 关键公式

残差定义：

$$r = z - H\hat{x}$$

- $z$：量测向量
- $H$：量测雅可比矩阵
- $\hat{x}$：[[状态估计]]给出的状态估计值
- $r$：量测残差，即"实测值 − 由估计状态反推出来的量测值"

白话：**如果模型和量测都是干净的，残差里应该只剩下噪声；残差异常大，就说明有坏数据。**

卡方检验统计量（加权残差平方和）：

$$J(\hat{x}) = r^{\mathsf T} W r = \sum_{i=1}^{m}\left(\frac{r_i}{\sigma_i}\right)^{2}$$

- $W$：量测权重矩阵，$W = \mathrm{diag}(1/\sigma_i^{2})$
- $\sigma_i$：第 $i$ 个量测的误差标准差
- $m$：量测数量；判据为 $J(\hat{x}) > \chi^{2}_{(m-n),\,\alpha}$ 时报警
- $\chi^{2}_{(m-n),\,\alpha}$：自由度为 $m-n$（量测数 − 状态数）、显著性水平为 $\alpha$ 的卡方分位点

白话：**把每个残差按它自己的噪声水平归一化后平方相加，得到一个"总离谱程度"**；它在正常时服从卡方分布，所以能设一个统计上合理的门限。自由度就是系统的冗余度——冗余越多，越能发现坏数据。

被绕过的条件（BDD 的致命弱点）：

$$a \in \mathrm{range}(H) \quad \Longrightarrow \quad r_{bad} = r$$

- $a$：攻击者注入的量测偏差向量
- $\mathrm{range}(H)$：矩阵 $H$ 的列空间
- $r_{bad}$：被攻击后重新计算得到的残差

白话：**只要攻击向量落在 $H$ 的列空间内，残差与检验统计量都完全不变，BDD 无感**——这正是 [[虚假数据注入攻击(FDIA)]] 的隐蔽条件。

## 用网安的话说（小电解读）

- BDD ≈ **基于签名的 IDS**：只挡已知模式，挡不住精心构造的绕过。
- [[虚假数据注入攻击(FDIA)]] ≈ **针对 IDS 的绕过技术**：语法合法、语义恶意，签名匹配直接失效。
- 卡方检验 ≈ **带统计门限的误用检测**：不靠特征库，靠"残差只应含噪声"这个白盒假设。

### 相同点

1. **对抗逻辑同构**。FDIA 的条件 $a \in \mathrm{range}(H)$，本质是"存在合法输入使检测器输出不变"，等同语法合法化绕过。
2. **误报权衡相同**。BDD 用显著性水平 $\alpha$ 控误报，$\alpha$ 调小则漏报上升 —— 就是你在调的 IDS 门限。
3. **评估体系可搬**。混淆矩阵、TPR/FPR 在电网论文里同样通用（见[[入侵检测系统(IDS)]]）。

### 不同点 / 难点

1. **检测依据是物理模型，不是流量模式**。BDD 拿不到"攻击报文长什么样"，只有[[状态估计]]给出的期望值。**依赖的是物理规律而非模型容量 —— "堆模型刷指标"常打不过一个写对约束的简单方法。**
2. **告警后的处置完全不同**。IT 里可封 IP、隔离主机；电网里只能"剔除该量测重新估计"，因为不能停一台变压器。**检测与处置被物理约束切开了。**
3. **对抗空间带物理约束**。[[对抗样本攻击]]靠 $\ell_p$ 扰动，电网攻击向量必须落在 $H$ 的列空间内，约束更强，反而让"需要多大扰动"变成可解析计算的问题。

### 电网场景的特殊之处

1. **冗余度是天然检测资源**。卡方检验自由度是 $m-n$，**冗余越多越能发现坏数据**，IT 里没有对应物，测点布点优化因此是正经研究问题。
2. **攻击者需要拓扑知识，这既是门槛也是破口**。构造 $a=Hc$ 要求知道 $H$；拓扑被篡改时检测前提就崩。**拓扑安全是没被吃透的缝隙。**
3. **检测永远慢一步**。所以对策是[[移动目标防御(MTD)]]这类"让攻击者算不准 $H$"的主动扰动。

切入建议：**别一上来就做"深度学习检测 FDIA"**，那条路极拥挤，已被[[20_Research/Papers/L3-工控与电网安全/A_Survey_of_Machine_Learning_Methods_for_Detecting_False_Data_Injection_Attacks|022 FDIA 检测的机器学习方法综述]]总结完。更值得做**"约束边界"型题目**：分析"多大扰动预算、多少拓扑信息才能绕过 BDD"，或做"物理一致性校验 + 学习型检测"的融合并诚实评估误报代价。这类题正好卡在"工业 AI 与安全"的交界：既要物理建模，又要处理对抗性，还能落到"检测率被高估"这个批判性议题上。
