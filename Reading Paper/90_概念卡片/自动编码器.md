# 自动编码器

## 一句话

一个"压缩再还原"的神经网络：只学过正常数据，所以正常数据能还原得出来，异常数据还原不好，误差大就报警。

## 为什么重要

在电网安全里，**攻击样本几乎拿不到**。你不可能真的去攻击一座变电站来采集训练数据，仿真出来的攻击又和真实攻击有差距。这个现实决定了：**无监督方法比监督方法更实用**。

自动编码器（AE）是无监督异常检测里最经典、最好落地的一个。它只需要正常数据就能训练，不需要任何攻击标签——这正好匹配电网场景的数据现实。

它也是理解整个"表示学习 + 重构误差"范式的入口：[[深度学习检测方法]]里的很多变体（去噪自编码器、稀疏自编码器、变分自编码器）都是它的衍生。理解了 AE，你就理解了"用重构误差当异常分数"这一整套思路。

同时它也是**攻防对抗的绝佳战场**。电网里很多异常检测器都是在线训练的 AE，而在线训练意味着攻击者有机会通过污染训练数据来"教坏"检测器——这是投毒攻击最典型的落点之一。

## 核心要点

| 变体 | 核心改动 | 解决的问题 | 在电网里的用法 |
|---|---|---|---|
| 基础 AE | 压缩到低维再还原 | 学习数据的主要结构 | 量测断面的异常评分 |
| 去噪 AE（DAE） | 输入加噪、目标是还原干净数据 | 提升鲁棒性与泛化 | 量测噪声大的场景 |
| 稀疏 AE（SAE） | 限制隐层激活的稀疏度 | 学到更本质的特征 | 提取稳定运行模式 |
| 变分 AE（VAE） | 隐空间是概率分布 | 可生成样本、可算似然 | 生成式检测与数据增强 |
| 时序 AE（LSTM-AE） | 编解码器换成序列模型 | 处理时间相关性 | 负荷/频率序列异常检测 |
| 图 AE | 编码器在图上做消息传递 | 利用电网拓扑结构 | 结合拓扑的异常定位 |

一个重要的工程细节：**阈值怎么定，比网络怎么设计更影响效果**。常见做法是用正常数据的重构误差分布取分位数（比如 95% 或 99% 分位）作为阈值，而不是拍脑袋定一个数。

## 关键公式

自动编码器由编码器和解码器两部分组成：

$$h = \sigma\bigl(W_e x + b_e\bigr), \qquad \hat{x} = \sigma\bigl(W_d h + b_d\bigr)$$

- $x$：输入样本（一条量测断面，或一段时序窗口）
- $W_e, b_e$：编码器的权重与偏置
- $h$：隐层表示，维度远小于输入，所以叫"瓶颈层"
- $W_d, b_d$：解码器的权重与偏置
- $\hat{x}$：重建出来的输入
- $\sigma(\cdot)$：激活函数，通常是 ReLU 或 sigmoid

白话：**先把数据压进一个很窄的通道，再让它自己复原**。因为通道很窄，网络只能记住数据里最主流的结构——正常运行的规律。

训练目标是最小化重建误差：

$$\min_{W_e,W_d} \;\frac{1}{N}\sum_{i=1}^{N}\bigl\lVert x_i - \hat{x}_i \bigr\rVert_2^2$$

- $N$：训练样本数
- $\lVert x_i - \hat{x}_i\rVert_2^2$：第 $i$ 个样本的重建误差平方和

检测阶段的判定规则：

$$\text{异常分数}\ s(x) = \lVert x - \hat{x}\rVert_2^2, \qquad s(x) > \tau \Rightarrow \text{判为异常}$$

- $s(x)$：异常分数，就是重建误差
- $\tau$：阈值，通常取正常数据 $s$ 分布的高分位数

白话：**训练时只喂正常数据，模型就只会还原正常数据；来一个它没见过的模式，它还原不出来，误差就大了**。误差超过 $\tau$ 就报警。

## 用网安的话说（小电解读）

自编码器做异常检测，你在网安里应该见过：训练集只放正常流量，用重建误差检测 DGA 域名、异常 URL、恶意流量。搬到电网上，输入从"网络流特征"换成"量测断面或负荷序列"，其它几乎一模一样。

相同点：
- 都是**半监督式的"正常样本建模"**：只用正常数据，不需要攻击标签；
- 都用重建误差当异常分数，都面临阈值选择的难题；
- 都有同样的软肋——**如果异常数据恰好落在正常数据流形附近（比如只在某个维度上轻微偏移），重建误差不会明显变大，就会漏报**。

不同点（电网的特殊之处）：
- **物理约束让"漏报"更容易发生**。隐蔽性 FDIA 的特点正是"整体上看起来完全正常"，只是在特定方向上有偏移。基础 AE 对这种偏移不敏感，所以电网里更常见的是**在 AE 上加物理约束**（比如让隐层表示满足潮流方程的近似关系），或者干脆用多个 AE 分别监测不同区域；
- **数据是时序且强相关的**。电网量测不是独立同分布样本，前后时刻高度相关。所以纯全连接 AE 效果往往不如 LSTM-AE 或时序图 AE；
- **在线训练带来投毒面**。电网数据分布会随季节和检修漂移，所以不少方案采用在线更新。而在线更新意味着攻击者可以**缓慢地向训练数据里注入精心构造的样本**，让 AE 把攻击模式学成"正常"。这正是"温水煮青蛙"式攻击的原理，也是电网里 AE 检测器最现实的威胁；
- **异常的语义有歧义**。AE 报出来的异常可能是故障、可能是检修、可能是攻击，需要额外的判别逻辑。

研究切入点：一是**鲁棒 AE 训练**（对抗投毒、对抗样本的加固），这是当前明确的开放问题；二是**物理信息 AE**（把潮流约束编进网络结构或损失）；三是**多 AE 协同**（每个区域一个 AE，用一致性来发现局部隐蔽偏移）。这三条路都有清晰的论文空间，而且第二条几乎不需要你深入电网业务知识，只要会用潮流方程作为约束即可。
