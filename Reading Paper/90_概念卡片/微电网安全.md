# 微电网安全

## 一句话

微电网是一小片能自己发电、自己带负荷、还能和主网"断开单过"的电网，它靠通信和控制器维持平衡 —— **通信一断，这片电网就可能自己崩掉**。

## 为什么重要

[[智能电网]]是"大电网 + 信息化"，而微电网是"小电网 + 全自主"。它通常由光伏/风机 + 储能 + 少量可控电源组成，可以在**并网模式**（和主网连着，互通有无）和**孤岛模式**（断开主网，独立运行）之间切换。

这个"可孤岛"的特性，既是它的价值（主网故障时还能保住关键负荷），也是它的安全难点：

1. **孤岛运行时没有大电网兜底**。主网是一个近乎无限的"缓冲池"，频率电压掉了有人顶；孤岛微电网里，**任何一台设备的行为异常都会立刻反映成频率/电压波动**，容错空间小得多。
2. **它必须靠通信协同**。分布式控制（下垂控制、一致性算法）要求各单元持续交换频率、功率等信息。这跟[[SCADA系统]]那种"集中采集"模式不同，它是**闭环、实时、点对点**的控制通信，一旦被篡改或延迟，控制器会基于错误信息动作。
3. **它是[[虚拟电厂]]、[[电动汽车充电安全]]的技术底座**。理解微电网安全，等于拿到了新型电力系统安全的半张地图。

在[[电力系统弹性(Resilience)]]的框架里，微电网本身就是一种"弹性资源"——但它自己也需要弹性。

## 核心要点

| 维度 | 要点 | 说明 |
|---|---|---|
| 两种运行模式 | 并网模式 | 主网提供频率/电压支撑，微电网跟随 |
| | 孤岛模式 | 自主维持频率电压，对扰动极其敏感 |

| | 认证与轻量密码 | 适配资源受限的现场设备 |

## 关键公式

孤岛微电网最核心的物理约束是**功率平衡**（这也是攻击者最想破坏的等式）：

$$\sum_{i\in\mathcal{G}}P_{i}-\sum_{j\in\mathcal{L}}P_{j}-P_{loss}=\frac{dE_{k}}{dt}\ \Big/\ (\text{惯量项})\ \Rightarrow\ \text{频率偏差}\ \Delta f$$

更直观地写成频率响应形式：

$$\Delta f \propto \frac{\sum P_{gen}-\sum P_{load}}{K}$$

- $\sum P_{gen}$：所有发电单元（含逆变器、储能）输出的有功功率之和
- $\sum P_{load}$：负荷消耗的有功功率之和
- $P_{loss}$：网络损耗
- $K$：系统的频率响应/惯量系数 —— **微电网里 $K$ 很小**，因为都是电力电子设备（见[[逆变器与电力电子安全]]）
- $\Delta f$：频率偏差，$K$ 越小、功率缺额越大，$\Delta f$ 越大

**白话**：微电网"体量小、惯量小"，所以**同样的功率缺额会造成远大于主网的频率跌落**。攻击者只要让发电和负荷的差值出现缺口（比如伪造负荷、篡改储能指令、切断某台逆变器），就能快速把频率推离安全区。（这里的 $K$ 是示意性写法，具体建模因控制方式而异。）

## 用网安的话说（小电解读）

微电网在架构上非常像你熟悉的一类系统：**一个带自动故障转移的小型集群**。

- **并网/孤岛切换 ≈ 主备切换**。平时挂在大集群（主网）下面，出事了自动切到独立运行。攻击者的经典打法就是"**切换过程中的窗口期**"——切换瞬间状态最脆弱，通信中断、状态不同步、认证空白都集中在这一刻。
- **分布式控制 ≈ 分布式一致性协议（如 Raft/Paxos）**。各节点靠互相交换信息达成一致。你立刻能想到的漏洞：**拜占庭节点**（篡改信息的节点）、**通信分区**（split-brain，两边各自以为自己是主）、**DoS 导致超时误判**。电网的对应物叫"分布式控制的一致性收敛被破坏"，本质完全一样。
- **残差检测 ≈ 用模型做完整性校验**。论文 081 那类方法，就是用物理模型算"应该是什么样"，再看实测对不对，和你用基线做异常检测是同一套思路。

电网场景的特殊之处：

1. **控制回路是闭环实时的**。IT 里你篡改一条消息，顶多让某个服务算错一次；微电网里篡改一条功率信息，控制器会**基于错误信息真的去调功率**，然后产生新的物理状态，再被测量、再影响控制 —— 错误会被物理过程放大。这叫"控制-物理耦合"，是 CPS 攻击区别于纯 IT 攻击的根本。
2. **小惯量 = 低容错**。IT 系统可以重试、可以降级；微电网的频率是"现在就掉"，没有重试机会。
3. **设备资源受限**。现场设备算力和电量有限，传统重密码方案（TLS + 证书链）不一定跑得动，所以"轻量认证"是刚需，这也解释了论文 088 那类电池指纹认证的动机。

切入建议：微电网安全里"**分布式控制的拜占庭容错**"和"**轻量认证**"两块，最能用上你的网安背景，而且文献相对不饱和。
