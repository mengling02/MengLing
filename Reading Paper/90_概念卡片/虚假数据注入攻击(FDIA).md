# 虚假数据注入攻击（FDIA）

## 一句话

攻击者**不破坏设备、不中断通信**，只悄悄篡改传给调度中心的量测数据，让电网的"眼睛"看到错误的现实 —— 从而诱导错误决策，最终引发电网事故。

## 为什么它是最经典的电网攻击

2009 年 Liu、Ning、Reiter 提出后，它成了电力 CPS 安全研究的**绝对主线**。
原因很简单：它**绕过了传统的"坏数据检测"**，是"完美犯罪"式的攻击。

## 攻击的数学本质（小白版）

回顾[[状态估计]]：量测 $z$，状态 $x$，$z = Hx + e$（$H$ 是拓扑决定的雅可比矩阵）。
残差检测：$r = z - H\hat{x}$，若 $\|r\|$ 超过阈值就报警。

攻击者注入 $a$，得到 $z_{bad} = z + a$。若令

$$a = Hc$$

（$c$ 是任意攻击者选定的状态偏移向量），则

$$z_{bad} = H(x + c) + e$$

**关键结论**：新的残差 $r_{bad} = r$，**与攻击前完全相同**！

也就是说：攻击者成功让状态估计输出 $x + c$，而**残差检测完全无感**。
代价是：攻击者必须知道 $H$（即**掌握电网拓扑结构**）。

## 攻击分类（记住这几类就够了）

| 类型 | 特点 | 难度 |
|---|---|---|
| **完全信息 FDIA** | 攻击者知道完整 $H$ 矩阵 | 低（数学上完美） |
| **部分信息 FDIA** | 只知道局部拓扑，需近似/搜索 | 中 |
| **盲 FDIA** | 用历史数据学习 $H$ | 高（但 2017 年已被证明可行） |
| **负载重分配（LR）攻击** | 子集攻击，隐蔽性更强 | 高 |
| **数据完整性攻击 vs 可用性攻击** | 篡改 vs 拒绝服务 | — |

## 关键公式

攻击者构造的注入向量满足：

$$a = Hc$$

- $a$：注入到量测上的偏差向量
- $H$：量测雅可比矩阵，由网络拓扑与线路参数决定（攻击者必须事先掌握它，这就是"掌握拓扑"的含义）
- $c$：攻击者任意选定的状态偏移向量，即他**希望调度员相信的那个错误状态偏差**

代入量测方程后：

$$z_{bad} = z + a = H(x + c) + e$$

- $z_{bad}$：被篡改后的量测向量
- $x + c$：状态估计将会输出的（错误）结果
- $e$：原有的量测噪声，攻击者并未改变它

白话：**只要注入向量落在 $H$ 的列空间里，残差就一点没变**——状态估计被悄悄推偏了 $c$，而 [[不良数据检测与状态估计防御|BDD]] 完全看不出异常。这也说明隐蔽攻击的可行性直接取决于攻击者掌握多少 $H$ 的信息。

## 用网安的话说（小电解读）

一句话：**FDIA ≈ 一次"语法完全合法、语义彻底篡改"的篡改，专门绕过基于完整性校验的 IDS。**

- **≈ 完整性校验绕过，但不改指纹**。BDD 只问"这组量测符不符合物理规律"，攻击者就照物理规律编一组假数据给它——你报告里用的 **valid-but-malicious**。$a = Hc$ 就是：把"想骗调度员相信的偏移量 $c$"**编码成量测空间里一串合法改动**，残差 $r$ 一毫不差，**等于改了文件、哈希却没变**。

### 相同点

1. **攻击链同构**。侦察（拿到拓扑 $H$）→ 武器化（算 $a$）→ 投递（中间人改量测/通信）→ 影响（错误调度决策），kill chain 直接套用。
2. **检测思路的演进就是 IDS 演进史**。基于模型（残差 ≈ 规则型 IDS）、数据驱动（自编码器/LSTM ≈ 机器学习 IDS）、物理加数据融合（GNN ≈ 混合检测），再到用 [[移动目标防御(MTD)]] 让攻击打不准；[[对抗样本攻击]] 的扰动最小化亦然。

### 不同点 / 难点

1. **门槛被物理知识抬高**。打 Web 服务不用懂业务；这里**必须先掌握拓扑和量测模型**才能算 $a$，攻击者常因此是内部人或潜伏者（见 [[高级持续性威胁(APT)]]）。
2. **约束是硬的**。对抗样本里像素可任意微调，电网量测却要满足功率平衡等约束，攻击空间小一圈。反过来，**"在物理可行集内搜隐蔽扰动"就很值得做**。
3. **危害是物理的**。数据被改在 IT 里止于信息层，FDIA 终点是错误调度决策。

### 电网场景的特殊之处

1. **无监督是主流**。真实攻击样本极稀缺，且 [[电力信息物理系统(CPS)]] 的闭环耦合让"仿真数据多真"存疑。
2. **假数据 vs 真故障**。故障破坏物理一致性，精心构造的 FDIA 不会——**这是本方向独有的题**。
3. **检测≠定位**。测出"有坏数据"容易，**指认哪几个量测被改**难得多。

切入建议：最顺手的组合是**图建模 + 时序无监督检测**（拓扑天生是图，见 [[图神经网络]]），偏离正常时空相关性即告警，绕开标签稀缺。更缺人的是**"攻击最小可检测性 vs 检测器最优性"的博弈分析**，贴合你实验室"工业 AI 与安全"定位。变种边界以 [[20_Research/Papers/L3-工控与电网安全/Comprehensive_Survey_and_Taxonomies_of_False_Injection_Attacks_in_Smart_Grid|021 FDIA 综述]] 为准。
