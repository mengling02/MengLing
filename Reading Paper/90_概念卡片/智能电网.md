# 智能电网（Smart Grid）

## 一句话

**把"电"和"信息"彻底融合的下一代电网**：能自我感知、自我决策、自我恢复，支持海量分布式新能源和用户双向互动。

## 从"传统电网"到"智能电网"变了什么

| 维度 | 传统电网 | 智能电网 |
|---|---|---|
| 信息流 | 单向（只能看，控制有限） | **双向**（用户也能反馈、也能被调度） |
| 电源 | 集中式大电厂为主 | **集中 + 海量分布式**（光伏、风电、储能、电动车） |
| 通信 | 专用、封闭 | **IP 化、无线、5G、云平台** |
| 控制 | 人工调度 | **自动化 + AI 辅助决策** |
| 安全边界 | 相对清晰 | **边界模糊，攻击面爆炸** |

## 关键特征（美国 DOE 的经典概括）

1. **自愈（Self-healing）**：故障自动隔离与恢复
2. **互动（Consumer participation）**：用户参与需求响应
3. **抗攻击（Attack resistance）**：抵御物理与网络攻击
4. **高质量供电**：满足数字设备要求
5. **容纳多种发电与储能**
6. **市场化**：支持电力交易
7. **资产优化**

## 中国的说法：**新型电力系统**

中国官方提法叫"**新型电力系统**"，核心是：
- **新能源占比高**（风光为主）
- **源网荷储一体化**
- **数字化、智能化**

配套安全要求也升级了 —— 见 [[电力监控系统安全防护体系]] 和 [[20_Research/Papers/L1-零基础起步/新型电力系统信息物理安全防护体系研究|002]]。

## 为什么它是"安全的噩梦"

**每增加一个智能设备，就多一个攻击入口**：
- 智能电表（数亿台）
- 分布式光伏逆变器（可被远程控制）
- 电动车充电桩
- 5G 通信模组
- 云平台、移动运维 App

→ 传统"物理隔离"越来越难维持 → 这正是当前研究的**核心矛盾**，也是你的机会所在。

## 关键公式

这个概念以架构/标准/定性描述为主，没有单一的核心公式。理解它的要点在于：

- **双向信息流**：能量流仍是单向（发电 → 输电 → 配电 → 用电），但信息流变成双向（量测上行、控制与价格信号下行），"双向"是它与传统电网在结构上的分界线。
- **分层控制架构**：调度中心（EMS）→ 变电站自动化（保护、测控）→ 现场设备（互感器、智能终端），自上而下实时性要求递增、单点算力递减，安全机制必须匹配这个梯度。
- **高异构与海量终端**：集中式大电源叠加海量分布式光伏、风电、储能与电动汽车，接入点数量级增长，形成"数量爆炸 + 弱认证 + 长生命周期 + 难打补丁"的攻击面结构。
- **隔离假设的失效**：远程运维、5G 与云平台接入使传统"物理隔离"难以维持，边界从"清晰的墙"退化为"持续变化的接缝"。

## 用网安的话说（小电解读）

- **≈ 一个巨大的、地理分布的、实时性极高的 ICS + IoT 网络**：传统电网 ≈ 封闭内网，智能电网 ≈ 把控制平面暴露给海量边缘设备。
- **≈ IoT 经典困局的放大版**：**数量爆炸 + 弱认证 + 长生命周期 + 难打补丁**。

### 相同点

1. **威胁建模方法可直接搬**：资产清点、攻击面枚举、信任边界划分，只把对象换成逆变器、充电桩、电表。
2. **边缘攻击与 AI 安全工具都能对上**：固件后门、默认凭证、中间人劫持量测 ≈ [[后门攻击]] / [[数据投毒攻击]]；配电侧分布式检测用到 [[联邦学习]]、[[差分隐私]]。

### 不同点 / 难点

1. **实时性约束卡死了安全机制**。IT/IoT 里加一层 TLS 最多卡几十毫秒；配电自动化的保护与控制有严格时延预算，**加密和检测必须在毫秒与低算力额度内完成** —— 这是"轻量级安全"成为刚需的原因。
2. **双向信息流改变了攻击方向**。传统电网只能打"控制下行"；智能电网里用户侧参与反馈，[[电力需求响应]] 意味着**用户侧数据能伪造来影响调度**。
3. **设备归属带来治理难题**。充电桩、屋顶光伏是用户私有资产，运维权限分散，**谁有权打补丁、谁记日志在组织上模糊**。

### 电网场景的特殊之处

1. **物理约束仍然在场**。攻击最终要满足物理规律和 [[状态估计]] 的残差检验，这给检测补了 IT 没有的先验。
2. **风险是系统性的**。IT 里一台 IoT 设备沦陷只是一个点；电网里足够多分布式资源被协同控制，会变成**频率/电压的系统性问题** —— 这是 [[虚拟电厂]] 安全值得单独研究的原因。
3. **仿真平台相对可得**。配电与需求响应侧有公开数据与仿真环境（[[工控安全测试床与数据集]]）。

**切入建议**：最有缝隙的题是**"实时性预算下的轻量级异常检测"** —— 给定时延/算力上限，比较不同模型（含 [[时序图神经网络]]）在该预算内的性能，画成边界曲线。目标明确、可量化、能对比已有方法，正好吃你实验室的工业 AI 与安全方向。坑是别把仿真当真实结论。
