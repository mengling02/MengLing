# 数据投毒攻击

## 一句话

在模型**训练阶段**往训练数据里掺假，让训出来的检测器带着"先天缺陷"上岗 —— 上线后参数已固化，事后很难查出哪几条样本是假的。

## 为什么重要

电网里越来越多的检测器是"学出来的"：用历史量测、通信流量、负荷曲线训练出的异常检测模型（见[[电力系统异常检测]]、[[深度学习检测方法]]）。这类模型有一条 IT 世界同样存在的软肋 —— **它的判断力来自训练数据，谁控制了训练数据，谁就控制了它的判断力**。

投毒攻击处在这条链路的最上游，也是最难修的一环：模型上线后权重已经固化，你很难从参数里反推出"当初哪几条样本被动了手脚"。相比之下，[[对抗样本攻击]]是测试阶段的"当场骗过你"，投毒是训练阶段的"提前教歪你"，两者常被拿来对比。

它和[[后门攻击]]是上下游关系：**投毒是手段，后门是其中一种结果**。投毒不一定要做后门 —— 让模型整体变笨也算投毒。

在电网语境下它的特殊之处在于：数据来自现场（智能电表、AMI、PMU、运维工单），这些数据源本身就在攻击者可能触及的范围内，而"数据被污染"往往要在很久之后、以"检测器突然大面积误报"的形式暴露出来。

## 核心要点

| 分类维度 | 类型 | 说明 |
|---|---|---|
| 攻击目标 | 可用性投毒 | 让模型整体性能下降，谁都能看出它变笨了 |
| | 定向/完整性投毒 | 只让模型在特定样本上出错，其余场合表现正常，极隐蔽 |
| | 后门投毒 | 平时完全正常，见到触发器才出错，最难排查 |
| 投毒时机 | 训练前投毒 | 篡改已归档的历史数据集，可长期潜伏 |
| | 在线/持续投毒 | 针对在线学习、增量更新的检测器边训边投 |
| 攻击者知识 | 白盒 / 灰盒 / 黑盒 | 是否知道模型结构、特征工程与训练流程 |
| 投毒比例 | 少量定向 vs 大量无差别 | 定向投毒往往只需极小比例样本即可生效 |
| 电网典型入口 | 智能电表上报、AMI 量测、标签数据、运维标注 | 由现场设备、第三方数据商或内部人员写入 |

## 关键公式

投毒的标准数学形式是一个**双层优化**（bilevel optimization）：

$$\max_{\mathcal{D}_{p}}\ \mathbb{E}_{(x,y)\sim\mathcal{D}_{test}}\Big[\mathcal{L}\big(f_{\theta^{\star}}(x),\ y\big)\Big],\qquad \theta^{\star}=\arg\min_{\theta}\ \mathbb{E}_{(x,y)\sim\mathcal{D}_{tr}\cup\mathcal{D}_{p}}\big[\mathcal{L}(f_{\theta}(x),y)\big]$$

- $\mathcal{D}_{tr}$：干净的原始训练集
- $\mathcal{D}_{p}$：攻击者构造的投毒样本集（外层要优化的变量）
- $f_{\theta}$：待训练的检测模型，$\theta$ 是它的参数
- $\theta^{\star}$：在"干净数据 + 投毒数据"上正常训练出来的模型参数
- $\mathcal{L}$：训练损失（内层）／攻击者希望最大化的测试损失（外层）

**白话**：内层是受害者老老实实跑一遍训练；外层是攻击者挑毒样本，目标是让训出来的模型在测试集上错得越离谱越好。攻击者不碰模型、不碰训练代码，**只改"教材"，让模型自己学歪**。

## 用网安的话说（小电解读）

这基本就是 AI 版的**供应链投毒**：你信任的是"训练流程"，但流程的输入被污染了，所以整条信任链都塌了。跟你熟悉的软件供应链攻击（往依赖库里塞恶意包）在逻辑上完全同构 —— 区别只是投毒的目标从"可执行代码"变成了"数据分布"。

和[[对抗样本攻击]]的关键差异要记牢：对抗样本是**测试时**在输入上做手脚，属于"现场骗过你"；投毒是**训练时**在数据上做手脚，属于"提前教歪你"。前者改的是推理路径，后者改的是决策边界本身。所以对抗样本可以靠输入净化、随机化推理来缓解，投毒只能靠数据溯源和训练流程管控。

电网场景的特殊之处有三点：

1. **数据来源天然分散且不完全可信**。AMI 量测由成千上万块电表上报，运维标签由人打，任何一个环节都可能被污染，你很难说"我的训练集是干净的"。
2. **攻击后果是"沉默的失效"**。检测器被投毒后不是报错，而是安静地放行攻击 —— 这和"检测器被关掉"效果一样，但更难发现。
3. **标签极难获取**。电网里真实攻击样本本来就稀缺（见[[工控安全测试床与数据集]]），大量数据靠仿真生成或人工标注，这恰恰给投毒提供了巨大空间。

切入建议：把"投毒鲁棒性"当作检测器的评价维度之一（不只看准确率，还要看"训练集被污染 5% 时性能掉多少"），这个方向在电网文献里还很空。
