# 强化学习（RL）

## 一句话

智能体通过**与环境反复交互、试错、获得奖励**来学习最优策略。在电网里，它既被用来**控制电网**，也被攻击者用来**寻找攻击策略**。

## 为什么电网适合 RL

电网的很多问题是**序贯决策问题**（每个动作影响未来状态），传统优化方法在不确定性下会很吃力：

| 任务 | 传统方法 | RL 的优势 |
|---|---|---|
| 紧急控制 | 预置策略表 | 可自适应未知工况 |
| 电压/无功控制 | 优化求解 | 在线快速决策 |
| 频率调节（AGC） | PID | 学得更优策略 |
| 需求响应调度 | 规则 | 应对用户行为不确定性 |

## 核心要素（小白版）

- **状态 $s$**：电网当前运行点（电压、潮流、频率）
- **动作 $a$**：调整发电机出力、切负荷、投切电容
- **奖励 $r$**：通常 = −（运行成本 + 越限惩罚 + 停电损失）
- **目标**：最大化累积折扣回报 $\mathbb{E}\left[\sum_t \gamma^t r_t\right]$

## 关键难点：**安全**

电网里"试错"的代价是**真的停电**，所以不能像打游戏一样随便探索。
于是有了 **Safe RL（安全强化学习）**：

1. **约束马尔可夫决策过程（CMDP）**：把安全要求写成硬约束
2. **Lyapunov 方法**：构造能量函数保证稳定性
3. **安全层/盾牌（Shield）**：动作执行前先过一遍安全校验
4. **对抗训练**：让策略在扰动下依然稳健

## 攻击者的视角（对你最重要）

RL 是**双刃剑**：

- 攻击者用 RL 学习**最优攻击策略**：例如用 RL 搜索能让频率控制器失稳的[[虚假数据注入攻击(FDIA)]]序列
- 也有论文用 RL 做**动态防御**：学习最优的[[移动目标防御(MTD)]]扰动策略

**这是一个天然的"攻防博弈"选题框架**：把电网攻防建模成两个 RL 智能体的对抗（类似 AlphaGo 的自博弈），目前工作还很少。

## 关键公式

学习目标（最大化累积折扣回报）：

$$J(\pi) = \mathbb{E}_{\pi}\!\left[\sum_{t=0}^{\infty} \gamma^{t} r_t\right]$$

- $\pi$：策略，即在状态 $s$ 下选择动作 $a$ 的规则
- $r_t$：第 $t$ 步获得的奖励，电网里通常取"运行成本 + 越限惩罚 + 停电损失"的负值
- $\gamma \in [0,1)$：折扣因子，衡量未来奖励相对于即时奖励的重要程度

白话：**智能体不追求某一步的即时收益最大，而是追求长期总收益最大**——这正是它适合序贯决策类电网控制任务的原因。

Bellman 最优方程（动作价值函数的最优形式）：

$$Q^{*}(s,a) = r(s,a) + \gamma \max_{a'} Q^{*}(s',a')$$

- $Q^{*}(s,a)$：在状态 $s$ 下采取动作 $a$、此后始终按最优策略行动所能获得的最大累积折扣回报
- $s'$：执行动作 $a$ 后转移到的下一状态
- $r(s,a)$：该步的即时奖励

白话：**"这一步有多好" = "现在拿到的奖励" + "折扣之后的、下一步最好能有多好"**。几乎所有值迭代、Q-learning、DQN 类算法都在逼近这个方程。

安全强化学习中的约束形式（约束马尔可夫决策过程 CMDP）：

$$\max_{\pi}\; J(\pi) \quad \text{s.t.} \quad C_i(\pi) = \mathbb{E}_{\pi}\!\left[\sum_{t} \gamma^{t} c_i(s_t, a_t)\right] \le d_i$$

- $c_i(\cdot)$：第 $i$ 项安全代价，如电压越限量、功率不平衡量
- $d_i$：该项代价的允许上限（安全阈值）

白话：**把"安全要求"从软惩罚改写成硬约束**——电网里试错的代价是真的停电，所以必须显式限制策略的越限行为。

## 用网安的话说（小电解读）

你其实已经见过 RL 了，只是叫法不同：

- **≈ 自动化渗透测试的智能体版**。静态 payload ≈ 固定策略表；RL 智能体则是在环境里反复试、按反馈调整，学出一条最优攻击链。
- **≈ 红蓝对抗的自博弈**。红队蓝队就是两个 RL 智能体互相当对手：一个学让频率失稳，一个学扰动防御。

### 相同点

1. 奖赏塑造和你在检测模型里做的损失设计是一回事：**你奖励什么，智能体就学什么**，设计错了就学出歪策略。
2. 探索-利用、稀疏奖励、样本效率这些坑，两边一样。
3. 对抗鲁棒性评估的方法论（扰动、迁移、自适应攻击）可以直接搬。

### 不同点 / 难点

1. **试错的代价是真的停电**。所以必须上安全 RL：CMDP 把安全写成硬约束、Shield 在动作执行前拦一道。
2. **环境不可重置**。电网的状态带着历史（机组组合、负荷水平），**部分可观测 + 不可逆**让标准 RL 假设失效。
3. **奖励函数很难写对**。运行成本、越限惩罚、停电损失怎么加权？不同权重导出完全不同的策略，而**你很难判断哪个才对**。另外调度要求毫秒级响应，策略网络还必须很轻。

### 电网场景的特殊之处

1. **仿真环境是这个方向的基础设施**。先搭靶场、再谈迁移，跟你在网安里的做法一致。
2. **攻防双方都可用 RL**，且天然对称：攻击者学最优 [[虚假数据注入攻击(FDIA)]] 序列，防御者学最优 [[移动目标防御(MTD)]] 扰动策略。
3. **物理约束可以当安全层**。保护装置硬逻辑天然适合做 Shield，比纯学习更容易给出安全保证。

### 切入建议

最值得做的是**把电网攻防写成双 RL 自博弈框架**：一个智能体搜索能让保护误动或频率失稳的攻击序列，另一个学习防御扰动，在仿真环境里对抗训练。可参看 [[20_Research/Papers/L4-AI与电网安全/Safe_Reinforcement_Learning_for_Power_System_Control_A_Review|032 安全强化学习用于电力系统控制综述（必读）]]。这条题直接落在你实验室"工业 AI 与安全"的核心，且**自博弈框架本身仍是缺的**。风险也说清楚：sim-to-real 目前不成熟，短期更适合定位成方法论研究。
