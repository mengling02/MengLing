# 逆变器与电力电子安全

## 一句话

逆变器是新能源并网的必经关口，它没有传统发电机的物理惯性、稳定性全靠控制算法，所以**改它的控制参数就等于改电网的物理稳定性**。

## 为什么重要

传统电网的稳定，很大程度上靠同步发电机的**转子惯量**：一大坨旋转的机械质量，负荷突变时它靠动能顶一下，频率不会立刻塌。新能源（光伏、风电、储能）通过逆变器并网，**没有转子、没有惯量**，只能靠控制算法去"模拟"惯量（虚拟同步机、下垂控制等）。

这就带来一个质变：**电网的稳定性从"物理规律保证"变成了"代码保证"**。而代码是可以被改的。

所以逆变器安全不是"某个设备的安全"，而是[[电力系统稳定性]]的**新攻击面**。它也是[[微电网安全]]、[[虚拟电厂]]、[[电动汽车充电安全]]的共同底座 —— 这些新形态里，功率都从逆变器过。相比篡改量测的[[虚假数据注入攻击(FDIA)]]（骗过调度员的"眼睛"），攻击逆变器是直接动手改"手脚"，后果是物理的、即时的。

## 核心要点

| 维度 | 要点 | 说明 |
|---|---|---|
| 逆变器的角色 | 直流-交流转换 | 光伏板、风机、电池、充电桩输出的直流电，必须逆变才能并入交流电网 |
| 为什么脆弱 | 无物理惯量 | 稳定性依赖控制算法而非机械质量，参数即稳定裕度 |
| | 高度软件化 | 固件可刷、参数可远程下发、通信接口开放 |
| 主要攻击面 | 控制参数篡改 | 改下垂系数、频率/电压设定值、功率指令 |
| | 固件与配置 | 恶意固件、后门版本、供应链污染 |
| | 通信接口 | Modbus/DNP3 等工业协议（见[[Modbus协议安全]]），常无认证 |
| | 设定值注入 | 伪造调度指令或伪造量测反馈形成闭环欺骗 |
| 攻击后果 | 频率/电压偏移 | 局部甚至广域的频率、电压异常 |
| | 振荡与失稳 | 多台逆变器协同被控时可激发系统级振荡 |
| | 市场影响 | 通过物理扰动传导到电力市场价格（见[[虚拟电厂]]） |
| 防御思路 | 残差/物理一致性检测 | 用物理模型判断控制行为是否合理 |
| | 指令认证与加密 | 保护下行控制通道 |
| | 硬件信任根与固件签名 | 防止固件被刷 |

## 关键公式

逆变器最经典的控制律是**下垂控制**（droop control），它用"假装有惯量"的方式让逆变器像发电机一样响应：

$$\omega=\omega_{0}-m\,(P-P_{0}),\qquad V=V_{0}-n\,(Q-Q_{0})$$

- $\omega$：逆变器输出角频率，$V$：输出电压幅值
- $\omega_0, V_0$：额定频率与额定电压（空载设定点）
- $P, Q$：逆变器实际输出的有功、无功功率
- $P_0, Q_0$：额定有功、无功设定点
- $m, n$：下垂系数（$m$ 调频率-有功，$n$ 调电压-无功）

**白话**：负荷变重（$P$ 变大）时，主动把频率降一点、电压降一点 —— 因为多个逆变器都按同一套规则动作，最终自动达成功率分配平衡。**下垂系数 $m,n$ 直接决定系统"软硬"**：调大调小都可能破坏稳定性，所以这两个数是攻击者的首选目标。（不同文献用的符号和形式略有差异，但物理含义一致。）

## 用网安的话说（小电解读）

这个方向对你来说有个非常友好的切入点：**它的攻击面就是工控攻击面的翻版，只是后果落在了物理世界。**

对应关系：
- 篡改逆变器控制参数 ≈ **篡改 PLC 的寄存器值**。技术上没有新东西，难的是"怎么接进去"——现场逆变器往往有维护接口、有无线/运营商通道、有厂商远程运维通道，这些都是可打的入口。
- 恶意固件 ≈ **固件植入/供应链投毒**。区别是逆变器固件一旦被刷，攻击者可以直接让它在某个时刻"物理上乱来"。
- 伪造调度指令 ≈ **中间人攻击**。因为下行控制通道常缺少认证与完整性保护。

和 IT 场景最大的不同，也是这个方向最有意思的地方：**攻击效果不由"数据"体现，而由"物理量"体现**。在 IT 里你被打了，最多是服务不可用；在这里，攻击者可以让频率偏移、让保护装置误动、让设备过载烧毁。而且**没有"回滚"按钮** —— 频率掉下去就是掉下去了。

另一个特殊点：**攻击者不需要控制很多台**。因为逆变器是"按同一套规则协同"的群体，破坏协同的收益远大于单点破坏。这跟"打一个节点影响整个集群"的思路（类似分布式系统的协同攻击）完全一致，也是论文 080 那类"选择性攻击若干台逆变器"的动机所在。

切入建议：这个方向把"工控协议安全"和"控制理论"缝合得很好。你可以从**逆变器通信接口的协议安全分析**入手（门槛低、和你的背景对口），再往"控制参数篡改的物理影响建模"延伸。
