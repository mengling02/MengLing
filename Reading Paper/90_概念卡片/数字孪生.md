# 数字孪生

## 一句话

给物理电网配一个**实时同步的数字镜像**：真实系统在动，镜像跟着动；你在镜像里试一下会发生什么，再决定真实系统怎么做。

## 为什么重要

数字孪生和普通仿真的区别就一个字：**联**。普通仿真跑的是离线模型，输入是假设的数据；数字孪生的输入是**现场实时数据**（[[SCADA系统]]量测、[[同步相量测量单元(PMU)]]相量），输出还能反过来影响物理系统。

它和另一个概念必须分清楚：[[硬件在环仿真(HIL)]]是把**真实硬件**接进仿真回路，数字孪生是把**实时真实数据**接进仿真回路。两者常常叠加使用 —— 一个测试床既有孪生模型、又有真实继电器，那它同时是数字孪生和 HIL。

在电网安全研究里，数字孪生解决了一个长期痛点：**你不能在真实电网上做攻击实验**。真实电网不能停机、不能承受风险；纯软件仿真又抓不到真实设备的协议行为、时序抖动和固件缺陷。数字孪生给出了中间地带 —— 足够真实、可以随便打、还能重放复现。它是[[工控安全测试床与数据集]]这条技术线的上游方法论。

## 核心要点

| 维度 | 要点 | 说明 |
|---|---|---|
| 三大组成 | 物理实体 | 真实电网/变电站/设备 |
| | 数字模型 | 高保真仿真模型（潮流、电磁暂态、通信网络） |
| | 数据链路 | 双向实时数据流：状态同步 + 决策反馈 |
| 按耦合程度分 | 数字模型（Digital Model） | 只有人工数据交换，无自动同步 |
| | 数字影子（Digital Shadow） | 物理 → 数字自动同步，反向仍靠人工 |
| | 数字孪生（Digital Twin） | 双向自动同步，可闭环干预 |
| 电网中怎么用 | 状态镜像 | 用孪生算"应该是什么状态"，与实测比对做异常检测 |
| | 攻击推演 | 在孪生里跑攻击场景，评估影响与后果（what-if） |
| | 安全测试 | 作为靶场给攻击/防御算法提供可复现环境 |
| | 运维与培训 | 故障演练、人员培训、策略验证 |
| 关键难点 | 保真度 vs 实时性 | 模型越精细越算不动，实时性要求算得够快 |
| | 数据质量 | 孪生依赖量测，量测被污染则孪生一起错（见[[虚假数据注入攻击(FDIA)]]） |
| | 孪生自身的安全 | 孪生是新的攻击面：改模型、改同步数据即可误导决策 |

## 关键公式

这个概念以定性描述为主，没有单一的核心公式。它的技术要点可以概括为一条**同步与偏差**关系：

- 孪生的价值在于"偏差"：真实量测 $z(t)$ 与孪生预测 $\hat{z}(t)=f(\text{model}, \text{input})$ 之间的差 $\Delta(t)=z(t)-\hat{z}(t)$。
- $\Delta(t)$ 在正常工况下应保持在噪声水平；**一旦 $\Delta(t)$ 持续偏离，就说明"模型错了"或"现场被篡改了"** —— 前者要更新模型，后者可能是攻击。
- 这正是孪生做安全检测的原理：它把"异常检测"变成了"物理模型一致性校验"，和你熟悉的基于基线的异常检测同源，只是基线来自物理方程而不是统计。

工程上真正的难点不是这个式子，而是**时间对齐**：真实量测带时延和抖动，孪生模型步长是离散的，两者要对齐到同一时间轴上才有意义。

## 用网安的话说（小电解读）

数字孪生在网安里最贴切的类比是**高保真蜜罐 / 网络靶场（cyber range）**，而且它比蜜罐多一层用途：

- **作为靶场 ≈ 网络靶场**。真实环境不能打、测试环境不够真，靶场就是折中。你在 CTF 和渗透测试里对靶场的所有理解都可以直接搬过来：可复现、可重放、可快照回滚、可批量跑攻击脚本。
- **作为检测基线 ≈ 白名单/完整性校验**。孪生说"这个时刻的潮流应该是这样"，相当于一份**物理层面的已知良好状态基线**。任何偏离都值得怀疑 —— 这跟文件完整性监控（FIM）、配置基线漂移检测是同一套逻辑。
- **孪生自身的安全 ≈ 监控系统被攻破**。这点最关键也最容易被忽略：**如果你用孪生做检测，那孪生就成了新的单点信任**。攻击者只要污染孪生的输入数据（而输入恰恰来自可被[[虚假数据注入攻击(FDIA)]]篡改的量测），就能让孪生"验证"一个错误的现实。**用被污染的尺子量东西，量出来的一定是错的。** 这和"日志服务器被攻破后所有审计结论都不可信"完全同构。

相同点：可复现、可快照、可并行实验、支持红蓝对抗 —— 与靶场一致。
不同点：**孪生是实时闭环的**，它不只是实验环境，还可能直接参与运行决策。一旦参与决策，"孪生被攻破"就不再是研究环境的问题，而是生产事故。

电网场景的特殊之处：
1. **物理保真度有硬门槛**。IT 靶场只要能跑通协议就行；电网孪生必须让潮流、频率、保护动作都符合物理规律，否则实验结论没意义。
2. **实时性是硬约束**。电磁暂态仿真的步长要到微秒级，这对算力和模型简化都是挑战。
3. **数据量大、来源多**。PMU 每秒几十帧、海量智能电表数据，孪生要做数据清洗与对齐，这本身就是攻击面。

切入建议：数字孪生是**做实验的基础设施**，不是攻击技术。对你来说最实际的用法是：把它当作"验证你的检测算法"的平台，同时把"**孪生自身的可信性**"（数据源可信、模型不可被篡改）当作一个独立的小选题 —— 这个角度在文献里还比较空。
