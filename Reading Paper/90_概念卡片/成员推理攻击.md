# 成员推理攻击

## 一句话

攻击者只看模型的输出，就能判断**某条数据是不是在训练集里** —— 而"在不在训练集里"本身往往就是隐私。

## 为什么重要

电网里训练模型的数据，很多是**居民的真实用电行为**：负荷曲线、充电记录、家电使用习惯。这些数据被用来训练[[电力负荷预测]]或[[电力系统异常检测]]模型之后，模型本身就成了一个"数据残留物"。

成员推理攻击的意义在于：它不要求攻击者拿到原始数据，只要拿到模型（甚至只是模型的输出接口），就能一条一条地问"这户人家在不在你的训练集里"。而被选进训练集这件事本身就有信息量 —— 比如"某个时段有稳定充电行为的家庭才会被选进 EV 充电研究的数据集"，那么推断出成员身份，就等于推断出"这家有电动车、且某时段在家"。

它和[[差分隐私]]是同一枚硬币的两面：**MIA 是"要防的"，差分隐私是"用来防它的数学工具"**。所以在隐私方向的论文里，MIA 常被当作衡量隐私泄露程度的基准攻击（benchmark attack）——如果一个方法连 MIA 都挡不住，隐私保护就无从谈起。

## 核心要点

| 分类维度 | 类型 | 说明 |
|---|---|---|
| 攻击者知识 | 黑盒 | 只能查询模型拿输出（API、预测值、置信度） |
| | 白盒 | 能拿到模型参数、梯度、训练配置 |
| 主要信号 | 置信度 / 损失值 | 模型对"见过的"样本往往给出过高置信度 |
| | 梯度信息 | 联邦学习中从上传的梯度里反推（[[联邦学习攻击与防御]]） |
| | 时间、能耗、缓存等侧信道 | 作为辅助信号 |
| 攻击手法 | 阈值法 | 用一个阈值卡损失或置信度，最简单 |
| | 影子模型法 | 训练多个"影子模型"模拟目标模型，再训一个二分类器 |
| | 基于生成模型的攻击 | 用生成模型逼近目标模型的训练分布 |
| 防御手段 | 差分隐私训练 | 加噪，从数学上限制单条样本的影响 |
| | 正则化 / 早停 / 限制输出精度 | 降低过拟合，压缩攻击信号 |
| | 只返回硬标签 / 聚合上报 | 减少可观测信息量（见[[联邦学习]]） |

## 关键公式

最经典的一类 MIA 是**阈值法**，把攻击写成一个二分类判别：

$$\mathcal{A}(x)=1\Big[\ \mathcal{L}\big(f_{\theta}(x),\,y\big)<\tau\ \Big]$$

- $x, y$：待判定样本及其标签
- $f_{\theta}$：目标模型（$\theta$ 为参数）
- $\mathcal{L}$：损失函数，$\mathcal{L}(f_\theta(x),y)$ 越小说明模型对该样本越"自信正确"
- $\tau$：攻击者选定的阈值
- $\mathcal{A}(x)=1$：判定"$x$ 在训练集中"

**白话**：模型对训练时见过的样本会"记得更牢"，损失更低、置信度更高。攻击者只要设一个阈值卡一下，就能把"见过的"和"没见过的"分开 —— **过拟合就是隐私泄露**。

（实际攻击中 $\tau$ 常通过在影子模型上标定得到；不同文献的具体做法差别较大。）

## 用网安的话说（小电解读）

这个概念对你来说是老朋友 —— 它属于**隐私攻击三件套**（成员推理、属性推理、模型反演）里最容易理解也最好复现的一个，本质就是"利用模型的过拟合做信息泄露"。

用你熟悉的语言说：模型是一个"记性太好"的服务端。它对训练样本的响应和陌生样本的响应有系统性差异，攻击者不需要攻破任何访问控制，**只要把模型当成一个 oracle 反复查询，就能做统计推断**。这跟"通过多次查询从数据库里一点点抠出信息"的推理攻击（inference attack）思路完全一致，也跟侧信道攻击里"观察响应差异反推内部状态"的味道很像。

相同点：都靠"可观测输出与秘密之间的相关性"；都不需要破坏系统，属于被动信息收集；防御都要靠"降低输出与秘密的相关性"（差分隐私、限流、输出降精度）。

不同点：MIA 的攻击面是**模型本身**，而不是网络或主机；它的"漏洞"不是某个配置错误，而是**统计规律**，所以没法打补丁，只能从训练过程入手降低信号强度。

电网场景的特殊性：
1. **数据即物理事实**。用电负荷曲线能反推在不在家、用什么电器、甚至生活习惯。所以 MIA 在电网里泄露的不只是"隐私"，而是**可被用于入室盗窃、精准营销、保险定价**的物理行为信息。
2. **数据高度相关**。同一台变压器下几百户的负荷曲线有强相关性，即使某户没被直接泄露，也能通过邻居推断出来 —— 这是电网特有的"群体隐私"问题。
3. **联邦学习是主战场**。电网数据天然分散在各台区、各充电桩，[[联邦学习]]是主流方案，但它恰恰是 MIA 的高发地：梯度、模型更新本身就是泄露信道（见[[联邦学习攻击与防御]]）。

切入建议：把 MIA 当"隐私测评工具"用 —— 对现有的电网联邦学习方案做一轮 MIA 基准测试，量化"到底漏了多少"，这类工作门槛不高但结论扎实。
