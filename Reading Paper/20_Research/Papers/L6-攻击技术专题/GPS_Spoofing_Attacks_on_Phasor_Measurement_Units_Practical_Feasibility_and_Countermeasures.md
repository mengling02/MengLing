# 046 | 针对同步相量测量单元的 GPS 欺骗攻击：实际可行性与对策

> [!abstract] 一句话
> 用几百块的软件定义无线电就能骗掉 PMU 的 GPS 授时，论文做了实验证明，并提出用 LoRa 做远程交叉校验的对策。

## 为什么读它

这篇论文在 L6 专题里位置特殊：**它是唯一一篇"物理层/无线层"攻击，也是唯一一篇给出了完整对策的论文。**

前面 039–045 讨论的都是"数据层"攻击——篡改数据、注入偏移、制造振荡。这篇换了一个完全不同的攻击面：**GPS 授时信号**。

为什么这个攻击面这么重要？因为 **PMU 的一切价值都建立在"时间同步"上**：

- PMU 之所以能给出全网同步的相角，是因为所有 PMU 都用 GPS 提供的**统一时钟**打时间戳。
- 如果攻击者能欺骗某个 PMU 的 GPS 接收机，让它相信"现在是另一个时间"，那么这个 PMU 测出的**相角就会整体偏移**——而它上报的数据在其他方面完全正常。

**这是"数据完全合法但数值错误"的又一个精妙案例**，而且它的攻击成本极低：论文用**商用软件定义无线电（SDR）**就实现了，不需要任何定制硬件。

论文的另一半价值在于**对策**：用 **GPS 信号冗余 + LoRa 扩频调制**，在远程位置校验 GPS 信号完整性，并与 PMU 当前输出比对。作者强调这是一个**可以立即部署（ready-to-deploy）**的方案。

这篇的写法也值得注意——**攻击和防御在一篇论文里闭环**，这在攻击技术专题里是少见的。

## 这篇论文在讲什么（白话版）

### 背景：PMU 为什么依赖 GPS

先解释 PMU 的工作原理（不熟的先看 043）。

电网的状态包括**电压相角**，而相角是一个**相对量**——你必须有一个统一的时间基准，才能比较不同地点的相角。比如"北京某节点的电压相角是 30 度"，这个 30 度是相对于什么？答案是相对于一个**全网统一的时间参考**。

GPS 系统除了给出位置，还给出**极其精确的时间**（精度可达几十纳秒）。PMU 就利用这个时间来打时间戳：每个 PMU 在自己的时间戳上采样，于是所有 PMU 的采样点可以被对齐到同一个时刻，调度中心就能得到"同一瞬间"的全网快照。

**关键洞察**：PMU 上报的数据里，**相角是相对于 GPS 时间的**。如果攻击者让某个 PMU 的 GPS 接收机相信"现在是另一个时间"，那么这个 PMU 测出的相角就会整体偏移。

### 攻击原理：时间偏移如何变成相角偏移

这是本文最核心的物理机理，用一句话说：

> **相角 = 角频率 × 时间**

所以时间的偏移会**线性地**转化为相角的偏移。具体公式见下一节。

**这里有个很重要的性质**：这种攻击产生的错误是**结构化的**——它不是随机的噪声，而是**一个整体偏移**。而且因为时间偏移是**常数**（攻击者让时钟固定偏 $\Delta t$），所以相角偏移也是**常数**。这种"整体一致的偏移"非常容易被误认为是"正常运行状态下的相角差"，从而难以被识别。

论文标题说"**先前研究已经证明 GPS 欺骗攻击可以瘫痪电力系统运行**"——本文的贡献不是发现这个威胁，而是：

1. **证明它用廉价设备就能实现**（实验证据）
2. **提出一个可部署的对策**

### 实验证据：用 SDR 实现欺骗

论文提供了**实验证据（experimental evidence）**，证明这种攻击可以用**常见的商用数字无线电——软件定义无线电（Software Defined Radio，SDR）**实现。

**SDR 是什么**（给零基础读者的解释）：传统无线电的调制解调是用专用硬件电路做的，SDR 则把大部分信号处理放到软件里，硬件只负责收发原始信号。这样一来，一台通用设备就能模拟**任意**无线协议——包括 GPS 信号。

**为什么这件事重要**：SDR 的价格已经很低（消费级的几百到几千元），而且**公开可得**。这意味着 GPS 欺骗的攻击门槛**从"国家级能力"降到了"实验室能力"**。

**攻击者需要什么前提**：

| 前提 | 说明 |
|---|---|
| **无线发射能力** | 需要在目标 PMU 天线附近有发射能力（GPS 信号很弱，所以通常需要一定程度的靠近或定向发射） |
| **知道 GPS 信号结构** | GPS 的民用信号格式是**公开标准**，不需要逆向 |
| **SDR 设备** | 商用可得，成本低 |
| **不需要** | 不需要接触 PMU、不需要入侵通信网络、不需要电网知识 |

**注意最后一行**：这是本文最令人警惕的地方——**攻击者完全绕过了电网的信息安全防护体系**（防火墙、加密、认证全都用不上），因为他攻击的是**无线物理层**。

### 对策：GPS 信号冗余 + LoRa

论文提出的对策思路是：**在远程位置独立校验 GPS 信号的完整性，然后和 PMU 的当前输出比对。**

具体架构：

1. **GPS 信号冗余**：不依赖单个 GPS 接收机的输出。在**远程位置**（和 PMU 物理分离的地点）也部署 GPS 接收，得到"独立的"GPS 时间/位置数据。
2. **LoRa 传输**：用 **LoRa（Long Range，远距离低功耗无线通信）扩频调制技术**，把远程校验点的数据传回来。
3. **比对**：把远程校验得到的 GPS 数据，与 PMU 当前输出的数据做比对。如果 PMU 报告的相角与"应该有的相角"（由远程 GPS 推算）不一致，就判定为攻击。

**为什么用 LoRa？** 论文提到 LoRa 的**扩频调制（spread spectrum modulation）**技术。扩频的信号特征和 GPS 完全不同，所以**针对 GPS 的欺骗设备不会（也难以）同时欺骗 LoRa 链路**——这形成了一种**跨信道的交叉验证**。

作者强调这是一个"**ready-to-deploy（可立即部署）**"的系统，能"为 PMU 的 GPS 欺骗检测问题提供**即时解决方案（instant solution）**"。

**摘要未给出**实验的具体参数：SDR 型号、发射距离、发射功率、LoRa 的传输距离、检测的准确率/误报率等。

## 关键公式（小白版）

**公式一：GPS 时间偏移到相角偏移的转换**

$$\theta_i(t) = \omega \left( t - t_{\text{GPS}} \right)$$

当 GPS 时间被欺骗偏移 $\Delta t$ 时：

$$\theta_i'(t) = \omega \left( t - (t_{\text{GPS}} + \Delta t) \right) = \theta_i(t) - \omega \Delta t$$

所以相角偏移量是：

$$\Delta\theta = \omega \cdot \Delta t$$

逐个符号解释：

- $\theta_i(t)$：第 $i$ 个 PMU 在时刻 $t$ 测得的相角。
- $\omega$：系统的角频率（$= 2\pi f$，工频 50 Hz 时约等于 314 rad/s）。
- $t_{\text{GPS}}$：GPS 提供的参考时刻。
- $\Delta t$：攻击者造成的 GPS 时间偏移量。
- $\Delta\theta$：由此产生的相角测量偏移量。

**白话**：**时间偏一点，相角就偏一大截。** 因为角频率 $\omega$ 很大（约 314 rad/s），即使 GPS 时间只偏 1 毫秒，相角也会偏移约 0.314 弧度（约 18 度）——这在电力系统里是**极其显著**的错误。

**这个公式也说明了一个重要的事实**：GPS 时间精度是 PMU 精度的**瓶颈**。PMU 声称的相角精度（比如 0.01 度）对应的时间精度是微秒级——这意味着攻击者只需要造成**微秒级**的时间偏差，就能造成**可见**的相角误差。

**公式二：交叉校验的判据（概念形式）**

$$\left| \theta_i^{\text{PMU}}(t) - \theta_i^{\text{remote}}(t) \right| > \tau \;\Rightarrow\; \text{判定为 GPS 欺骗}$$

- $\theta_i^{\text{PMU}}(t)$：PMU $i$ 上报的相角。
- $\theta_i^{\text{remote}}(t)$：由远程（LoRa 链路）独立校验点推算出的、PMU $i$ **应该**有的相角。
- $\tau$：判定阈值。
- 超过阈值 → 报警。

**白话**：**不信单个 GPS 接收机，用第二个独立来源做交叉验证。** 这和你熟悉的"双因子认证""多源数据交叉校验"是同一个防御范式。

## 用网安的话说（小电解读）

这篇论文对你来说几乎没有理解门槛，因为它就是**无线安全 + 时间同步攻击**的组合。逐条对应：

**第一，GPS 欺骗 = 中间人攻击 + 时间同步攻击。**

- **时间同步攻击**：你一定见过 **NTP 欺骗**——伪造 NTP 服务器的响应，让客户端把系统时间调错。时间错了，Kerberos 票据会失效（时钟偏移过大直接拒绝）、TLS 证书会过期、日志时间线会错乱。**GPS 欺骗是同一个攻击在物理层的实现**：伪造的不是 NTP 响应包，而是 GPS 卫星信号。
- **中间人**：GPS 欺骗本质上是"冒充合法信号源"，和 ARP 欺骗冒充网关、DNS 欺骗冒充解析服务器，是同一类手法。区别在于 GPS 是**单向广播**——PMU 只能被动接收，无法通过"挑战-响应"来验证信号源的真实性。**这使它比双向通信的协议更难防**（没有握手，就没有认证的机会）。

**第二，攻击绕过了整个信息安全防护体系。**

这是最值得你注意的一点。你之前读的论文（038、042）都在讨论防火墙、异常检测、加密、认证。**GPS 欺骗让这些全部失效**——因为：

- 攻击不经过任何网络 → 防火墙看不到
- 攻击不篡改任何数据包 → 完整性校验通不过
- 攻击不涉及凭据 → 认证机制用不上

**这就是"攻击面"概念的绝佳教材**：当你把防护资源全部投在"网络层"时，攻击者会转向"物理层"。这和你熟悉的"WAF 做得很强，但服务器本身有漏洞"、"边界防护很强，但供应链被投毒"是同一个逻辑——**防御是有盲区的，而攻击者总在找盲区**。

**第三，对策是"带外信道 + 冗余校验"，这是经典防御范式。**

论文的对策用 LoRa 做第二信道。这在网安里的对应物非常多：

- **带外验证（Out-of-band verification）**：短信验证码、硬件令牌、电话回拨——用不同的信道验证同一个事实。
- **DNSSEC**：用密码学签名让解析结果可验证，不依赖单一信任源。
- **多路径路由 / 多源交叉验证**：不信任任何单一数据源。
- **冗余传感器 / 投票机制**：工控里的三取二（2oo3）表决。

**核心思想**：**单点信任必然导致单点失效。** 论文的攻击之所以成立，是因为所有 PMU 都信任同一个 GPS 系统；对策之所以有效，是因为引入了**独立的第二个信任源**。

**第四，一个很有价值的对比：为什么 GPS 欺骗比 FDIA 更"划算"？**

| 维度 | FDIA（039–045） | GPS 欺骗（本篇） |
|---|---|---|
| 需要的知识 | 电网拓扑/参数（或大量数据） | 只需 GPS 信号格式（公开） |
| 需要的设备 | 网络访问权限 | 一台 SDR |
| 是否需要实时计算 | 通常需要 | 不需要 |
| 绕过什么防护 | 绕过 BDD | 绕过**所有**网络层防护 |
| 攻击效果 | 状态估计出错 | 相角整体偏移 |

**这个对比说明：攻击的"性价比"不一定和"技术复杂度"成正比。** GPS 欺骗技术上更简单，但因为打在了防护盲区上，反而可能更有效。这对你做安全评估时的启发是：**不要只看攻击的技术难度，要看它绕过了多少层防御。**

**迁移到你的研究，可以怎么切入？**

1. **GPS 欺骗检测的机器学习方法**。论文的检测方案是**基于阈值比对的**（和远程数据比，超阈值就报警）。这相当于一条**静态规则**。可以研究：**能否用机器学习识别 GPS 欺骗的特征模式？** 比如，欺骗造成的偏移是"常数偏移"，而正常的相角波动是"随机波动"——这个统计特征差异是可学的。这是一个直接可做的选题。
2. **多源授时的融合与攻击检测**。现代设备可以同时接收 GPS、北斗、GLONASS、Galileo。**多星座交叉验证**是一个很自然的加固思路，而且它比论文的 LoRa 方案**不需要额外基础设施**。可以研究"多星座一致性检测"能否识别只欺骗单一星座的攻击。
3. **时间同步攻击的通用化**。GPS 欺骗只是时间同步攻击的一种。还有 NTP、PTP（IEEE 1588）、IRIG-B 等。可以做一个**系统性的"电力系统时间同步攻击面"综述或威胁建模**——这个题目在中文文献里非常少。
4. **物理层攻击的检测**：把信号层的特征（信号强度、多普勒频移、到达角）引入检测。这属于无线安全（RF fingerprinting），和你实验室的方向可能不那么直接对接，但如果导师有无线安全背景，这是一个很好的交叉点。

## 局限性

- **摘要缺少实验参数**：没有给出 SDR 型号、发射距离、发射功率、天线配置，因此无法评估"实际可行性"到底有多容易（是"隔着一条街"还是"要贴到天线上"）。
- **对策的部署成本未评估**：LoRa 方案需要部署额外的远程 GPS 校验节点和通信链路，论文称其"ready-to-deploy"，但没有给出成本、覆盖范围、维护需求。
- **LoRa 链路本身也可能被攻击**：论文用扩频来增加攻击难度，但如果攻击者同时针对 LoRa 频段，方案是否还有效？论文没有讨论这个"对策本身的安全性"问题（这是一个常见的研究盲点）。
- **未讨论多星座场景**：现代 PMU 通常支持 GPS + 北斗等多星座，只欺骗一个星座可能被一致性检查发现。论文的威胁模型是否考虑了这一点，摘要中没有体现。
- **缺少性能指标**：对策的检测准确率、误报率、延迟等关键指标，摘要中均未给出。
- **单篇论文的完整性**：攻击实验和对策设计是否在同一测试环境下验证（即"对策能否挡住论文自己实现的攻击"），摘要中未明确说明。

## 和你的方向有什么关系

- **这是一个"攻击面盲区"的绝佳案例**，非常适合写进开题报告的"研究背景"——用来论证"电网安全不能只做网络层防护"。
- **对接实验室方向**：
  - **入侵检测**：GPS 欺骗检测本质上是"时序信号的异常检测"——检测"相角是否有一个不正常的常数偏移"。你熟悉的自编码器、LSTM 都能用上。
  - **AI与数据安全**：多源授时数据的融合与异常识别。
  - **图像识别与安全**：如果你有信号处理背景，可以把 GPS 信号做成时频图（spectrogram），用 CNN 做欺骗信号识别。这是一个很有意思的跨领域迁移（把无线电信号变成"图像"再分类）。
- **三个具体选题**：
  1. **基于相角时序统计特征的 GPS 欺骗检测**——不需要额外硬件（不需要 LoRa 节点），只分析 PMU 数据本身。门槛低，可快速产出。
  2. **多星座一致性检测**——利用 GPS/北斗/Galileo 的交叉验证，无需额外基础设施。
  3. **电力系统时间同步攻击面综述**——覆盖 GPS/NTP/PTP/IRIG-B，中文文献空白。
- **实验资源提醒**：真做 GPS 欺骗实验需要 SDR 设备和屏蔽环境，**且涉及无线电发射，必须遵守当地的无线电管理规定**（未经许可的发射可能违法）。建议优先做"检测算法"而非"攻击实现"。

## 原文摘要

> Prior research has demonstrated that global positioning system (GPS) spoofing attacks on phasor measurement units (PMUs) can cripple power system operation. This paper provides an experimental evidence of the feasibility of such an attack using commonly available digital radios known as software defined radio (SDR). It also introduces a novel countermeasure against such attacks using GPS signal redundancy and low power long range (LoRa) spread spectrum modulation technique. The proposed approach checks the integrity of the GPS signal at remote locations and compares the data with the PMUs current output. This countermeasure is a ready-to-deploy system that can provide an instant solution to the GPS spoofing detection problem for PMUs.
