# 045 | 无网络参数下针对交流状态估计的定向虚假数据注入攻击

> [!abstract] 一句话
> 攻击者连线路参数都不需要知道，只靠 PMU 数据中负荷的自然波动（用 OU 过程建模），就能反推出电网参数并构造定向大偏差攻击。

## 为什么读它

这篇和 041 是一对"双胞胎"——都在削减攻击者的知识假设，但**削减的方式和数学工具完全不同**：

| | 041 | 045（本篇） |
|---|---|---|
| 削减什么 | 不需要拓扑连接和线路电抗 | 不需要任何网络参数 |
| 数据来源 | 一般量测 | 只用**有限的 PMU 数据** |
| 数学工具 | 稀疏优化（低秩+稀疏分解） | **Ornstein-Uhlenbeck 过程**（随机过程） |
| 攻击目标 | 保持隐蔽 | **定向（targeted）**大偏差 |
| 状态估计模型 | 线性（DC） | **非线性（AC）** |

**"AC 状态估计"这个点特别重要。** 前面 039–043 的隐蔽性分析基本都基于直流潮流（DC）线性模型，因为线性模型下 $a = Hc$ 的推导干净漂亮。但真实电网的潮流方程是**非线性的**（$z = h(x) + e$，$h$ 是三角函数），在非线性模型下构造隐蔽攻击要难得多。本文正面处理了这个问题。

另一个亮点是它把**负荷的随机波动**从"噪声"变成了"信息源"——这是很有创造性的思路，也是这篇论文最值得学的地方。

## 这篇论文在讲什么（白话版）

### 背景：AC 状态估计为什么更难攻击

先复习一下：状态估计是"用量测反推电网状态"的算法。状态 $x$ 主要是各节点的电压幅值和**相角**。

**DC（直流）状态估计**做了一次线性化近似：假设电压幅值都接近额定值、相角差很小，于是潮流方程可以近似成线性的 $z = Hx + e$。这样一切都很简单——攻击条件 $a = Hc$ 直接推导出来。

**AC（交流）状态估计**不做这个近似，用的是真实的非线性潮流方程：

$$z = h(x) + e$$

- $h(\cdot)$：非线性函数，包含三角函数（$\sin$、$\cos$），描述电压幅值、相角与量测之间的关系。
- $z$：量测向量（PMU 场景下包含电压/电流相量）。
- $e$：量测误差。

**非线性带来两个麻烦**：

1. **隐蔽攻击的构造不再是一个线性方程组问题**，需要解非线性方程，可能存在多解或无解。
2. **"定向"更难**：攻击者想让状态估计输出一个**指定的**偏移量，在非线性模型下需要仔细处理。

### 本文的核心思路：把"负荷波动"变成"信息源"

这是本文最有创造性的部分，值得慢慢讲。

**观察**：电网的负荷**一直在波动**。用户开灯关灯、工厂启停设备，负荷时时刻刻在小幅随机变化。这种波动在传统认知里是**噪声**——它干扰量测，让状态估计不准确。

**本文的洞察**：既然负荷在波动，而负荷变化会**引起状态和量测的变化**，那么反过来，**观测量测的变化就能推断出系统的动态特性**。也就是说，**波动本身携带了关于系统参数的信息**。

**关键问题**：怎么从随机的波动中提取出确定性的系统参数？

**答案**：用一个已知的随机过程模型来拟合负荷波动，然后从拟合出的参数里反推电网参数。

### 工具：Ornstein-Uhlenbeck 过程

**Ornstein-Uhlenbeck 过程（简称 OU 过程）**是本文的核心数学工具。

OU 过程是一个**均值回复（mean-reverting）的随机过程**——它描述的量会随机波动，但总是被"拉回"到一个长期均值附近。数学形式是一个随机微分方程：

$$dX_t = \theta(\mu - X_t)\,dt + \sigma\, dW_t$$

逐个符号解释：

- $X_t$：时刻 $t$ 的随机变量（在这里，代表负荷或状态的偏离量）。
- $\mu$：长期均值（long-term mean），系统被拉回的"中心"。
- $\theta$：回复速率（mean-reversion rate），越大说明"拉回"得越快。
- $\sigma$：波动强度（volatility），越大说明随机波动越剧烈。
- $W_t$：标准布朗运动（维纳过程），提供随机性。

**为什么选 OU 过程？** 因为它**符合负荷的物理特性**：负荷不会无限漂移（有均值回复），但也不是恒定的（有随机波动）。而且 OU 过程是一个**线性高斯过程**，它的统计性质（均值、方差、自协方差）都有**解析表达式**——这意味着攻击者可以从观测数据中**直接估计出 $\theta$、$\mu$、$\sigma$**，而不需要复杂的优化。

**这就是本文的技术路线**：

1. 用 OU 过程建模电网在**环境条件（ambient conditions）**下的负荷动态。
2. 利用 OU 过程的统计性质（特别是自协方差结构），从 PMU 量测数据中**反解出电网参数**。
3. 用反解出的参数构造 FDIA 向量。
4. 发动定向大偏差攻击。

论文把这个过程明确表述为"**从入侵者视角（from the viewpoint of intruders）**"设计的算法。

### 攻击者的能力假设

这是判断本文威胁度的关键，逐条列出：

| 项目 | 内容 |
|---|---|
| **需要网络参数吗** | 不需要（no network parameters） |
| **需要什么数据** | 有限的 PMU 数据（limited PMU data） |
| **需要实时吗** | 需要观测一段时间来估计参数（隐含要求，摘要未明说时长） |
| **需要知道攻击目标吗** | 需要，这是"定向（targeted）"攻击 |
| **对负荷动态的假设** | 假设负荷波动符合 OU 过程 |

**注意一个隐含的强假设**：本文的方法依赖"负荷本身有可建模的动态（intrinsic load dynamics）"。如果某个时段负荷非常平稳（比如深夜），波动信息不足，参数估计的精度可能下降。这一点论文没有在摘要中讨论。

### 结果

论文在 **IEEE 39-bus 系统**上研究了各种攻击向量和攻击区域，结论是：

> 提出的 FDIA 方法能够**成功绕过不良数据检测**，并以**很高的概率**发动**定向大偏差攻击**。

论文还给出了该 FDIA 模型的**充分条件（sufficient conditions）**——即在什么条件下攻击能够成立。

**摘要未给出**具体的成功率数值（只说"很高概率"）、需要的 PMU 数量、参数估计的误差、以及攻击的偏差幅度等量化结果。

## 关键公式（小白版）

**公式一：AC 量测模型**

$$z = h(x) + e$$

- $z$：量测向量。
- $x$：状态向量（电压幅值与相角）。
- $h(\cdot)$：**非线性**函数，由电网拓扑、线路参数和物理定律（基尔霍夫定律）共同决定。
- $e$：量测噪声。

**白话**：和 DC 模型的 $z = Hx + e$ 相比，唯一的区别是 $Hx$ 变成了 $h(x)$——但这个"唯一区别"让所有线性代数工具都失效了，攻击构造从"解线性方程组"变成"解非线性方程"。

**公式二：OU 过程**

$$dX_t = \theta(\mu - X_t)\,dt + \sigma\, dW_t$$

- $\theta$：均值回复速率，反映负荷"回归正常水平"的速度。
- $\mu$：长期均值，负荷的基准水平。
- $\sigma$：波动强度，负荷随机波动的幅度。
- $W_t$：布朗运动，随机性的来源。

**白话**：负荷会随机地上下抖动（$\sigma dW_t$），但总被一个"弹簧"拉回基准值（$\theta(\mu - X_t)dt$）。**攻击者要做的，就是从观测到的负荷轨迹里，估计出这根弹簧的强度。**

**公式三：攻击隐蔽性条件（概念形式）**

在非线性模型下，隐蔽性条件从线性的 $a = Hc$ 变成：

$$a = h(x + c) - h(x)$$

- $a$：注入的偏移向量。
- $c$：攻击者想让状态估计偏移的量。
- $h(x+c) - h(x)$：状态偏移 $c$ 引起的量测的**实际（非线性）变化**。

**白话**：攻击者注入的偏移，必须**恰好等于**"状态偏移 $c$ 在非线性模型下引起的量测变化"。这样检测器看到的残差依然正常。**注意这个式子是"非线性"的——它依赖 $x$ 的当前值，所以攻击向量必须随运行状态实时调整**（这也是本文必须"定向"的原因之一）。

## 用网安的话说（小电解读）

这篇论文有几个点能直接和你的知识对上，而且对应得相当漂亮。

**第一，这是"黑盒系统辨识"（Black-box System Identification）。**

攻击者不知道电网参数（相当于不知道目标系统的内部结构），但他能观测输入输出（PMU 数据），于是他用一个**参数化的统计模型**（OU 过程）去拟合观测数据，从拟合参数里反推系统特性。

这和你在网安里做的事一模一样：

- **黑盒模型窃取（Model Extraction）**：通过大量查询 API，用代理模型拟合目标模型的行为。
- **协议逆向（Protocol Reverse Engineering）**：通过观测流量推断协议格式和状态机。
- **侧信道分析**：通过功耗、时序、缓存访问模式推断内部密钥或数据结构。
- **网络拓扑发现**：通过主动/被动探测推断网络结构。

**区别在于"探测信号"的来源**：本文的攻击者**不主动注入探测信号**，而是**利用系统本身就有的波动**（负荷波动）作为"免费的探测信号"。这一点非常聪明——**主动探测容易被发现，被动利用天然波动则完全无痕**。

**第二，"利用负荷波动"= 利用"Living off the Land"的信号。**

网安里的 Living off the Land（LoL）指的是用系统自带的合法工具做攻击，不引入外来物。本文的思路是同一个哲学的变体：**不引入任何人为的信号，只用系统本身就有的行为作为信息来源**。

你熟悉的应用场景：

- **被动指纹识别**：不发探测包，只监听正常流量来识别设备。
- **加密流量分析**：不破解加密，只从流量模式（包大小、时序）推断用户行为。
- **旁路信道攻击**：不干扰系统运行，只观察它的自然行为。

**第三，"定向攻击（Targeted Attack）"= 定向对抗样本。**

论文强调是"定向（targeted）"的——攻击者要让状态估计**输出指定的**错误值，而不是随便输出一个错的。

这和你熟悉的**定向对抗样本（Targeted Adversarial Example）**是同一个概念：非定向攻击只要让分类器出错就行，定向攻击要让分类器输出**指定的类别**。定向攻击更难，但危害更精确可控——攻击者可以精确地"伪造"他想让调度员看到的电网状态。

**第四，AC 非线性 = 模型不再是线性的，攻击要跟着状态变。**

这是一个很重要的工程含义：在 DC 线性模型下，攻击向量 $a = Hc$ 是**固定的**，算一次就能一直用。但在 AC 非线性模型下，$a = h(x+c) - h(x)$ **依赖当前状态 $x$**，所以：

- 攻击者必须**实时知道当前状态**（需要持续窃听量测）
- 攻击者必须**实时重算攻击向量**（需要计算能力）

这显著提高了攻击成本。**这也是为什么"AC 下的 FDIA"比"DC 下的 FDIA"研究得少——不是因为不重要，而是因为难。**

**迁移到你的研究，可以怎么切入？**

1. **用深度时序模型替代 OU 过程**。OU 过程是一个线性高斯模型，只能刻画均值回复的动态。而真实的负荷波动可能有更复杂的结构（周期性、长记忆性、非线性）。可以用 **LSTM / Transformer / 扩散模型**来学习负荷动态，看看能否得到更精确的参数估计，从而构造更隐蔽的攻击。这是一个非常自然、且技术栈完全匹配的迁移点（你的深度学习能力直接可用）。
2. **防御侧：检测"参数估计行为"**。攻击者要估计系统参数，必须观测一段时间的量测。那么防御方能否检测"有人在系统性地观测我们"？这是一个**反侦察**问题，在网安里对应"检测扫描行为"。有意思的是，这个方向在电网安全文献里几乎没有。
3. **利用正常波动做异常检测**。反过来用：正常波动是有统计规律的，攻击者注入的信号会破坏这些规律。可以设计检测器**只看负荷波动的统计特性**是否正常。这是一个很优雅的检测思路——**不需要知道攻击长什么样，只需要知道"正常长什么样"**（这正是无监督异常检测的核心思想）。
4. **AC 与 DC 的攻击成本对比实验**。系统性地比较"同样的隐蔽性要求下，AC 模型比 DC 模型需要多多少计算量和多少实时数据"。这是一个可以做实验、结论清晰的题目。

## 局限性

- **负荷动态假设过强**：假设负荷波动符合 OU 过程（线性、高斯、均值回复）。真实负荷波动可能有更强的非平稳性（比如早晚高峰的突变、天气驱动的阶跃变化），此时 OU 模型会失配。
- **依赖 PMU 覆盖**：方法只用 PMU 数据，所以其适用性受限于 PMU 的部署密度。在 PMU 覆盖不足的区域，攻击者可能无法估计出足够多的参数。
- **需要观测时间**：从随机波动中估计参数需要足够的样本量，这意味着攻击者必须先"潜伏"一段时间。摘要没有说明需要多长时间的数据。
- **摘要缺少量化结果**：只说"很高概率（very high probabilities）"绕过 BDD，没有给出具体成功率、偏差幅度、PMU 数量需求。
- **仿真规模较小**：只在 IEEE 39-bus 系统上验证，规模中等。
- **没有防御方案**：纯攻击视角，没有给出"面对无参数攻击该如何检测"的建议。
- **充分条件的宽严未知**：论文给出了充分条件，但摘要没有说明这些条件在实际电网中是否容易满足。

## 原文摘要

> State estimation is a data processing algorithm for converting redundant meter measurements and other information into an estimate of the state of a power system. Relying heavily on meter measurements, state estimation has proven to be vulnerable to cyber attacks. In this paper, a novel targeted false data injection attack (FDIA) model against AC state estimation is proposed. Leveraging on the intrinsic load dynamics in ambient conditions and important properties of the Ornstein-Uhlenbeck process, we, from the viewpoint of intruders, design an algorithm to extract power network parameters purely from PMU data, which are further used to construct the FDIA vector. Requiring no network parameters and relying only on limited phasor measurement unit (PMU) data, the proposed FDIA model can target specific states and launch large deviation attacks. Sufficient conditions for the proposed FDIA model are also developed. Various attack vectors and attacking regions are studied in the IEEE 39-bus system, showing that the proposed FDIA method can successfully bypass the bad data detection and launch targeted large deviation attacks with very high probabilities.
