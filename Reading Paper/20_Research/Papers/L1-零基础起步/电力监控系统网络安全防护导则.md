# 006 | 电力监控系统网络安全防护导则（GB/T 36572-2018）

> [!abstract] 一句话
> 《电力监控系统安全防护规定》的**技术落地版**：法规说"要做什么"，这份国标说"具体怎么做"。

## 定位：法规 → 国标 → 行标，三级落地

理解中国电力网络安全的标准体系，记住这条链条：

```
第一层：法律 / 行政法规
  └─ 《网络安全法》《关键信息基础设施安全保护条例》
        ↓
第二层：部门规章（强制）
  └─ 《电力监控系统安全防护规定》（发改委，2025-01-01 施行）
        ↓
第三层：国家标准（推荐性，但行业强推）
  └─ GB/T 36572-2018《电力监控系统网络安全防护导则》  ← 本篇
        ↓
第四层：行业标准（具体实施）
  └─ DL/T 2335-2021《电力监控系统网络安全防护技术导则》
```

## 这份标准解决什么问题

《电力监控系统安全防护规定》给出的是**原则性要求**（安全分区、网络专用……）。
但工程人员需要回答：**具体怎么分区？隔离装置选什么参数？加密认证怎么做？**

GB/T 36572-2018 就是把这个"怎么做"标准化。

它通常覆盖的内容框架（依据电力行业网络安全导则的通行结构）：

| 环节 | 内容 |
|---|---|
| **总体要求** | 安全防护目标、原则、责任划分 |
| **安全分区** | 分区的具体划分方法、边界定义 |
| **网络专用** | 专用网络的建设要求 |
| **横向隔离** | 隔离装置的技术要求与部署方式 |
| **纵向认证** | 加密认证装置的部署与密钥管理 |
| **主机与终端安全** | 操作系统加固、外设管控、恶意代码防范 |
| **安全监测** | 监测手段、告警、审计 |
| **安全管理** | 制度、人员、运维、供应链 |

## 用网安的话说（小电解读）

> 对你而言，这份标准的价值在于：**它是一份"甲方需求说明书"**。

如果你未来做的是**防御技术研究**（检测算法、防护装置），那么：
- **标准里的要求 = 你的技术必须满足的功能清单**
- 例如：标准要求"安全监测"，你的检测算法就要能对接这个监测体系

如果你做的是**攻击研究**（威胁分析、脆弱性），那么：
- **标准 = 攻击者要突破的目标清单**
- 例如：隔离装置是标准强制的 → 那么"隔离装置本身的绕过"就是高价值研究方向

> 写论文的"研究背景"时，引用标准比引用论文更有分量 —— 因为它证明你的问题**来自真实工程需求**。

## 局限性

- 2018 年发布，**未覆盖"新型电力系统"带来的新形态**（虚拟电厂、海量分布式、5G 接入等）。
- 推荐性标准（GB/T），法律强制力弱于部门规章，但通过行业监管实际强制推行。
- 本笔记未覆盖条款细节，需要时请查原文。

## 和你的方向有什么关系

- **合规性研究**：任何面向中国电网的技术方案，都要论证"符合 GB/T 36572 与发改委规定"。
- **标准缺口研究**：新型电力系统带来的新场景（如分布式资源接入）在现行标准中覆盖不足 → **"标准缺什么，你就研究什么"**，这是很实用的选题策略。
- 建议动作：**把这份标准和 DL/T 2335-2021 一起，作为你的"合规基线"收藏**。
