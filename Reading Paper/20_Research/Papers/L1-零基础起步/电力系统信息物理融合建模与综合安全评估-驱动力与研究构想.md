# 001 | 电力系统信息物理融合建模与综合安全评估：驱动力与研究构想

> [!abstract] 一句话
> 中国学者较早系统提出：**智能电网 = 信息物理融合系统（CPS）**，因此"信息故障"必须和"物理故障"放在同一个框架里建模和评估 —— 这是整个电网安全研究的**方法论起点**。

## 为什么让你先读这篇

你是网安背景，第一反应可能是"电网安全 = 给电网做渗透测试 + 部署 IDS"。
这篇论文会纠正这个直觉：

> **在电网里，信息层的一个比特错误，可能导致物理层的一台变压器烧毁。**

所以电网安全不是"IT 安全的子集"，而是一个**跨层耦合问题**。理解这一点，你后面读的所有论文（尤其是 [[虚假数据注入攻击(FDIA)]] 和 [[状态估计]]）才有落脚点。

## 这篇论文在讲什么（白话版）

作者要回答三个问题：

**1）为什么必须做"信息物理融合建模"？**

传统电力系统分析假设"信息是完美的"——量测准确、通信可靠、控制指令必然执行。
但现实中：
- 通信延迟 → 控制指令迟到 → 物理系统失稳
- 量测错误 → 状态估计出错 → 调度决策错误
- 通信中断 → 保护装置拒动 → 故障扩大

所以必须**把信息环节的可靠性纳入电力系统分析**。

**2）怎么建模？**

核心思路：**在传统电力系统模型上，叠加"信息层"的模型**，并刻画两者的交互：
- 信息层：通信网络拓扑、时延、丢包率、误码率、可用性
- 物理层：潮流方程、发电机动态、保护逻辑
- **耦合接口**：量测上行通道 + 控制下行通道

**3）评估什么？**

不是单纯评估"信息系统的安全性"，而是评估**"信息故障 → 物理后果"的传递链**。
比如：某个通信链路中断，会不会导致某个保护误动，进而引发连锁跳闸？

## 核心内容拆解

论文的论证链条大致是：

```
驱动力（为什么现在必须做）
  ├─ 智能电网/能源互联网 → 信息与物理深度融合
  ├─ 信息环节故障 → 物理系统风险（不再是理论假设，已有实际案例）
  └─ 传统"电力"与"信息"分而治之的评估方法失效
        ↓
研究构想（怎么做）
  ├─ 信息物理融合建模：统一建模框架 + 跨层耦合接口
  ├─ 综合安全评估：从"信息指标"和"物理指标"各自独立 → 到"跨层传递链"评估
  └─ 关键难点：建模粒度、耦合关系量化、计算复杂度
```

## 用网安的话说（小电解读）

> 这篇论文的价值，不在于给出了什么算法，而在于**定义了问题空间**。

- 它相当于在电网领域提出：**"我们不能再用 ISO 七层模型分层看问题了，必须做跨层威胁建模。"**
- 传统 IT 安全里，一台服务器挂了 → 服务降级。电网里，一条通信链路断了 → **可能触发保护误动，导致真实设备损坏**。
- 所以电网安全的核心方法论是：**"攻击路径 + 物理后果"的联合建模**，而不是单纯的漏洞挖掘。
- 对应你熟悉的概念：这是一种**"后果驱动"的风险评估（Consequence-driven）**，而非"漏洞驱动"。

**一个直接可用的思维模板**：
```
攻击入口（信息域）
  → 被篡改的数据/指令（信息域）
    → 哪个控制回路受影响（耦合点）
      → 哪个物理量越限（物理域）
        → 什么后果（停电/设备损坏）
```
后面每一篇攻击类论文，都可以用这个链条去拆。

## 局限性

- 这是 2016 年的"研究构想"类论文，**重框架、轻算法**：它提出问题，但不给出完整解决方案。
- 主要面向**传统电力系统 + 集中式通信**，对后来出现的海量分布式新能源、5G、云平台等新形态覆盖不足（这部分由 [[20_Research/Papers/L1-零基础起步/新型电力系统信息物理安全防护体系研究|002]] 这篇 2025 年的论文来补）。
- 未涉及攻击者视角（对抗性），主要是可靠性视角（随机故障）。

## 原文摘要

> 智能电网与能源互联网都是典型的信息物理融合系统（cyber-physical system，CPS），信息环节的可靠性问题可能导致物理系统的运行风险。为了对其系统及信息故障进行分析评估，文中在分析了对电力系统进行信息物理融合建模与评估的必要性及驱动力后，提出了一种 CPS 融合建模构想。该方法将 CPS 系统抽象为一个有向拓扑图，模型将物理系统和信息系统中的状态量统一抽象为“数据节点”，将信息处理、信息传输等环节抽象为“信息支路”。在此基础上，系统的信息-能量流可通过矩阵运算的方式快速简单地进行量化计算，与一般的迭代计算和仿真方法相比，该方法可有效提升计算速率。最后，对信息物理系统的综合安全评估技术体系进行了展望。
