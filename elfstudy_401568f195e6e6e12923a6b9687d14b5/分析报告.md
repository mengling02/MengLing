# elfstudy 逆向分析报告

> 目标文件:`elfstudy`(43,304 字节,ELF64 / x86-64 / PIE / 动态链接,已 strip)
> 分析时间:2026-10-31

## 1. 程序本体:一个"ELF 结构查看器"

- 品牌:**ELFStudy 1.4.2 — ELF structure inspector**
- 用法:`elfstudy [-q] [-p|-s|-y] [file|-]`
- 功能:把目标 ELF 读进一块 64KB 的 .bss 静态缓冲区(0xB260),然后打印
  `[image] / [header] / [program headers] / [sections]` 信息
- 选项:`-q / -p / -s / -y / -h` 及长选项,无隐藏命令(全部字符串比较都集中在
  main 的参数解析里,共 9 个,逐一核对过)

## 2. 代码层结论:程序里**没有** flag 逻辑

| 检查项 | 结果 |
|---|---|
| 全量反汇编(0x2540–0x7317,4618 条指令) | 完成 |
| 可达性分析(从 _start/main/init_array 递归) | 全部代码可达,**无死代码函数** |
| .eh_frame FDE 表还原的函数边界 | 与反汇编完全吻合,共 38 个函数,**没有额外函数** |
| main 中 `call 0x3b30` | 该函数是 `endbr64 + 9×nop + ret` 的**空函数**(疑似被挖空的调用点) |
| .rodata / 立即数中的字符串 | 全部为正常提示语;全文件 **0 处 `flag`、无 `flag{`** |
| movabs 64 位立即数 | 只有 PT 名称(GNU_EH_F 等),无隐藏串 |

## 3. 文件层异常(手工构造 ELF 的证据)

这个 ELF **不是链接器产物**,而是作者自写生成器拼出来的,多处痕迹:

1. **段间空隙藏数据**(关键)
   - `0x7325–0x8000`(两个 PT_LOAD 之间,运行时**不映射**):
     - `0x7325–0x7396` 113 字节 0
     - `0x7396–0x739A` `90 90 90 90`
     - **`0x739A–0x76C6` 812 字节高熵数据(熵 7.19 bit/byte,均匀分布)** ← 唯一可疑载荷
     - `0x76C6–0x7A6E` 与正式 `.rela.plt` **逐字节相同**的副本(936 B)
     - 其余为 0
   - `0x1988–0x2000`:21 条 24 字节记录 `(随机8B, 0x73xx, 0x3900000001)`,
     其中 14 条指向 `0x7325+8i` —— 指向上面被清零的"14 项指针表"
   - `0x9198–0x9AC8`:930 字节全 0
2. **伪重定位**:`.rela.dyn` 前 4 条 R_X86_64_RELATIVE 的 r_offset 落在
   `.dynsym[57]` 内部(0x954/0x956/0x957/0x958,相互重叠),addend 为
   0x2600/0x25f1/0x25ff/0x1d30
3. **`.rodata` 的 to_chars 数字表被破坏**:标准应为 200 字节 `"000102…9899"`,
   实际 207 字节,在偏移 192 处多插入了 7 个字符 `2939495`
4. `.shstrtab` 后缀合并,`.plt`/`.got` 两节的名字变成 `plt`/`got`
5. 空隙中的"随机值"带弱雪崩特征(多值共享 `…b6 e9` 尾字节),说明是
   生成器内存泄漏,而非真随机

## 4. 对 812 字节载荷的解密尝试(全部失败)

### 4.1 无已知明文时
- 单字节 XOR/ADD 全文件扫描:无
- **重复密钥 XOR 穷举证明**:周期 1–64 内不存在任何能解出全 ASCII 的密钥
- 全文件任意 8/12/16/20/24/32 字节窗口作重复密钥:无
- 全文件任意 812 字节窗口与载荷异或:无
- RC4 / AES-128/256 (ECB/CBC/CTR/CFB/OFB, 16 组口令) / TEA/XTEA/XXTEA:无
- hash 链密钥流、autokey、链式/差分/累计异或:无
- LSB/MSB、2bit/4bit 隐写、位步长 1–256、字节重排:无
- zlib/bz2/lzma/裸 deflate、常见文件魔数:无

### 4.2 已知明文 crib = `flag{`(用户提供格式后)
- **周期 1–8 直接破解**(crib 给出完整密钥,全偏移):无
- **周期 6–16 双 crib(`flag{` + `}`)**:仅 2 个候选,均为统计噪声
  (`flag{Opo8yi}` 等,解密后其余 800 字节仍是乱码,排除)
- crib 派生密钥流的周期性搜索(任意周期):无 → 密钥流非周期
- PRNG 全偏移 crib 暴搜:mt19937(C++ 播种)/ glibc rand() / Python random,
  种子 0–6000:无;LCG/xorshift32/64 结构检测:无
- AES 密钥 = 文件内所有 16/32 字节窗口(4.3 万个 × 5 种模式):无
- AES/ChaCha/Salsa 密钥 = 文件哈希、口令哈希:无
- RC4 密钥 = 文件内所有窗口:无
- 中等长度(207–1980B)结构区(数字表/节表/文件头/gap1)作重复密钥:无
- 简单变换后的 `flag{` 模式全文件搜索(位反转/半字节交换/UTF-16/7bit/ rol/add/xor 256 种):无

**结论:载荷熵 7.19、直方图均匀、无周期、无结构 —— 是强密码输出或纯随机填充,
密钥不在二进制内。** 载荷已导出为 `payload_0x739a.bin`(md5
`f788a9b5060b69de11ca2d1ef0cce9a0`)。
